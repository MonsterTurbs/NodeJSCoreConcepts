📝 Study Notes: Basic Networking Concepts

🔍 Introduction to Networking

  • 💡Networking lets computers share information without moving disks by hand.
  • ⏳Before coding network apps in Node.js, understand how networks work.
  • 🌐These ideas apply to any language: JavaScript, Go, Java, Python, and more.

📼 Old-School File Sharing

  • 💾Used floppy disks, CDs, or USB sticks to move data between PCs.
  • 🚶‍♂️You had to save file to disk, walk to another computer, then load it.
  • ✈️To share with someone far away, you might even have to mail or fly the disk.

🔌 Building a Simple Network

  • 📶Use Ethernet cables to connect devices to a network switch.
  • 🔀A switch directs data between connected computers automatically.
  • ⚙️Switch setup may involve simple configuration (like SSH into it).

💳 Network Interface & MAC Address

  • 🖥️Each computer has a network interface card (NIC) for cable connections.
  • 🔑NIC has a unique MAC address (48‑bit identifier in hex).
  • 🔒MAC addresses help switches know where to send data.

📦 Packets & Frames

  • ✉️Data is broken into packets (also called frames on Ethernet).
  • 📝Each packet includes:
    • Source MAC (sender)
    • Destination MAC (receiver)
    • Payload (your data)
  • 🔄Switch reads destination MAC and forwards packet to the right device.
