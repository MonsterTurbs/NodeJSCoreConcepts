⏱️Why Progress?

When uploading big files, show users how much is done (e.g. 20%, 50%, 100%).

📊Get Total Size

// after opening file handle
const stats = await fileHandle.stat();
const totalSize = stats.size; // bytes

📥Track Bytes Sent

let uploadedBytes = 0;
fileStream.on('data', chunk => {
  uploadedBytes += chunk.length;
  // …calculate & show percent…
});

➗Calculate & Display %

const percent = Math.floor(uploadedBytes / totalSize * 100);
if (percent !== lastPercent && percent % 5 === 0) {
  lastPercent = percent;
  console.log(`Uploading… ${percent}%`);
}

🔄Clear & Update Line

const { clearLine, cursorTo } = require('readline');
// each time before logging:
clearLine(process.stdout, 0);
cursorTo(process.stdout, 0);
process.stdout.write(`Uploading… ${percent}%`);

🎉Done!

When percent === 100, finish upload and exit.
