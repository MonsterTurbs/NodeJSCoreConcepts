💸Avoid Unexpected AWS Charges

When you finish using your AWS server, always terminate it through the AWS console. AWS bills by the hour for each running instance, and prices vary by server type—so stopping or terminating your server stops the hourly charges.

🔌Release Unused Elastic IPs

If you assigned an Elastic IP to your server, remember to delete or release it when you no longer need it. AWS charges a small fee for each unused Elastic IP address, so releasing them keeps your bill lower.
