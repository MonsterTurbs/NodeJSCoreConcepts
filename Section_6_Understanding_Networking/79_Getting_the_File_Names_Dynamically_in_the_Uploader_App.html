🎯Goal

Allow the client to specify any file path when running:

node client.js path/to/myfile.txt

🔢Grab Command-Line Args

  • Use process.argv array:
    • const args = process.argv;
// args[0] = full Node path
// args[1] = script path
// args[2] = your file path
const filePath = args[2];

📂Extract Filename

  • Use Node’s path.basename():
    • const path = require('path');
const fileName = path.basename(filePath);
// e.g. 'myfile.txt'

📤Client: Send Filename & File

  • First write the header:
    • socket.write(`FILENAME:${fileName}-----`);
  • Then stream file data:
    • fileStream.on('data', chunk => socket.write(chunk));

🖥️Server: Parse Header

  • On first 'data' event:
    • const divider = '-----';
const idx = data.indexOf(divider);
const fileName = data
  .subarray(divider.length, idx)
  .toString('utf8');
// now open write stream: `storage/${fileName}`
// then write data.subarray(idx + divider.length)
