🌐IP Addresses

Every device on a network needs a unique address:

  • IPv4: 32-bit, ~4 billion addresses, dotted-decimal (e.g. 192.168.0.1)
  • IPv6: 128-bit, huge space, hex notation (e.g. 2001:db8::1)

🏠Subnet & Routing

Addresses split into:

  • Network portion: which LAN you’re on
  • Host portion: which device

Routers use network bits to forward packets between LANs.

🔍DNS (Domain Name System)

Humans use names (e.g. google.com), computers use IPs. DNS servers map:

your-app.com ↔ 203.0.113.42

Lookup process:

  1. Your computer → DNS server
  2. DNS returns IP
  3. Your app connects to IP
