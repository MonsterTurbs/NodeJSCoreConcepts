📝 Study Notes: TCP/UDP Port Numbers

🔢 What Are Port Numbers?

  • 📶Ports connect the transport layer (TCP/UDP) to applications (HTTP, SSH).
  • 🎯Each port is like a “door” on a device where apps send/receive data.
  • 🔗To talk to a service, you specify both IP address and port number.

🗂️ Port Range Categories

  • 🔒System Ports: 0–1023 (require admin/root privileges).
  • 👤User Ports: 1024–49151 (safe for user apps).
  • 🔀Dynamic/Ephemeral: 49152–65535 (temporary client ports).
  • 📚The full valid range is 0–65535 on most OSes.

📖 Well-Known Ports

  • 🌐Port 80: HTTP
  • 🔒Port 443: HTTPS
  • ⚙️Port 22: SSH
  • 📧Port 25: SMTP (email)
  • 📑Many others listed in IANA registry.

See IANA Port Numbers.

🔀 TCP vs UDP on Same Port

  • 🔒TCP and UDP are separate: you can run a TCP service and a UDP service on the same port number.
  • 🚫You cannot run two TCP services on the same port or two UDP services on the same port.

✅ Picking a Port for Node.js

  • 👤Prefer ports ≥1024 to avoid needing root/admin rights.
  • ⚠️Avoid well-known ports unless you’re replacing that service (e.g., run HTTPS on 443).
  • 🔍If port in use, Node.js will error: listen EADDRINUSE.

💻 Node.js Example

const http = require('http');

// Use a user port (e.g., 3000)
const PORT = 3000;
const server = http.createServer((req, res) => {
  res.end('Hello on port ' + PORT);
});

server.listen(PORT, () => {
  console.log('Server listening on', PORT);
});

Run node app.js and navigate to http://localhost:3000.

📦 net Module Basics

  • 🛠️net.createServer() → returns net.Server; your chat server.
  • 🔗net.createConnection() → returns net.Socket; your chat client.
  • 🎉Use same module for TCP networking and IPC (Inter-Process Communication).

🔀 TCP vs. IPC in net Module

  • 🌐TCP: Servers listen on host+port.
  • ⚙️IPC: Servers listen on filesystem path (Unix socket/file pipe).
  • 💡Chat app uses TCP; IPC is for inter-process messaging on same machine.

🚀 server.js Skeleton

const net = require('net');

const server = net.createServer(socket => {
  console.log('New connection!');
  // handle incoming data via socket.on('data')
});

server.listen(3008, '127.0.0.1', () => {
  console.log('Server listening on', server.address());
});

🚀 client.js Skeleton

const net = require('net');

const client = net.createConnection({ host:'127.0.0.1', port:3008 }, () => {
  console.log('Connected to chat server!');
  // send messages via client.write(message)
});

client.on('data', data => {
  console.log('Received:', data.toString());
});

🔄 Socket = Duplex Stream

  • ↔️Every socket is a stream.Duplex—you can .write() and .on('data').
  • 📦Use socket events ('data', 'end', 'close') to manage chat messages.

🔄 Quick Recap

  • 🔧net.createServer() → net.Server
  • 🔗net.createConnection() → net.Socket
  • 🌐TCP sockets connect endpoints across networks; IPC sockets talk within the same machine.
  • 🗃️Use server.address() to get host, port, and family info.

👥 Tracking & Broadcasting

  • 📨Keep an array of all socket objects on 'connection' event:
    • const clients = [];
server.on('connection', socket => {
  clients.push(socket);
});
  • 🔊Broadcast incoming data to everyone:
    • socket.on('data', msg => {
  clients.forEach(s => s.write(msg));
});

🎤 Asking User Input

  • 🖥️Use readline/promises to ask in server console:

const rl = readline.createInterface(
  { input: process.stdin, output: process.stdout }
);
const msg = await rl.question('Enter message: ');
  • 🚀Then broadcast msg to all clients.

📦 Promisify Terminal Methods

  • 💡Convert callback-based APIs to promises for cleaner async/await:
    • function clearLine(stream, dir) {
  return new Promise(res => stream.clearLine(dir, res));
}

function moveCursor(stream, dx, dy) {
  return new Promise(res => stream.moveCursor(dx, dy, res));
}
