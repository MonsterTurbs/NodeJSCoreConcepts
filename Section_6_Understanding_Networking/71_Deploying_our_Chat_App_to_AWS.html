☁️AWS Free Tier

AWS offers a free tier for 12 months: 750 hours/month of EC2 (virtual server), 5 GB storage, and more! Great for learning without paying. 💳

🖥️Launching an EC2 Instance

  1. Go to EC2 → Launch Instance.
  2. Choose Amazon Linux (or Ubuntu).
  3. Select t2.micro (1 vCPU, 1 GB RAM) for free tier.
  4. Create/download an SSH key pair (PEM file) to log in.

📍Regions Matter

AWS is divided into regions (Ohio, California, Singapore…). Choose the region closest to your users for low latency. You can route users globally with services like Route 53 and load balancers. 🌐

🔑SSH & Key Permissions

Use your PEM key to SSH in:

chmod 400 my-key.pem
ssh -i my-key.pem ec2-user@YOUR_PUBLIC_IP

On Linux/macOS you may need chmod 400 to protect the key.

🔒Security Groups (Firewall)

A security group is like a firewall:

  • Inbound rules: which ports/IPs can connect (e.g. TCP 4020 for your chat app).
  • Outbound rules: where your server can send traffic.

For testing you might “allow all,” but in production open only needed ports!

🚀Deploy & Run Your App

  1. SSH into your EC2 instance.
  2. Install Node.js (via NVM): nvm install 16.
  3. Upload your chat-server.js code.
  4. Set HOST to the EC2 private IP and PORT you choose.
  5. Run: node chat-server.js. Your app is now live at YOUR_PUBLIC_IP:PORT!
