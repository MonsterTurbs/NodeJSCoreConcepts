📨What is UDP?

UDP stands for User Datagram Protocol. It lives in the transport layer (Layer 4) alongside TCP. Unlike TCP, UDP is connectionless—it just sends packets without setting up or tearing down a session.

🚫🔁Connectionless & Unreliable

Because it doesn’t track connections or acknowledgements, packets may arrive out of order or be lost. You must add your own checks if you need guaranteed delivery or ordering.

⚙️Using Node.js dgram

const dgram = require('dgram');
    
// Receiver
const server = dgram.createSocket('udp4');
server.on('message', (msg, rinfo) => {
  console.log(`Received "${msg}" from ${rinfo.address}:${rinfo.port}`);
});
server.bind(8000, '127.0.0.1');

// Sender
const client = dgram.createSocket('udp4');
const message = Buffer.from('Hello, UDP!');
client.send(message, 8000, '127.0.0.1', err => {
  if (err) console.error(err);
  client.close();
});

💨When to Use UDP

  • Real‐time streaming (video, voice) where speed matters more than perfect accuracy.
  • Online gaming—small packet losses are acceptable.
  • Custom high-speed protocols (e.g. QUIC/WebRTC).

📏Packet Size & Tuning

Default UDP packets max out around 64 KB. In Node you can increase the send buffer:


const sock = dgram.createSocket({
  type: 'udp4',
  sendBufferSize: 128 * 1024  // 128 KB
});

⚖️TCP vs. UDP

TCP ⇒ reliable, ordered, connection-oriented, larger headers.
UDP ⇒ faster, simpler, connection-less, smaller headers.
