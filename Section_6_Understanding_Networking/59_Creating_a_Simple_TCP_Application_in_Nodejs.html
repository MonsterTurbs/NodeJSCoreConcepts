📝 Study Notes: Networking & TCP Server in Node.js

🖥️ Simple TCP Server Setup

  • 📁Create folder networking, then file simple-server.js.
  • 📦Import module: 
    const net = require('net');
  • 🚀Make server:
    const server = net.createServer(socket => {
  socket.on('data', data => {
    console.log(data.toString('utf8'));
  });
});
server.listen(3099, '127.0.0.1', () => {
  console.log('Server listening on', server.address());
});
  • 🔗Run with node simple-server.js. It listens on port 3099 of loopback.

📨 Simple TCP Client (Sender)

  • 📦In simple-sender.js, import same module and connect:
    • const net = require('net');
const client = net.createConnection({ host:'127.0.0.1', port:3099 }, () => {
  client.write('Hello from sender!');
});
  • ▶️Run after server: node simple-sender.js. Server logs the message.
  • 🔄Socket is a duplex stream: you can socket.on('data') and socket.write().

🔍 Inspecting with Wireshark

  • 💻Open Wireshark and select interface Loopback for 127.0.0.1.
  • ⚡Run server & sender, then stop capture to view packets.
  • 📑Look for Protocol TCP and Port 3099.
  • 📊Right-click a packet > Follow > TCP Stream to see payload.
  • 🔎Expand layers: Frame > Ethernet II > Internet Protocol > TCP to view headers.

🔧 Packet Details Explained

  • 📐Frame length includes headers + data (often > payload size).
  • 📝Headers contain source/destination MAC, IP, ports, sequence numbers.
  • 📶Actual data appears under TCP payload in hex and ASCII.
  • 💡Activity Monitor shows only payload bytes, not header overhead.
