📁Project Setup

  • Create folder uploader/ inside your networking project
  • Inside, make two files:
    • server.js (the upload server)
    • client.js (reads & sends a file)

🖥️server.js: Listen for Uploads

  • Import modules: const net = require('net'), const fs = require('fs/promises')
  • Create TCP server: 
    const server = net.createServer(socket => { … })
  • On client connection:
    • Open a writeable file in uploader/storage/, e.g. test.txt
    • Create a writable stream from the file handle
    • When socket emits data, write those bytes to the file stream
    • On socket end, close file and socket
  • Start listening: 
    server.listen(5050, '::', () => {
  console.log('Uploader server on [::]:5050');
});

📤client.js: Send a File

  • Import net and fs/promises
  • Create TCP connection to ::1 on port 5050: 
    const socket = net.createConnection({ host:'::1', port:5050 }, async() => { … })
  • Inside callback:
    • Open your source file (e.g. text.txt) for reading
    • Create a readable stream from the file handle
    • On stream data, socket.write(data)
    • On stream end, socket.end() to close connection

✅Test & Verify

  • Run server: node server.js
  • Run client: node client.js
  • Check uploader/storage/test.txt—it matches original file byte-for-byte
  • Server logs connection start/end
