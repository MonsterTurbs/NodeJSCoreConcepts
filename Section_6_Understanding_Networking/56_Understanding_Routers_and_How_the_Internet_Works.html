📝 Study Notes: Basic Networking Concepts

🔍 Introduction to Networking

  • 💡Networking lets computers share information without moving disks by hand.
  • ⏳Before coding network apps, it helps to know how networks work.
  • 🌐These ideas apply in any programming language.

📼 Old-School File Sharing

  • 💾You used floppy disks or USB sticks to move files between PCs.
  • 🚶‍♂️Save to disk, walk to another computer, then load the file.
  • ✈️To share far away, you might mail or fly the disk.

🔌 Building a Simple Network

  • 📶Ethernet cables carry bits (0s and 1s) between devices.
  • 🔀A network switch forwards data to the correct computer.
  • ⚙️Switches may require simple setup (like logging in to configure).

💳 Network Interface & MAC Address

  • 🖥️Each computer has a Network Interface Card (NIC) for cable or Wi‑Fi.
  • 🔑NIC has a unique MAC address (48-bit ID in hex).
  • 🔒Switches use MAC addresses to know where to send packets.

📦 Packets & Frames

  • ✉️Data is split into packets (called frames on Ethernet).
  • 📝Each packet has:
    • Source MAC
    • Destination MAC
    • Payload (the actual data)
  • 🔄Switch reads destination MAC and sends packet to the right port.

🛣️ Routers & IP Addresses

  • 📍Routers connect multiple networks (e.g., building to building).
  • 🌍They use IP addresses instead of MACs to route packets.
  • 🏷️An IP address is like a street address: each device gets a unique one.
  • 🔀Routers know which network a device’s IP belongs to and forward data.

☁️ Internet Backbone & ISPs

  • 🛠️ISPs (Internet Service Providers) give you access to the global network.
  • 🔌You connect your home or phone via a modem/router supplied by your ISP.
  • 🌐Undersea and land cables form the Internet backbone linking continents.
  • 📲Whether wired, Wi‑Fi, or mobile (4G/5G), you get a public IP to send/receive data.
