📝 Study Notes: Networking with Node.js

🌐 What Is Networking?

  • 🔗Networking means connecting computers to send and receive data.
  • ⚙️Node.js was built to create scalable network applications easily.
  • 💡Concepts apply across languages: Go, Java, Python, and more.

🛠️ Key Node.js Modules

  • 📦net: For low‑level TCP sockets.
  • 📬dgram: For UDP datagrams.
  • 🆔dns: For DNS lookups.
  • 🔧Also use readline, process, and path for CLI UI.

💬 Chat App Demo

  • 🚀Server (`server.js`) listens for TCP connections.
  • 👥Clients (`client.js`) connect, receive an ID, and send messages.
  • 🔄Messages go from client → server → all clients, enabling real‑time chat.
  • 🌍Clients and server can be anywhere in the world via the internet.

📤 Uploader App Demo

  • 📁Client (`client.js`) reads a file and streams it to the server.
  • 💾Server (`server.js`) receives data and writes to storage/ folder.
  • 🔢Shows upload progress percentage in the console.
  • ✅Uploaded file appears intact in the storage directory.

🔍 Networking Fundamentals

  • 🔌TCP: Reliable, connection‑oriented transport.
  • 💨UDP: Fast, connectionless datagrams.
  • 🌐Protocols (HTTP, FTP, SSH) build on TCP/UDP.
  • 🎯Understanding sockets and streams is key.

🚀 Deployment

  • ☁️Use a public server (AWS, DigitalOcean, GCP) with a public IP.
  • ⚙️Copy your app files and run node server.js on that server.
  • 🌍Global clients connect via the server’s IP address and port.
  • 🔒Optional: Use firewalls and TLS for security.
