📝 Study Notes: TCP/UDP Port Numbers

🔢 What Are Port Numbers?

  • 📶Ports connect the transport layer (TCP/UDP) to applications (HTTP, SSH).
  • 🎯Each port is like a “door” on a device where apps send/receive data.
  • 🔗To talk to a service, you specify both IP address and port number.

🗂️ Port Range Categories

  • 🔒System Ports: 0–1023 (require admin/root privileges).
  • 👤User Ports: 1024–49151 (safe for user apps).
  • 🔀Dynamic/Ephemeral: 49152–65535 (temporary client ports).
  • 📚The full valid range is 0–65535 on most OSes.

📖 Well-Known Ports

  • 🌐Port 80: HTTP
  • 🔒Port 443: HTTPS
  • ⚙️Port 22: SSH
  • 📧Port 25: SMTP (email)
  • 📑Many others listed in IANA registry.

See IANA Port Numbers.

🔀 TCP vs UDP on Same Port

  • 🔒TCP and UDP are separate: you can run a TCP service and a UDP service on the same port number.
  • 🚫You cannot run two TCP services on the same port or two UDP services on the same port.

✅ Picking a Port for Node.js

  • 👤Prefer ports ≥1024 to avoid needing root/admin rights.
  • ⚠️Avoid well-known ports unless you’re replacing that service (e.g., run HTTPS on 443).
  • 🔍If port in use, Node.js will error: listen EADDRINUSE.

💻 Node.js Example

const http = require('http');

// Use a user port (e.g., 3000)
const PORT = 3000;
const server = http.createServer((req, res) => {
  res.end('Hello on port ' + PORT);
});

server.listen(PORT, () => {
  console.log('Server listening on', PORT);
});

Run node app.js and navigate to http://localhost:3000.
