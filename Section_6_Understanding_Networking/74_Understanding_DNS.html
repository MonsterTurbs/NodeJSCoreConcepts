🔍What is DNS?

DNS (Domain Name System) is like the Internet’s phone book. It converts easy-to-remember domain names (e.g. google.com) into IP addresses (e.g. 142.250.64.110) so your browser can connect to the right server.

📡How DNS Lookup Works

  1. Your browser asks your configured DNS server “What’s the IP for example.com?”
  2. DNS server checks its table and replies with the IP address.
  3. Your computer then connects to that IP to load the website.

⚙️Your Local Hosts File

You can override DNS on your own machine by editing /etc/hosts (Mac/Linux) or C:\Windows\System32\drivers\etc\hosts (Windows). Example entry:

127.0.0.1   mysite.local

This makes mysite.local point to your own computer.

💻Node.js DNS Lookup Example

import { promises as dns } from 'dns';

(async () => {
  const { address } = await dns.lookup('google.com');
  console.log('Google IP →', address);
})();

Save as simple-dns.js and run node simple-dns.js.

🔧Building Your Own DNS

You can write a custom DNS server in Node.js using the net (TCP) or dgram (UDP) modules. It listens on port 53, parses queries, and returns IP records from your own table.

🚨DNS Security Warning

  • Rogue DNS: Malware or attackers can hijack your DNS settings to redirect you to fake sites.
  • Be cautious: Always use trusted DNS servers (ISP, Google DNS 8.8.8.8, Cloudflare 1.1.1.1).

🌍Why Use Domain Names?

  • Friendly and memorable compared to numeric IPs.
  • Enables load balancing: one domain → many IPs behind the scenes.
  • Easy to reassign: changing a site’s IP only requires DNS update, not reissuing URLs.
