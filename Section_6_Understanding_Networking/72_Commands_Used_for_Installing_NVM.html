💻How to Install nvm on Amazon Linux 2

💡 nvm lets you install and switch Node.js versions easily.

Follow these steps:

  1. Install nvm script via curl: 
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.34.0/install.sh | bash
  2. Activate nvm in your shell: 
    . ~/.nvm/nvm.sh
  3. Install Node.js v16 (or any version you need): 
    nvm install 16

🔗 Script source: github.com/nvm-sh/nvm

⚙️ On Ubuntu: You may need to sudo apt install curl first.
