🔒Security Reminder

Plain TCP is unencrypted—anyone sniffing the network can read your files. In production, wrap traffic in TLS (Node’s built-in tls module) to get secure upload (like HTTPS).

🚀Deploying Your Uploader

  1. SSH into your server: ssh -i key.pem user@host
  2. Upload uploader.js and make storage/ folder
  3. Install PM2: npm install -g pm2
  4. Start app: pm2 start uploader.js

📤Uploading to Remote

On your client machine, run:

node client.js <path/to/your-file>

Example:

node client.js ./video.mp4

📂Verify on Server

  1. SSH back in and list storage/.
  2. Check file size: ls -l storage/<filename>.
  3. Download via SCP to compare:
    4. scp -i key.pem user@host:storage/video.mp4 ./downloaded.mp4

🎉Success!

You can reliably upload large files (text, images, video) from any machine to your Node.js server—no data loss or corruption. 😄
