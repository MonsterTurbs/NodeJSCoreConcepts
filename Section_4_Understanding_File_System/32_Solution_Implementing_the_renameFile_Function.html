📝 Beginner-Friendly Study Notes: “Rename File” Command

🔄 What Is fs.rename?

  • ❓fs.rename(oldPath, newPath) is a Node.js Promise-based function from fs/promises that renames (or moves) a file.
  • 📂If you give it two paths, it changes the file’s name from oldPath to newPath.
  • 🚚You can also “move” a file into another folder by specifying a folder path in newPath.

🛠️ Step: Basic Rename Syntax

  • 📋Use await fs.rename(oldPath, newPath) inside an async function.
  • 🖋️For example: 
    async function renameFile(oldPath, newPath) {
  await fs.rename(oldPath, newPath);
  console.log(`✅ File renamed from ${oldPath} to ${newPath}`);
}
  • 🚀That changes the file’s name or location in one step.

⚠️ Step: Use try…catch for Errors

  • 🔍If oldPath doesn’t exist or newPath is invalid, fs.rename throws an error.
  • 🛡️Wrap the call in try…catch to handle those errors gracefully:
  • async function renameFile(oldPath, newPath) {
  try {
    await fs.rename(oldPath, newPath);
    console.log(`✅ File renamed from ${oldPath} to ${newPath}`);
  } catch (e) {
    if (e.code === 'ENOENT') {
      console.log(`⚠️ No file or directory at this path: ${oldPath}`);
    } else {
      console.error(`❌ Error renaming file: ${oldPath} → ${newPath}`, e);
    }
  }
}
  • 👍This way, if the source file is missing or the destination folder doesn’t exist, you log a friendly message instead of crashing.

📂 Renaming vs. Moving Files

  • 📌If newPath is in the same folder but with a different name, you’re simply renaming.
  • 🚚If newPath contains a different directory (for example, 'dir/newname.txt'), you’re moving the file into that folder.
  • ❗️If the folder in newPath does not exist, fs.rename throws an ENOENT error. You must create that folder first or catch and report the error.

✏️ Example: Rename in Current Folder

  • 📝Assume you have file.txt in your app’s folder and want to rename it to file-renamed.txt:
  • // In your main handler after reading command.txt:
await renameFile('file.txt', 'file-renamed.txt');
// Logs “✅ File renamed from file.txt to file-renamed.txt”
  • 🎉After running this, check your folder: file.txt no longer exists, and file-renamed.txt is there.

🚀 Example: Move to a Different Folder

  • 📂Create (or ensure) a folder named dir in your project:
  • ➡️Then rename (move) file-renamed.txt into that folder:
  • await renameFile('file-renamed.txt', 'dir/file-renamed.txt');
// Logs “✅ File renamed from file-renamed.txt to dir/file-renamed.txt”
  • 👍If dir doesn’t exist, you’d see “⚠️ No file or directory at this path: file-renamed.txt” or “destination doesn’t exist.”

❗️ Common Errors & Friendly Messages

  • 🔍ENOENT: Means “Error NO ENTry” (no file or directory). You catch this to say “No file at this path to rename.”
  • ✨If newPath parent folder is missing, fs.rename also throws ENOENT. Your message could be “Destination folder doesn’t exist.”
  • 🔒Any other error (permissions, invalid characters) you catch and log as “Error renaming file” with the error object for debugging.

🔗 Putting It All Together

  • 📋Here’s the final renameFile function: 
    const fs = require('fs/promises');

async function renameFile(oldPath, newPath) {
  try {
    await fs.rename(oldPath, newPath);
    console.log(`✅ File renamed from ${oldPath} to ${newPath}`);
  } catch (e) {
    if (e.code === 'ENOENT') {
      console.log(`⚠️ No file or directory at this path: ${oldPath} (or destination folder missing)`);
    } else {
      console.error(`❌ Error renaming file: ${oldPath} → ${newPath}`, e);
    }
  }
}
  • 🎉Use this in your main watcher logic when you detect “rename a file” command, passing the two paths you extracted.

💡 Why This Matters

  • 📚You learn how to call a Promise-based filesystem function (fs.rename) and handle asynchronous code in Node.js using async/await.
  • 🛡️Error handling with try…catch teaches you to write robust code that won’t crash when files or folders are missing.
  • 🚀Moving files between folders introduces the concept of file paths, absolute vs. relative, and the importance of ensuring target folders exist.
