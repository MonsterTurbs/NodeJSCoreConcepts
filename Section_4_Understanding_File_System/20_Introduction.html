📝 Files in Node.js – Study Notes

📂 What Is a File?

  • 💾A file is a collection of data—text, images, video—stored on disk or other storage.
  • 🖥️In the operating system, files are just fixed‐length “blocks of bytes.”
  • 🔍When Node.js reads or writes a file, it handles these raw bytes (0s and 1s) in your program.

📖 Simple Example: Read a File

  • 📝Create a folder named app. Inside it, make app.js and Text.txt.
  • ✍️Put some random text in Text.txt (e.g., “Hello, world!”).
  • 💻In app.js, write:
const fs = require('fs');

const contents = fs.readFileSync('Text.txt');
console.log(contents);
  • ▶️Run node app.js in your terminal.
  • 🔢You’ll see a Buffer (raw bytes) printed out.

🔢 Understanding the Buffer Output

  • 🔍The contents variable is a Buffer: a sequence of raw bytes (0s and 1s) shown in hexadecimal.
  • 🔡Each byte (8 bits) can represent a character (especially if it’s ASCII text).
  • 💡To read it as human‐readable text, we must convert it with a character encoding.

🔄 Buffer → String (UTF-8)

  • 🛠️Use toString('utf8') to convert the Buffer into text:
const contents = fs.readFileSync('Text.txt');
console.log(contents.toString('utf8'));
  • 😊Now you’ll see the actual text inside Text.txt.
  • 🔤UTF-8 is the default encoding that covers ASCII, so each ASCII character uses exactly one byte.

🔤 ASCII & UTF-8 Basics

  • 🇺🇸ASCII: American Standard that defines 128 characters (A–Z, a–z, 0–9, punctuation)."
  • 🔢In ASCII, each character is 1 byte (8 bits). Example: 'A' = 65 (decimal), 'a' = 97 (decimal).
  • 🌐UTF-8: A global encoding supporting many languages and symbols.
  • 🔗UTF-8 is backward‐compatible with ASCII—ASCII characters still occupy exactly one byte in UTF-8.

👀 Demo: Automatic File‐Watcher App

  • 📁Create a file named command.txt inside the app folder.
  • 🔧The app will watch command.txt and execute commands written there (create, delete, rename, add).
  • 💻In app.js, write code like:
const fs = require('fs');

// Start watching 'command.txt'
fs.watchFile('command.txt', () => {
  const cmds = fs.readFileSync('command.txt')
    .toString('utf8')
    .trim()
    .split('\n');
  for (const line of cmds) {
    const [action, ...args] = line.split(' ');
    switch (action) {
      case 'create':
        fs.writeFileSync(args[0], '');
        console.log('✅ Created:', args[0]);
        break;
      case 'delete':
        if (fs.existsSync(args[0])) {
          fs.unlinkSync(args[0]);
          console.log('❌ Deleted:', args[0]);
        }
        break;
      case 'rename':
        fs.renameSync(args[0], args[1]);
        console.log('✏️ Renamed:', args[0], '→', args[1]);
        break;
      case 'add':
        fs.appendFileSync(args[0], args.slice(1).join(' ') + '\n');
        console.log('➕ Added to', args[0]);
        break;
      default:
        console.log('⚠️ Unknown command:', action);
    }
  }
});
  • ▶️Run the app: node app.js (it keeps running, watching the file).
  • 🖊️Edit command.txt with commands like:
create /Users/You/Desktop/app/newfile.txt
add /Users/You/Desktop/app/newfile.txt Hello, Node.js!
rename /Users/You/Desktop/app/newfile.txt /Users/You/Desktop/app/renamed.txt
delete /Users/You/Desktop/app/renamed.txt
  • 🚀You’ll see the file get created, text added, renamed, and deleted automatically.

💡 Why Learn File Handling?

  • 📑Many web/server apps read or write files (configs, logs, user uploads).
  • 🔄Understanding OS file mechanics helps you use Node’s fs module effectively.
  • ⚙️You’ll learn both synchronous (blocking) and asynchronous (non‐blocking) methods.
  • 🔐Proper file handling reduces bugs and security issues in your app.
