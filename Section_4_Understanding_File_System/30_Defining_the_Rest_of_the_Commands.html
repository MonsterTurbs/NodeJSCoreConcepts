📝 Beginner-Friendly Study Notes: Defining Additional Commands

📋 Overview

  • 🎯We already implemented “create a file.” Now we define 3 more commands: “delete a file,” “rename a file,” and “add to the file.”
  • 🛠️In this lesson, we set up the checks (if statements) and placeholders for each function. Actual implementation is a challenge for you to complete.
  • 🚀By the end, you’ll have basic code that recognizes these 3 commands and calls the right functions with the correct arguments.

🔤 Step 1: List Your Command Phrases

  • ✏️At the top of your code, define each command string: 
    const createFileCmd = "create a file";
const deleteFileCmd = "delete a file";
const renameFileCmd = "rename a file";
const addToFileCmd = "add to the file";
  • 🔍These variables store the exact phrase to look for in command.txt.
  • ✅Using variables avoids repeating the literal string in multiple places and reduces typos.

🗑️ Step 2: Check for “Delete a File” and Get Its Path

  • 🔎When you read command.txt, check: 
    if (command.includes(deleteFileCmd)) {
  // 1) Find where “delete a file” ends
  const startIndex = command.indexOf(deleteFileCmd) + deleteFileCmd.length + 1;
  // 2) Extract everything after that as the path
  const filePath = command.substring(startIndex).trim();
  deleteFile(filePath);
}
  • 📏Explanation:
    • command.includes(deleteFileCmd) → true if phrase is present.
    • command.indexOf(...) + deleteFileCmd.length + 1 → position right after “delete a file ” (including space).
    • substring(startIndex) → takes from that position to the end, giving the file path.
  • 🚨Now call deleteFile(filePath) to handle removing the file.

🔄 Step 4: Check for “Rename a File” and Extract Paths

  • 🔎Check if the command includes the phrase: 
    if (command.includes(renameFileCmd)) {
  // 1) Find where “rename a file” ends
  const partsIndex = command.indexOf(" to ");
  // 2) Old path is the text between “rename a file ” and “ to ”
  const oldPathStart = command.indexOf(renameFileCmd) + renameFileCmd.length + 1;
  const oldPath = command.substring(oldPathStart, partsIndex).trim();
  // 3) New path is everything after “ to ”
  const newPath = command.substring(partsIndex + 4).trim();
  renameFile(oldPath, newPath);
}
  • 📏Explanation:
    • partsIndex = command.indexOf(" to ") finds where the “ to ” (with spaces) occurs.
    • oldPath = substring(from end of “rename a file ” up to partsIndex).
    • newPath = substring(partsIndex + 4) skips over “ to ” (3 letters + 1 space).
  • 🚨Call renameFile(oldPath, newPath) to handle renaming.

✍️ Step 6: Check for “Add to the File” and Extract Path & Text

  • 🔎Check the command: 
    if (command.includes(addToFileCmd)) {
  // 1) Find where “add to the file” ends
  const contentIndex = command.indexOf(" content ");
  // 2) File path is between end of phrase and “ content ”
  const pathStart = command.indexOf(addToFileCmd) + addToFileCmd.length + 1;
  const filePath = command.substring(pathStart, contentIndex).trim();
  // 3) Text content is everything after “ content ”
  const textStart = contentIndex + " content ".length;
  const contentText = command.substring(textStart).trim();
  addToFile(filePath, contentText);
}
  • 📏Explanation:
    • contentIndex = command.indexOf(" content ") finds where “ content ” occurs (with spaces).
    • filePath = substring(from end of “add to the file ” up to contentIndex).
    • contentText = substring(contentIndex + length of “ content ”) → the actual text to append.
  • 🚨Call addToFile(filePath, contentText) to handle appending.

🔗 Step 8: Full if-Statement Structure

  • 📋Inside your main handler (after you read command), include: 
    // 1) Create File
if (command.includes(createFileCmd)) {
  const filePath = command.substring(
    command.indexOf(createFileCmd) + createFileCmd.length + 1
  ).trim();
  createFile(filePath);
}

// 2) Delete File
else if (command.includes(deleteFileCmd)) {
  const filePath = command.substring(
    command.indexOf(deleteFileCmd) + deleteFileCmd.length + 1
  ).trim();
  deleteFile(filePath);
}

// 3) Rename File (using “ to ”)
else if (command.includes(renameFileCmd)) {
  const partsIndex = command.indexOf(" to ");
  const oldPathStart = command.indexOf(renameFileCmd) + renameFileCmd.length + 1;
  const oldPath = command.substring(oldPathStart, partsIndex).trim();
  const newPath = command.substring(partsIndex + 4).trim();
  renameFile(oldPath, newPath);
}

// 4) Add to File (using “ content ”)
else if (command.includes(addToFileCmd)) {
  const contentIndex = command.indexOf(" content ");
  const pathStart = command.indexOf(addToFileCmd) + addToFileCmd.length + 1;
  const filePath = command.substring(pathStart, contentIndex).trim();
  const textStart = contentIndex + " content ".length;
  const contentText = command.substring(textStart).trim();
  addToFile(filePath, contentText);
}
  • ✅Make sure you use else if so that only one command runs per save of command.txt.
  • 🔍If none of these phrases match, simply do nothing (or log “Command not recognized”).

🏆 Step 9: Your Challenge

  • 💡Now that you have placeholders, it’s time to write the actual code for each function:
    • deleteFile(path) – Use fs.unlink(path) (or fs.open + fs.unlink) to delete the file. If the file doesn’t exist, log “File not found.”
    • renameFile(oldPath, newPath) – Use fs.rename(oldPath, newPath) so the file gets its name changed. Handle errors if oldPath is missing.
    • addToFile(path, text) – Use fs.appendFile(path, text) to add the given text. If path doesn’t exist, log “Cannot add to non-existent file.”
  • ⏳Spend 10–30 minutes trying each one. Look up the Node.js documentation for fs.unlink, fs.rename, and fs.appendFile if you need help.
  • 🎉When you’re done, test each command by editing command.txt and saving:
    • delete a file /path/to/yourfile.txt
    • rename a file /path/oldname.txt to /path/newname.txt
    • add to the file /path/notes.txt content Hello, world!
