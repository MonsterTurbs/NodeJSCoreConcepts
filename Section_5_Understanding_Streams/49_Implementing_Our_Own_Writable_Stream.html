📝 Study Notes: Implementing a Custom Writable Stream

⚙️ Why Create a Custom Writable Stream?

  • 🔍Built‐in streams (like fs.createWriteStream) are convenient, but you may need extra control over how data is buffered or written.
  • ✏️By extending Node’s Writable class, you decide:
    • • When & how chunks are buffered
    • • When to flush all buffered chunks to the underlying resource
    • • Custom error handling and cleanup logic
  • 📚This example builds a writable stream that gathers chunks in memory until a high‐watermark threshold, then writes them as one block to a file.

➕ Including & Extending Writable

  • 📦Import Node’s Writable base class: 
    const { Writable } = require('stream');
  • 🏷️Define your own class that extends Writable: 
    class FileWriteStream extends Writable {
  constructor(options) {
    super(options);
    // … custom setup here …
  }
  // … must implement _write & _final & _destroy …
}
  • 🔄Inside the subclass’s constructor, call super() to invoke the base class’s constructor:
    • super({ highWaterMark: options.highWaterMark });
  • 📝Keep track of custom options (e.g., output filename, buffer array, current buffer size):
    • this.fileName      = options.fileName;
this.chunks        = [];
this.chunksSize    = 0;
this.writeCount    = 0;

🔧 Asynchronous Setup: _construct()

  • ⏳Optionally implement _construct(callback) if you need async setup (e.g., opening a file descriptor).
    • _construct(cb) {
  fs.open(this.fileName, 'w', (err, fd) => {
    if (err) return cb(err);
    this.fd = fd;           // Save file descriptor
    cb();                   // Signal “ready to write”
  });
}
  • 📁Until cb() is called, _write() won’t run. If you pass an error to cb(err), the stream errors out immediately.

✍️ Implementing _write(chunk, encoding, callback)

  • 📥Signature: 
    _write(chunk, encoding, callback) {
  // 1. Buffer the incoming chunk
  // 2. If total buffer size > highWaterMark → flush to file
  // 3. Otherwise, just callback()
}
  • ➕Each time Node calls _write, you receive:
    • • chunk: a Buffer (or string if encoding is specified)
    • • encoding: character encoding (usually irrelevant for raw Buffers)
    • • callback: invoke this when you’re done (either with callback() or callback(err))
  • 🗄️Append each chunk to an in-memory array and track the combined size: 
    this.chunks.push(chunk);
this.chunksSize += chunk.length;
  • 🔄When this.chunksSize > highWaterMark:
    • • 🔗Concatenate buffered chunks into one buffer:
      • const toWrite = Buffer.concat(this.chunks);
    • • 📂Use fs.write(fd, toWrite, …) to write them at once:
      • fs.write(this.fd, toWrite, 0, toWrite.length, (err) => {
  if (err) return callback(err);
  this.chunks = [];
  this.chunksSize = 0;
  this.writeCount++;
  callback();
});
  • ✔️Otherwise (buffer still below threshold), simply callback() to let Node know you’re ready for the next chunk.

🛑 Final Flush: _final(callback)

  • 🏁Once stream.end() is called by the user, Node invokes _final():
    • _final(callback) {
  // 1. Write any leftover buffered chunks 
  // 2. Reset buffer & size, then callback()
}
  • 📥If this.chunks.length > 0:
    • const lastBuf = Buffer.concat(this.chunks);
fs.write(this.fd, lastBuf, 0, lastBuf.length, (err) => {
  if (err) return callback(err);
  this.chunks = [];
  this.chunksSize = 0;
  callback();
});
  • 🔚After callback() in _final, Node emits a 'finish' event on the writable stream.

🧹 Cleanup: _destroy(err, callback)

  • ⚠️Method signature: 
    _destroy(error, callback) {
  // 1. If needed, log or handle the incoming error
  // 2. Close file descriptor
  // 3. Invoke callback(errOrNull)
}
  • 🚪Close the file descriptor (if open) inside fs.close:
    • if (this.fd) {
  fs.close(this.fd, (closeErr) => {
    callback(closeErr || error);
  });
} else {
  callback(error);
}
  • 🛡️If an error occurred earlier (passed into _destroy), pass it to callback(error). Otherwise, pass any closeErr.
  • 👀Always call callback() (with either error or null) so Node knows cleanup is done.

📦 Full Custom Writable Stream Class

const fs = require('fs');
const { Writable } = require('stream');

class FileWriteStream extends Writable {
  constructor({ fileName, highWaterMark = 16 * 1024 }) {
    super({ highWaterMark });
    this.fileName    = fileName;
    this.chunks      = [];
    this.chunksSize  = 0;
    this.writeCount  = 0;
    this.fd          = null; // file descriptor
  }

  // 1. Async setup: open the file before writing
  _construct(callback) {
    fs.open(this.fileName, 'w', (err, fd) => {
      if (err) return callback(err);
      this.fd = fd;
      callback();
    });
  }

  // 2. Buffer or flush when highWaterMark exceeded
  _write(chunk, encoding, callback) {
    this.chunks.push(chunk);
    this.chunksSize += chunk.length;

    if (this.chunksSize > this.writableHighWaterMark) {
      const toWrite = Buffer.concat(this.chunks);
      fs.write(this.fd, toWrite, 0, toWrite.length, (err) => {
        if (err) return callback(err);
        this.chunks = [];
        this.chunksSize = 0;
        this.writeCount++;
        callback();
      });
    } else {
      callback();
    }
  }

  // 3. Final flush any leftover buffer
  _final(callback) {
    if (this.chunks.length > 0) {
      const lastBuf = Buffer.concat(this.chunks);
      fs.write(this.fd, lastBuf, 0, lastBuf.length, (err) => {
        if (err) return callback(err);
        this.chunks = [];
        this.chunksSize = 0;
        callback();
      });
    } else {
      callback();
    }
  }

  // 4. Cleanup: close file descriptor
  _destroy(err, callback) {
    if (this.fd) {
      fs.close(this.fd, (closeErr) => {
        callback(closeErr || err);
      });
    } else {
      callback(err);
    }
  }
}

// Export or use directly
module.exports = FileWriteStream;

🚀 Using FileWriteStream to Write Millions of Lines

  • 📂Example script writes numbers 0…N–1 into test.txt efficiently:
    • const fsPromises   = require('fs').promises;
const FileWriteStream = require('./FileWriteStream');

(async () => {
  const N = 1_000_000;
  const stream = new FileWriteStream({ fileName: 'test.txt' });

  console.time('writeTime');
  // Write lines 0 … N–1, each followed by a space
  for (let i = 0; i < N; i++) {
    if (!stream.write(Buffer.from(i.toString() + ' '))) {
      // Backpressure: wait for 'drain'
      await new Promise((res) => stream.once('drain', res));
    }
  }
  stream.end(); // Triggers _final and then 'finish'
  stream.on('finish', () => {
    console.log('Number of flushes:', stream.writeCount);
    console.timeEnd('writeTime'); // e.g. ~2.7s on 10M writes
  });
})();
  • ⚙️Key points:
    • • Backpressure: .write() returns false when buffer is full; await 'drain' before continuing.
    • • High‐watermark: default is 16 KB. Can pass custom value (e.g. 16 * 1024).
    • • Flush count: writeCount shows how many times buffer was flushed to disk.

📌 Best Practices & Key Takeaways

  • ⚠️Never manually call or overwrite internal methods like _write or emit events yourself—follow Node’s documented hooks.
  • 🔔Always call callback() (or callback(err)) inside _write, _final, _destroy so Node can manage state & backpressure.
  • 🛡️Error Handling: If any filesystem call errors, pass the err to callback(err), and Node will emit 'error' on your stream.
  • 💨Backpressure: If .write() returns false, await the 'drain' event before writing more to avoid unbounded memory usage.
  • 🔍Implement _construct for any async setup (e.g. opening/locking resources). The stream will wait until cb() is called.
  • 🏁Use _final() to handle the last buffered data when .end() is invoked. Then Node emits 'finish'.
  • 🧹Implement _destroy(err, cb) to clean up resources (close file descriptors). Ensure cb() is always called.
  • 📚Reading Node’s stream docs thoroughly helps you avoid pitfalls and follow built‐in conventions.
