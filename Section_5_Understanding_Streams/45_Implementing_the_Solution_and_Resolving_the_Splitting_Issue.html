📝 Study Notes: Handling Partial Numbers & Even Filter

📋 Problem Recap & Goal

  • 🔍We read a large file of consecutive numbers (e.g., “0 1 2 … 999999”) using a Readable Stream.
  • ✂️Numbers arrive in fixed‐size chunks (buffers). A multi‐digit number may be split across two chunks, leaving incomplete fragments.
  • 🎯Objective: Extract only even numbers (or numbers divisible by 10, etc.) into a new file, handling any partial splits correctly and avoiding memory overuse.

🔍 Detecting Split Numbers

  • ❗After splitting a chunk’s text on two spaces, the first and last array elements may be partial numbers.
  • 🔢To detect a split at the end of numbers array: 
    let lastStr = numbers[numbers.length - 1];
let prevStr = numbers[numbers.length - 2];
if (Number(lastStr) !== Number(prevStr) + 1) {
  // this means the last element is incomplete (split)
  • 🔪Use pop() to remove that incomplete tail and store it in split for the next chunk: 
    split = numbers.pop();

🔗 Stitching First Element

  • 🧵On the next chunk, prepend split from previous chunk to its first element: 
    let firstStr = numbers[0];
if (split) {
  numbers[0] = (split + firstStr).trim();
}
  • 🛠️Trimming extra spaces helps avoid any leading/trailing whitespace issues: 
    numbers[0] = (split + firstStr).trim();
  • ✔️Now that stitched string is a full number again, ready for numeric checks.

🔢 Filtering Even Numbers

  • 1️⃣Convert each string in numbers to a Number: 
    let n = Number(str);
  • 2️⃣Check evenness (n % 2 === 0). If true, write it out: 
    if (n % 2 === 0) {
  if (!writeStream.write(str + '  ')) {
    readStream.pause(); // handle backpressure
  }
}
  • 3️⃣If write() returns false, pause the read stream and wait for 'drain' before resuming: 
    writeStream.on('drain', () => {
  readStream.resume();
});

📦 Final Leftover & Stream End

  • 🔚On 'end' of readStream, handle any remaining split (last fragment): 
    readStream.on('end', () => {
  if (split) {
    let lastNum = Number(split);
    if (!isNaN(lastNum) && lastNum % 2 === 0) {
      writeStream.write(split);
    }
  }
  writeStream.end();
});
  • ✅Once writeStream.end() is called, the 'finish' event indicates completion and you can time/close the handle.

💻 Full Code Example

const fs = require('fs/promises');

(async () => {
  // Open files and create streams
  const readHandle = await fs.open('textSmall.txt', 'r');
  const readStream = readHandle.createReadStream();
  const writeHandle = await fs.open('dest.txt', 'w');
  const writeStream = writeHandle.createWriteStream();

  let split = ''; // leftover from previous chunk

  console.time('readFilter');
  readStream.on('data', (chunk) => {
    // 1. Prepend leftover, convert to string
    let text = split + chunk.toString('utf8');
    // 2. Split by two spaces
    let numbers = text.split('  ');
    // 3. Detect and remove incomplete tail
    let lastStr = numbers[numbers.length - 1];
    let prevStr = numbers[numbers.length - 2];
    if (Number(lastStr) !== Number(prevStr) + 1) {
      split = numbers.pop();
    } else {
      split = '';
    }
    // 4. Stitch first element if leftover exists
    if (split && numbers.length > 0) {
      numbers[0] = (split + numbers[0]).trim();
      split = '';
    }
    // 5. Loop over complete numbers, write even ones
    for (let str of numbers) {
      let n = Number(str);
      if (!isNaN(n) && n % 2 === 0) {
        if (!writeStream.write(str + '  ')) {
          readStream.pause();
        }
      }
    }
  });

  // 6. Resume on drain
  writeStream.on('drain', () => {
    readStream.resume();
  });

  // 7. Handle end of read stream
  readStream.on('end', () => {
    if (split) {
      let lastNum = Number(split);
      if (!isNaN(lastNum) && lastNum % 2 === 0) {
        writeStream.write(split);
      }
    }
    writeStream.end();
  });

  // 8. On finish, stop timer and close handles
  writeStream.on('finish', async () => {
    console.timeEnd('readFilter');
    await readHandle.close();
    await writeHandle.close();
  });
})();

🔑 Key Steps & Tips

  • 🧩Always carry the last fragment (split) between chunks.
  • ✂️Use pop() to remove incomplete tail when split occurs.
  • 🔗Stitch split + numbers[0] before converting to Number.
  • ⚖️Convert each string to Number(str) before checking evenness (n % 2 === 0).
  • ⚠️On write() returning false, call readStream.pause() and wait for 'drain' before resume().
  • ✅Handle final leftover in 'end' event, then call writeStream.end() to emit 'finish'.
