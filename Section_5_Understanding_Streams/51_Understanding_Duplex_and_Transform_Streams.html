📝 Study Notes: Duplex & Transform Streams

📦 What is a Duplex Stream?

  • 🔀A duplex stream can read and write data independently.
  • 🛠️It has two internal buffers: one for readable data and one for writable data.
  • ⚙️You implement _read() for reading and _write() for writing.

🔍 Key Duplex Concepts

  • 📚No multiple inheritance in JavaScript, so Node provides Duplex class.
  • 🔒Readable and writable parts are totally separate—it can read from one source and write to another.
  • 🔄Example: Read from read.txt and write to write.txt, or even different destinations like network sockets.

✏️ Implementing a Custom Duplex

  • 📥_construct(cb): Open both read and write file descriptors before use.
  • 📤_write(chunk, encoding, cb): Append incoming chunks to writable buffer.
  • 📥_read(size): Pull data from readable buffer and push() to consumer.
  • 🧹_destroy(err, cb): Clean up resources (e.g., close files) and call callback.

🚀 Using Your Duplex Stream

  • ⚡Create instance: new DuplexStream({ readFile, writeFile, readableHighWaterMark, writableHighWaterMark }).
  • 🖊️Write: duplex.write(Buffer.from("hello")) and end with duplex.end().
  • 👂Read: duplex.on('data', chunk => console.log(chunk.toString())).
  • 🔄Readable and writable operations run in parallel.

🔄 Transform Streams

  • 🔧A transform stream extends Duplex, piping its write data into its read buffer.
  • 🔄You implement _transform(chunk, encoding, cb) to modify data.
  • 💡Common use: encryption, compression, or simple pass-through (PassThrough).

📌 Best Practices

  • ⚠️Only implement underscored methods: _construct, _read, _write, _transform, _destroy.
  • 🛡️Always call callbacks: cb() or cb(err) to avoid hanging streams.
  • 📚Use Node’s built-in streams unless you need deep customization.
  • 🚀Explore Duplex and Transform for advanced scenarios like protocol parsing.
