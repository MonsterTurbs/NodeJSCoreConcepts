📝 Study Notes: Streams Recap & Object Mode

🔄 Streams Quick Recap

  • 📥Streams let you process data piece by piece, not all at once.
  • 📤Types: Readable, Writable, Duplex, Transform.
  • ⚙️Key methods: _read(), _write(), _transform(), _construct(), _destroy().

📦 What Is Object Mode?

  • 🔧Object mode streams move JavaScript objects instead of binary buffers.
  • 📊Useful for large datasets like big JSON arrays or database records.
  • ⚠️Standard streams handle Buffer data; object mode handles any JS value.

🔛 Enabling Object Mode

  • ⚙️When creating a stream, set objectMode: true in options:
    • new Readable({ objectMode: true, ... })
new Transform({ objectMode: true, ... })
  • 📈HighWaterMark changes: default is 16 objects (not bytes).

🛠️ Example: Stream of Objects

const { Readable } = require('stream');

class ObjectStream extends Readable {
  constructor(items) {
    super({ objectMode: true });
    this.items = items;
    this.index = 0;
  }

  _read() {
    if (this.index < this.items.length) {
      this.push(this.items[this.index++]);
    } else {
      this.push(null);
    }
  }
}

// Usage:
const objs = [ {id:1}, {id:2}, {id:3} ];
const objStream = new ObjectStream(objs);
objStream.on('data', obj => console.log(obj));
objStream.on('end', () => console.log('Done!'));

📌 Key Points & Tips

  • ✔️Object mode streams behave just like normal streams but handle JS values.
  • 🔄You can pipe object streams into Transform streams that modify objects.
  • 🚀Great for processing database rows, API responses, or any large lists.
  • 📚Always check event names: 'data', 'end', 'error'.
