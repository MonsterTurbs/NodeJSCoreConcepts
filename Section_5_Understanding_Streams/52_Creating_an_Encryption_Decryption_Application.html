📝 Study Notes: Encrypt & Decrypt with Transform Streams

🔐 What Is Encryption & Decryption?

  • ✏️Encryption: Converting readable data into a code that hides its meaning.
  • 🔓Decryption: Reversing encryption to get the original data back.
  • 💾Both use binary data (0s and 1s) like many other operations (compression, encoding).

🔄 Transform Stream for Encryption

  • 🛠️Transforms data as it passes through: reads, modifies, then outputs.
  • 📥Implement _transform(chunk, encoding, cb) to encrypt or decrypt chunk.
  • ➡️Write to stream: transform.write(data); Read from stream: transform.on('data', ...).

🖊️ Example: Simple Cipher

  • 🔑Choose a key (e.g., shift number for Caesar cipher).
  • 📄In _transform, convert chunk to string, shift characters by key, then push().
  • 📜For decryption, reverse the shift by using negative key.
const { Transform } = require('stream');

class CaesarCipher extends Transform {
  constructor(shift) {
    super();
    this.shift = shift;
  }

  _transform(chunk, encoding, callback) {
    const input = chunk.toString();
    let output = '';
    for (let char of input) {
      // Shift only letters
      const code = char.charCodeAt(0);
      // Example for lowercase
      if (code >= 97 && code <= 122) {
        const shifted = ((code - 97 + this.shift) % 26) + 97;
        output += String.fromCharCode(shifted);
      } else {
        output += char;
      }
    }
    this.push(output);
    callback();
  }
}

🚀 Using the Cipher Stream

  • ⚡Create: const cipher = new CaesarCipher(3);
  • 🖊️Encrypt: cipher.write('hello'); cipher.end();
  • 👂Read result: cipher.on('data', data => console.log(data.toString()));

📌 Best Practices

  • ⚠️Always call callback() or callback(err) in _transform.
  • 🛡️Handle binary data carefully: use Buffer if needed instead of string.
  • 🔒Use real encryption libraries (e.g., crypto module) for production security.
  • 📚Learn about streams events: 'data', 'end', 'error', 'finish'.
