📝 Study Notes: Node.js Writable Streams API

📖 Overview of Writable Streams

  • 🔍A Writable Stream is an object you can send data to, such as writing to a file or sending an HTTP response.
  • 🌐Many Node.js modules use writable streams under the hood: fs.createWriteStream(), HTTP responses, TCP sockets, cryptography, child‐process stdio, and more.
  • 💡After you call stream.end(), no more write() calls are allowed.

📋 Important Events on Writable Streams

  • 🔒‘close’: Emitted when the stream and its underlying resource (e.g., file descriptor) have closed.
    • Example: stream.on('close', () => console.log('Stream closed'));
  • 💧‘drain’: Emitted when the internal buffer empties after write() returned false.
    • Use this to resume writing: 
      if (!stream.write(chunk)) {
  stream.once('drain', () => continueWriting());
}
  • ❗‘error’: Emitted if the stream or underlying resource errors. Always listen to avoid crashes.
    • Example: stream.on('error', err => console.error(err));
  • 🏁‘finish’: Emitted after stream.end() is called and all buffered data has been flushed.
    • Good place to stop timers and close file handles.
  • 🚰‘pipe’: Emitted when a readable stream is piped into this writable stream. Useful when chaining streams.
    • Example: readable.pipe(writable).on('pipe', src => console.log('Piped from', src));
  • 🛠️‘cork’ & ‘uncork’:
    • Calling stream.cork() buffers all write() calls in memory (no actual writes until uncork()).
    • Then stream.uncork() flushes all buffered data in one go—useful when writing many small chunks rapidly.
  • 💥‘destroy’: Immediately destroys the stream, preventing any further I/O.
    • Example: stream.destroy(new Error('Something broke'));

⚙️ Core Writable Stream Methods

  • ✏️stream.write(chunk): Pushes a buffer (or string) into the internal buffer.
    • Returns true if writableLength < highWaterMark, meaning it’s safe to continue writing.
    • Returns false if buffer is full, meaning you must wait for 'drain' before writing more.
  • 🔚stream.end([chunk]): Signals that no more data will be written.
    • Optionally writes one last chunk before ending.
    • Emits 'finish' when all data is flushed.
  • 🔄stream.cork(): Temporarily buffers all subsequent write() calls in memory.
    • Useful if you have many small writes and want to flush them in a single operation.
  • 🔔stream.uncork(): Flushes all buffered writes at once.
    • Always call uncork() after you finish grouping writes under a cork().
  • 🆘stream.destroy([error]): Immediately destroys the stream, optionally providing an error.
    • After destroy(), no more reads or writes can occur.

📊 Important Properties

  • 🔢stream.writableHighWaterMark: The size (in bytes) of the internal buffer before write() returns false. Defaults to 16 384 bytes (16 KB).
  • 📐stream.writableLength: How many bytes are currently buffered and waiting to be written to the underlying resource.
    • Always keep writableLength < writableHighWaterMark to avoid excessive memory use.
  • ⚡stream.writableFinished: true if stream.end() has been called and all buffered data has been flushed; otherwise false.
  • ✔️stream.writableEnded: true if end() has been called, regardless of whether all data is flushed yet.
    • Check writableFinished to confirm flush completion.
  • 🔔stream.writableNeedDrain: true if write() returned false (i.e., the buffer is full and you need to wait for 'drain').

💻 Code Snippets & Examples

  • 📂Creating a Write Stream to a file: 
    const fs = require('fs');
const stream = fs.createWriteStream('output.txt');
// Write a buffer or string:
const buf = Buffer.from('Hello, world!', 'utf8');
if (!stream.write(buf)) {
  // Buffer is full; wait for 'drain'
  stream.once('drain', () => {
    stream.write(buf);
  });
}
stream.end(() => {
  console.log('All data flushed to file');
});
  • 🌐Writing an HTTP response (Writable Stream): 
    const http = require('http');
http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'text/plain' });
  res.write('First chunk\n');
  res.write('Second chunk\n');
  res.end('Done!\n'); // emits 'finish' when all data is sent
}).listen(3000);
  • 🔧Using cork() & uncork() to batch small writes: 
    const stream = fs.createWriteStream('batch.txt');
stream.cork();
for (let i = 0; i < 1000; i++) {
  stream.write(`Line ${i}\n`);
}
stream.uncork(); // flushes all 1000 lines at once
stream.end();

💡 Tips & Best Practices

  • 👀Always check write()’s return value. If false, wait for 'drain' before writing more.
  • 🚫Never write after calling end()—it will cause an error.
  • 🔍Monitor writableLength and writableHighWaterMark to avoid large memory spikes.
  • 📖Read the official documentation’s descriptions for events and methods; it’s easier than memorizing them.
  • 🎯Use stream.finished() (from 'stream' module) to get a Promise that resolves when the stream ends, for cleaner async code.
