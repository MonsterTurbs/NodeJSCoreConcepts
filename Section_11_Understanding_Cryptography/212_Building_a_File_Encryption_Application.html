🎯Goal

Build a super-secure file encryption & decryption tool ⚔️ that only needs a single master password. Ideal for military, banking, or private data!

🛠️Core Components

  • Master Password – users supply one secret 🔑
  • Salt – random bytes to protect against rainbow tables 🧂
  • IV (Nonce) – random 96 bit value for AES-GCM 🔄
  • KDF – PBKDF2 to derive a strong 256 bit key from password 🔒
  • AES-256-GCM – encrypt & produce authentication tag 🗝️
  • Auth Tag – ensures integrity & authenticity ✔️

🚀File Format

We pack everything into one file in this order:

  1. 16 bytes of salt
  2. 12 bytes of IV (nonce)
  3. Ciphertext (your encrypted data)
  4. 16 bytes of Auth Tag

🔑Derive Key with PBKDF2

crypto.pbkdf2(
  password,
  salt,
  1_000_000,      // iterations
  32,             // key length (256 bits)
  'sha512',       // digest
  (err, key) => { … }
);

🔐Encrypt (encrypt.js)

const cipher = crypto.createCipheriv('aes-256-gcm', key, iv);
pipeline(
  fs.createReadStream('data.txt'),
  cipher,
  fs.createWriteStream('data.encrypted'),
  err => { … }
);
// write salt, iv, then append authTag

🕵️‍♂️Decrypt (decrypt.js)

const fd = fs.openSync('data.encrypted', 'r');
// read salt (16B), iv (12B), authTag (16B)
crypto.pbkdf2(… (err,key) => {
  const decipher = crypto.createDecipheriv('aes-256-gcm', key, iv);
  decipher.setAuthTag(authTag);
  pipeline(
    fs.createReadStream('data.encrypted', { start:28, end:size-17 }),
    decipher,
    fs.createWriteStream('data.decrypted.txt'),
    err => { … }
  );
});

🔗End-to-End Encryption

By sharing the master passphrase only among trusted clients (never the server), you achieve true end-to-end security:

  • Server stores only ciphertext 🚫📖
  • Clients derive keys locally from passphrase 🔑➡️🔐
  • No third party (even the server) can decrypt data 👮‍♂️🚫
