🔍SHA-256 From Scratch?

This video walks through a pure-JavaScript implementation of SHA-256. It’s ~100 lines of code—no magic, just simple math you could trace on paper! 📝

✨The “Magic” of Random

The only part that feels like magic is crypto.randomBytes()—OpenSSL gathering true randomness from your hardware. Everything else is clear math. 🔮

🔄Rotate-Right Helper

SHA-256 uses 32-bit words and needs to rotate bits right. A helper does:

function rotR (x, n) {
  return (x >>> n) | (x << (32 - n));
}

📏Padding to 512-bit Blocks

SHA-256 works on 512-bit (64-byte) chunks. If your message isn’t a multiple of 512 bits, you:

  1. Append 0x80 byte
  2. Pad with zeros until you’re 64 bits shy of a multiple of 512
  3. Append original message length in 64 bits

📐Constants from Math

SHA-256 uses 64 fixed 32-bit “K” values (cube roots of primes) and 8 initial hash words (square roots of primes). These drive the mixing in each round.

⚙️Main Compression Loop

For each 512-bit block:

  • Expand 16 words into 64
  • Repeat 64 rounds: mix current words with K[i], rotate, xor, add
  • Update the 8 running hash values

At the end, concatenate the 8 words → final 256-bit hash. 🔗

✅Verify vs. Node Crypto

At the end, the custom implementation’s output matches crypto.createHash('sha256') exactly—proof you’ve built it right! 🎉
