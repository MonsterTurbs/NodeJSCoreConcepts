🔐 Cryptography for Beginners

📖What is Cryptography?

Cryptography turns plain data (text, files) into secret code using a key—only someone with the key can read it.

🛡️Why Do We Need It?

  • Confidentiality: Only the right people see the data.
  • Integrity: Detect if data was changed by someone else.
  • Authentication: Verify who sent the data.

🌐Everyday Impact

  • Private messaging, secure online banking, and phone passcodes.
  • Disk and file encryption, HTTPS, SSH, VPNs.
  • Even cryptocurrencies rely on cryptography for security.

⚙️Key Node.js Modules

  • crypto: Core encryption, hashing, and more.
  • tls: Secure connections built on crypto.
  • https: HTTPS servers, built on tls.

🔗Under the Hood: OpenSSL

Node.js uses OpenSSL (written in C) for all cryptographic operations—making it both powerful and reliable.

🧠Three Subfields

  • Symmetric: Same secret key for encrypt/decrypt.
  • Keyless (Hashing): No key; one-way algorithms.
  • Asymmetric: Public/private key pairs, secure key exchange.

🛠️Tools & Prerequisites

  • Buffers & binary data (Node.js).
  • File system & streams basics.
  • Networking: DNS, TCP, HTTP/HTTPS.
  • Discrete math: bit math, probability.
  • Optional: Hex viewers (Hex Fiend, HxD) for exploring bytes.

⚠️Legal & Security Notes

  • Check local laws—some regions regulate or ban strong encryption.
  • Encryption is strong, but overall security can still be attacked (e.g., zero-click spyware).
