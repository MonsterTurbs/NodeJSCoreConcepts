🔒 AES Encryption Explained

✨What is AES?

AES (Advanced Encryption Standard) is the most common symmetric cipher—used everywhere from HTTPS to messaging apps.

🌐Everyday Uses

  • End-to-end chat encryption (WhatsApp, iMessage).
  • HTTPS web traffic (banks, websites).
  • Disk encryption (FileVault, BitLocker).
  • VPNs, SSH, password managers, IoT devices.

📦Block & Key Sizes

  • Operates on 128-bit blocks (16 bytes).
  • Key lengths: 128, 192, or 256 bits.
  • Number of rounds: 10 (128-bit key), 12 (192), or 14 (256).

🔄Core Steps per Block

  1. AddRoundKey: XOR block with round-specific key.
  2. SubBytes: Replace each byte via a lookup table.
  3. ShiftRows: Rotate each row of the 4×4 byte matrix.
  4. MixColumns: Mix bytes in each column (skip on last round).
  5. Repeat: Perform steps 2–4 for each round, then final AddRoundKey.

🔑Round Keys (Key Schedule)

The original key is expanded into multiple 128-bit round keys—one for each encryption round.

⚠️ECB Mode Warning

ECB simply concatenates encrypted blocks—identical plaintext blocks yield identical ciphertext. This reveals patterns, so use other modes (CBC, GCM) for real security.

🔧Node.js Example

Use crypto.createCipheriv('aes-128-ecb', key, null) and cipher.update()/cipher.final() to encrypt bytes in JavaScript.

🔍Learn More

Check the NIST AES specification (2001) for the full math details—SubBytes S-box, row shifts, column mixing, and key expansion algorithms.
