🛣️Roadmap Problem

We need to derive strong keys (AES, RSA) from simple passwords or small PINs, and also securely hash user passwords before storing. 💾🔐

🔑What Is a KDF?

A Key Derivation Function takes a low‐entropy secret (like a password) plus a random salt and produces a high‐entropy key. It’s slow by design to resist brute‐force. 🐢

🧩PBKDF2

Password-Based Key Derivation Function 2 is widely used (iOS, macOS, password managers).

crypto.pbkdf2(
  password, 
  salt, 
  iterations, 
  keyLen, 
  'sha512',
  (err, derivedKey) => {
    // use derivedKey (Buffer)
  }
);

🌊Salt & Iterations

  • Salt – random bytes (e.g. crypto.randomBytes(16)) 💧
  • Iterations – how many hash rounds (e.g. 100 000) 🔄
  • Higher = slower but stronger vs. brute‐force

📏Key Length & Digest

  • keyLen – desired byte length (e.g. 32 bytes for AES-256)
  • digest – hashing algorithm (“sha256” or “sha512”) 🛡️

💻Demo Code

const crypto = require('crypto');
const password   = 'myPassword';
const salt       = crypto.randomBytes(16);
const iterations = 100000;
const keyLen     = 32;            // 256 bits
const digest     = 'sha512';

crypto.pbkdf2(password, salt, iterations, keyLen, digest, (err, key) => {
  if (err) throw err;
  console.log('Derived key:', key.toString('hex'));
  console.log('Salt:', salt.toString('hex'));
});

🌟Other KDFs to Know

  • scrypt – better for weak passwords 🚀
  • HKDF – HMAC-based KDF, good for protocol keys 🔗
  • Argon2 – winner of the 2015 password hash contest 🥇

📂Storing Passwords

Use a KDF (e.g. PBKDF2 or Argon2) + unique salt for each user. Store both derived hash + salt. On login, re-derive and compare. No plain SHA‐256 please! 🚫🔓
