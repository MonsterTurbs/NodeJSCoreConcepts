🔐 Block Cipher Modes: ECB, CBC & CTR

📚What Are Modes?

Modes tell AES how to process many 128-bit blocks: how to chain them, add randomness, and protect integrity.

🔲ECB (Electronic Codebook)

  • Encrypts each block independently.
  • Identical plaintext blocks → identical ciphertext blocks.
  • Fast & parallelizable but leaks patterns (e.g. image outlines).

⛓️CBC (Cipher Block Chaining)

  • Uses an IV (random 128-bit) XORed with first block.
  • Each block’s ciphertext is XORed into next block’s input.
  • Hides patterns—identical plaintext blocks give different ciphertext.
  • Cannot parallelize encryption; decryption is parallel-safe.

🔢CTR (Counter)

  • Encrypts a counter (nonce + increment) instead of plaintext.
  • XORs encrypted counter with plaintext for ciphertext.
  • Parallel encrypt/decrypt & hides patterns.
  • Does not detect tampering—use GCM for authenticity.

💡Choosing a Mode

  • Avoid ECB in real data—use CBC or CTR.
  • For tampering protection, use authenticated modes like GCM.
  • Always use a random IV/nonce and never reuse it.
