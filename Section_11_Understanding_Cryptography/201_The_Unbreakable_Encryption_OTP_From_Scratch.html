🔐 Perfect Encryption: One-Time Pad

✨What Is One-Time Pad?

A perfect encryption using a random key (pad) the same length as the message, used only once and then destroyed.

📏Key Rules

  • Length: Key length = message length.
  • Randomness: Key must be truly random.
  • One-Time Use: Destroy key after encryption/decryption.

🔄Core Operation: XOR

XOR (⊕) compares bits: identical → 0, different → 1. Only with the same key can you reverse (decrypt) the ciphertext.

💻Node.js XOR Demo

In REPL: a = Buffer.from([0xA4]); b = Buffer.from([0xF3]); a[0] ^ b[0] → 0x87. Matches bitwise XOR table.

🚀Encryption Flow

  • Generate random key bytes (e.g., 100 bytes): crypto.randomBytes().
  • Encrypt: For each byte, cipher[i] = plaintext[i] ⊕ key[i] and then zero-out key[i].
  • Share ciphertext; key never travels online.

📡Practical Example

Commander and submarine each hold a copy of the key (exchanged physically). Commander sends XORed message over insecure channel; submarine XORs back to recover plaintext.

⚠️Key Management Challenge

Key must match message size—encrypting large data (e.g., terabyte) needs huge key and secure distribution, making OTP impractical at scale.
