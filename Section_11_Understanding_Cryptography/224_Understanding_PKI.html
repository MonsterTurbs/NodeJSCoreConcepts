🔐Understanding PKI

🌐What is PKI? Public Key Infrastructure (PKI) is a system for managing digital certificates and public–private key pairs.

🛠️Main Components:

  • 🏛️Certificate Authority (CA): Issues and revokes certificates.
  • 🗝️Public/Private Keys: Public key shared openly; private key kept secret.
  • 📜Digital Certificates: Bind a public key to an identity (website, person, service).
  • 🔄CRL/OCSP: Methods to check if a certificate has been revoked.

🔒Why it matters: Ensures that encrypted connections (HTTPS, email) are trusted and that identities can be verified.
