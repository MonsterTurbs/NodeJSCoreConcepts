🔑 Symmetric Encryption Basics

🗝️What Is Symmetric Encryption?

Uses one secret key and an algorithm (cipher) to turn data into unreadable code and back.

🔄How It Works

  • Plaintext: original data (text, video, etc.).
  • Encrypted by a cipher plus the secret key → Ciphertext (gibberish).
  • Only someone with the same key and algorithm can decrypt back to plaintext.

🛡️Key Points

  • Encryption: plaintext → ciphertext.
  • Decryption: ciphertext → plaintext.
  • Cipher: the method or algorithm used.
  • Key must stay secret; cipher is often public.

⚙️Common Ciphers

  • AES: industry standard for 20+ years (128, 192, 256-bit keys).
  • 3DES: older; replaced by AES because it's slower and less secure.
  • Having multiple ciphers (AES, ChaCha20) gives fallback if one is broken.

📜Historical Example: Caesar Cipher

Simple letter shift (e.g., A→D). Teaches plaintext/ciphertext terms, but real encryption works on binary data.

💻Node.js Example Overview

Using crypto.createCipheriv() and crypto.createDecipheriv() with AES-128: logs show plaintext, ciphertext (gibberish), then decrypted plaintext—lossless round-trip.
