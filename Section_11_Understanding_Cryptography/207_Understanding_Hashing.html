🔍What Is Hashing?

A hash function takes any size of data (“message”) and crunches it into a fixed‐size output called a hash or digest. For example, no matter if you hash one word or a big video, the result is always 256 bits long (for SHA-256).

🛡️Why Do We Hash?

  • Integrity: Detect if data was changed in transit 🔄
  • Authentication: Verify someone’s identity (e.g. password checks) ✅
  • Key Derivation: Turn a simple password into a strong AES key 🔑

⚙️Basic Hash Example in JavaScript

const crypto = require('crypto');

// Create a SHA-256 hasher
const hasher = crypto.createHash('sha256');

// Add our message
hasher.update('Hello, world! 🌎');

// Get the 256-bit digest as hex
const digest = hasher.digest('hex');

console.log(digest);

📋Popular Hash Algorithms

  • ✅ SHA-256 – 256-bit output (very widely used)
  • ✅ SHA-512 – 512-bit output (extra security)
  • ⚠️ MD5 and ⚠️ SHA-1 – broken, don’t use!

🔒What Makes a Hash “Secure”?

  1. Preimage resistance: Cannot reverse hash → original data 🔐
  2. 2nd preimage resistance: Cannot find a 2nd input matching same hash 🔑
  3. Collision resistance: Cannot find any two inputs with same hash ⚔️
  4. Avalanche effect: Tiny input change → completely different hash ❄️

🌐Hashing in the Real World

  • Passwords: Store salted hashes instead of plain text 🔑
  • File checks: Verify downloads with `sha256sum file` 📂
  • Cryptocurrencies: Bitcoin miners compute trillions of SHA-256 ⛏️
