🔍 Brute-Forcing One-Time Pad

❓Why Brute-Force OTP?

Even with small messages, OTP resists brute-force: many keys yield plausible plaintexts, so you can’t tell which is right.

🧮Keyspace Comparison

  • AES-128 keyspace: 2¹²⁸ combos (practically unsearchable).
  • OTP on 50-bit message: 2⁵⁰ combos—seems smaller but still fails.

⚙️Why OTP Fails Brute-Force

  • Given C = P ⊕ K, any candidate key K' yields a plaintext: P' = C ⊕ K'.
  • Many K' produce readable messages; attacker can’t distinguish the real one.

💻Demo Script

xor.js takes two hex buffers, XORs them, and prints as text. Play with different keys to see varied outputs.

🔄Example Outputs

  • Key A → "Commander Hendrik standby to launch"
  • Key B → "Commander Hendrik Nuke launch"
  • Key C → "Commander Hendrik "

All look plausible—no way to pick the true message.

🔒Perfect Secrecy

OTP grants perfect secrecy: ciphertext alone reveals nothing about plaintext without the exact key.

🚀Practical Takeaway

OTP is only secure if key never reused and remains secret. For most uses, AES with proper modes offers strong, guaranteed integrity.
