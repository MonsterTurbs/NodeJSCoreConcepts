📖 Key Terms

  • ⌨️Prompt: The text the terminal shows before you type a command.
    • Example: user@machine:~/folder$
    • Shows info like current directory, username, or Git branch.
  • 💬Command Line: The line where you type commands (e.g., ls -la).
  • 🖥️Terminal: The application that runs the command line (e.g., iTerm2, GNOME Terminal).
  • 🖱️GUI (Graphical User Interface): The graphical windows and icons you click—like Finder or File Explorer.

🚀 Why Use the Command Line?

  • ⚡Speed & Automation:
    • Do tasks (like creating many files) in one command instead of many clicks.
    • Example: Create 50 files at once with a loop instead of manually clicking 50 times.
  • 🔧Server Management:
    • Many servers have no GUI—everything is done via SSH and CLI.
    • Deploying, updating, and debugging on remote machines all happen in a terminal.
  • 🧩Powerful Toolchain:
    • Combine (“pipe”) tools: output of one command becomes input to another.
    • Example: man ascii \| head -n 43 \| tail -n 16 > ascii.txt (grab specific lines from manual and save to a file).
  • 💼Essential skill for backend developers—worth mastering early!

📂 Navigating Directories

  • 📍pwd → “print working directory”: shows your current folder path.
  • ➡️cd <folder> → “change directory”: move into a subfolder.
    • e.g., cd Testing jumps into “Testing” folder.
    • cd .. → go up one level.
    • cd ~ or just cd → back to home folder.
  • 📋ls → “list”: shows files/folders in the current directory.
    • ls *.html → lists only files ending in “.html”.
  • 📥mkdir <name> → “make directory”: create a new folder.
    • e.g., mkdir HTML makes an “HTML” folder.

📄 Working with Files

  • ✋touch <filename> → create an empty file.
    • e.g., touch index.html makes “index.html”.
  • 📝cat <filename> → display file contents.
    • e.g., cat text.txt shows text inside “text.txt”.
  • ✏️Edit files:
    • vim <filename> → powerful text editor (press i to insert, Esc :wq to save & quit).
    • nano <filename> → simpler editor (Ctrl+O to save, Ctrl+X to exit).
  • ✂️rm <filename> → delete a file.
    • Be very careful—file is gone! (e.g., rm old.txt deletes “old.txt”).
    • To delete a directory and its contents: rm -rf <folder> (dangerous—don’t use carelessly!).
  • 🔀mv <source> <destination> → move or rename.
    • e.g., mv index.html HTML/index.html moves file into “HTML” folder.
    • e.g., mv old.txt new.txt renames “old.txt” to “new.txt”.

🔧 Variables & Command History

  • 🔢Set a variable: NAME="Joe" (no spaces around =).
    • Refer to it with $NAME. e.g., echo $NAME prints “Joe”.
  • 📑See your last command: press ↑ (Up arrow) to cycle through history.
  • 🔍Search manual pages: man <command> (e.g., man ls shows how “ls” works).

➰ Piping & Redirection

  • ➡️Pipes (|): send output of one command into another.
    • Example: man ascii \| head -n 43 \| tail -n 16 → show specific lines from “man ascii”.
  • 💾Redirect ( > ): save output to a file.
    • Example: echo "Hello" > hello.txt writes “Hello” into hello.txt.
  • ➕Append ( >> ): add output to end of a file.
    • Example: echo "Line 2" >> hello.txt appends “Line 2” to hello.txt.

🌟 Handy Tips

  • 🔄Ctrl + A → jump to start of line; Ctrl + E → jump to end of line.
  • 📋Copy/Paste: Ctrl + Shift + C to copy, Ctrl + Shift + V to paste.
  • ❌Ctrl + C → stop a running command or clear partial input.
  • 📂Ctrl + L → clear the screen.
  • 🖱️You can drag & drop file paths into the terminal to insert their path automatically.
