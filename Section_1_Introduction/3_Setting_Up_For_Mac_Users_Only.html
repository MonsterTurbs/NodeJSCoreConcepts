💻 Terminal Basics (iTerm2)

  • 🐚We use the Terminal a lot. The built-in “Terminal” app works, but many prefer iTerm2.
  • 📥To install iTerm2:
    1. Open Safari → search “download iTerm2” → go to iTerm2.com → click “Downloads” → download .zip.
    2. Open Downloads folder → drag iTerm.app into /Applications.
    3. Open iTerm2 from Applications → click “Open” if macOS warns you.
  • ⚙️In iTerm2 Preferences (⌘ ,):
    • Under General > Working Directory, set “Reuse previous session’s directory” so new tabs open where you left off.
    • Under Appearance > Color Presets, pick a theme you like (e.g., Solarized Dark).
    • Under Keys, note useful shortcuts:
      • ⌘ 1, ⌘ 2, ⌘ 3 to switch tabs quickly.
      • Ctrl A goes to start of line; Ctrl E goes to end of line.
    • 📋To copy text: just select it—iTerm auto-copies. Paste with ⌘ V.
  • 🔍Find your CPU architecture: run uname -a.
    • If the result contains arm64, you have an Apple Silicon Mac.
    • If it shows x86_64, you have an Intel-based Mac.
  • 📌Right-click iTerm2 icon > Options > “Keep in Dock” for easy access.

🔧 Install Command Line Tools

  • 🛠️macOS requires “Command Line Developer Tools” (Git, GCC, Python, etc.) for many packages.
  • ⌨️To install: in Terminal, run: xcode-select --install → when a popup appears, click “Install” → agree to terms.
  • ✅After a few minutes, tools are ready. Verify by running python3 --version or gcc --version.

🍺 Install Homebrew

  • 🏠Homebrew is a package manager for macOS that simplifies installing apps.
  • ⌨️Check if Homebrew is installed: run brew -v.
    • If a version appears, Homebrew is already installed → skip this step.
    • If you see “command not found,” install it.
  • ⚡To install, copy the Homebrew command from the PDF or Homebrew website: /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" → press Enter → enter your password → wait.
  • 📜If Terminal warns “brew is not in your PATH,” run the two commands it suggests (add lines to ~/.zprofile or ~/.zshrc).
  • ✅After installing, run brew update to ensure formulas are current.

🌟 Install NVM & NodeJS

  • 🌀NVM (Node Version Manager) lets you install and switch between multiple NodeJS versions easily.
  • ⌨️To install NVM via Homebrew: brew install nvm
  • 📝After that, add these lines to your ~/.zshrc (or ~/.bash_profile if using bash): 
      
export NVM_DIR="$HOME/.nvm"  
[ -s "/opt/homebrew/opt/nvm/nvm.sh" ] && \. "/opt/homebrew/opt/nvm/nvm.sh"  
[ -s "/opt/homebrew/opt/nvm/etc/bash_completion.d/nvm" ] && \. "/opt/homebrew/opt/nvm/etc/bash_completion.d/nvm"
  • 📂Create the ~/.nvm folder if not auto-created: mkdir ~/.nvm
  • 🔄Restart Terminal or open a new tab, then verify with nvm -v.
  • 🚀Install NodeJS LTS (recommended): nvm install 20 → this grabs latest 20.x.y LTS. nvm use 20 → sets NodeJS v20 as active.
  • 📦Verify NodeJS & npm: node -v and npm -v should show versions (e.g., v20.x.y and npm 10.x.y).
  • ⚠️If you prefer a global installer instead, you can download the NodeJS macOS installer from nodejs.org (ARM64 for Apple Silicon or x64 for Intel), but NVM is easier for switching versions.

🧪 Install Postman

  • 🌐Postman is used to test HTTP APIs. We’ll use it in the HTTP section.
  • 🔍To install:
    1. In your browser, search “Download Postman” → go to postman.com/downloads.
    2. Choose the Mac version matching your CPU (Apple Silicon or Intel). Download the .zip/.dmg.
    3. Open the downloaded file → drag Postman.app into /Applications.
    4. Open Postman from Applications. If prompted, click “Open.”
  • ✅Verify by typing any URL in Postman’s request bar and clicking “Send”—you’ll get a response if online.

📡 Install Wireshark

  • 🌐Wireshark captures network packets to show exactly what data travels through your network card.
  • 🔍To install:
    1. Search “Download Wireshark” → go to wireshark.org/download.
    2. Choose the macOS installer for your CPU (ARM64 or Intel). Download the .dmg.
    3. Open the .dmg → drag Wireshark.app into /Applications.
  • 🔒On first launch, it may show “Permission to capture packets denied.”
    • Open the Wireshark .dmg again and run “Install ChmodBPF.”
    • Follow prompts → enter your password to grant permission.
    • Quit and reopen Wireshark → now you can capture packets.
  • ▶️To test: double-click your main network interface (e.g., “en0” or “Ethernet”) to start capturing. Then perform any web request (e.g., in Safari/Chrome). Stop capture to view packets.
  • ❕Later, you can disable packet highlighting or auto-scroll if it’s confusing—use the toolbar icons.

📊 Activity Monitor

  • 🔍Activity Monitor shows all running processes and resource usage (CPU, memory, disk, network).
  • ▶️Open it via Spotlight (⌘ Space → type “Activity Monitor” → Enter).
  • 👀Tabs to check:
    • CPU – shows overall CPU load and per-process usage.
    • Memory – shows how much RAM each process uses.
    • Network – shows data sent/received per process.
    • Disk – shows read/write per process.
  • 🕵️‍♂️To see your Node process: open Terminal → run node (starts REPL) or run your script (node app.js) → look for “node” in Activity Monitor. You’ll see its CPU, memory, and other stats.

🔢 Programmer Calculator

  • 🧮macOS Calculator has a “Programmer” mode to convert numbers between different bases (binary, hex, octal, decimal).
  • ▶️Open via Spotlight (⌘ Space → type “Calculator” → Enter). Then choose View > Programmer.
  • ✨You can enter:
    • A decimal number (e.g., “12”) to see its hex (0xC), octal (014), and binary (1100).
    • A hex number (e.g., “0xF”) to see decimal (15), octal (017), and binary (1111).
    • A binary sequence (e.g., “1010”) to see decimal (10), hex (0xA), and octal (012).
  • 📘We’ll use this in the Buffers section to understand how raw bytes map to text and numbers.

🚀 Testing a Simple NodeJS App

  • 📂Open Terminal and go to Desktop: cd ~/Desktop.
  • 📄Create a text file: touch text.txt → open in VS Code: code text.txt → type This text is coming from Node. → save and close.
  • 🆕Create Node app file: touch app.js → open in VS Code: code app.js.
  • 💻In app.js, copy/paste this code: 
      
const http = require('http');  
const fs = require('fs');  

const server = http.createServer();  
server.on('request', (req, res) => {  
  const data = fs.readFileSync('text.txt');  
  res.setHeader('Content-Type', 'text/plain');  
  res.end(data);  
});  

server.listen(4080, '127.0.0.1', () => {  
  console.log('Server running at http://' + server.address().address + ':' + server.address().port);  
});
  • ▶️In Terminal: node app.js → see “Server running at http://127.0.0.1:4080”.
  • 🌐Open Postman → set method to GET → URL http://127.0.0.1:4080 → click “Send” → response should show “This text is coming from Node.”
  • 📡Open Wireshark → double-click “Loopback” to capture → in Postman click “Send” → stop Wireshark → look for HTTP packets from 127.0.0.1.
    • Click one packet with protocol “HTTP” → scroll down to see the plain-text response.
  • ✅If Postman returns the text and Wireshark shows packets, your Mac is fully set up for the course!
  • 🎉Congratulations! You’re ready to follow along with the lessons.
