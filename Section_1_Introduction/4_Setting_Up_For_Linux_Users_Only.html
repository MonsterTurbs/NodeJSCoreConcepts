🐧 Linux Setup: Beginner-Friendly Study Notes

👋 Welcome & Guide

  • 😊This video shows how to prepare your Linux (Ubuntu 22) for the NodeJS course.
  • ⏭️Use the Table of Contents (bottom-left of the video) to skip parts you already know.
  • 📥Download the PDF of installation commands from Resources to copy/paste, instead of typing.
  • ❗Don’t bookmark or add notes in the video—content will change when updated.

💻 Terminal Basics

  • 🐚Open Terminal: click “Show Applications” → search “Terminal” → open it.
  • 🔧Zoom in/out: Ctrl + Shift + + to zoom in, Ctrl + − to zoom out.
  • ➕New tab: click the “+” icon or press Ctrl + Shift + T.
  • ⌨️Some handy shortcuts:
    • 🎯Ctrl + A → move cursor to start of line.
    • 🎯Ctrl + E → move cursor to end of line.
    • 📋Copy: select text → Ctrl + Shift + C. Paste: Ctrl + Shift + V.
    • ❌Ctrl + C → stop a running command or clear partial input.
  • 🔍Find CPU & OS: run uname -a.
    • If it shows arm64, you have an ARM-based machine. If x86_64, you have an Intel/AMD (x64) machine.
    • Also see “Ubuntu 22” in output.
  • 📌Pin Terminal to favorites: right-click its icon in the dock → “Add to Favorites”.

🌐 Browser

  • 🔥Firefox is usually pre-installed—feel free to use it. If you prefer Chrome, download and install it.
  • 👩‍💻Open Developer Tools: right-click page → “Inspect” or press Ctrl + Shift + I. Use the Network tab to view requests/responses.
  • ⚠️To install Chrome (x64): download .deb from google.com → in Terminal: 
    sudo apt install ./google-chrome-stable_current_amd64.deb
    If on ARM64, Chrome may not be supported—use Firefox instead.

📝 Code Editor

  • 💻Recommended: Visual Studio Code. If you already have an editor (e.g., Sublime, Atom), you can skip this.
  • 🔍To install VS Code:
    1. Download the .deb for your CPU (amd64 or arm64) from code.visualstudio.com.
    2. In Terminal: 
    sudo apt install ./code_*.deb
  • ✨Open via code . to launch VS Code in current folder (ensure code is in PATH).
  • 🎨Install extensions:
    • Material Theme: beautifies editor.
    • Material Icon Theme: file icons.
    • Prettier – Code formatter: auto-formats on save.
  • ⚙️Enable “Format on Save”: in Settings (Ctrl + ,) → search “Format on Save” → check box → configure default formatter to Prettier via Command Palette (Ctrl + Shift + P → “Format Document With…” → select Prettier).
  • 🔗Toggle Sidebar: Ctrl + B. Extensions: Ctrl + Shift + X, Explorer: Ctrl + Shift + E.

🌟 Install NVM & NodeJS

  • 🌀NVM (Node Version Manager) lets you install and switch between multiple Node versions smoothly.
  • ⌨️To install NVM: 
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
  • 🔄Reload profile: 
    source ~/.bashrc
    (or source ~/.zshrc if using zsh). Verify with nvm --version.
  • 🚀Install latest LTS NodeJS: 
    nvm install --lts
    Then nvm use --lts. Confirm with node -v and npm -v.
  • ⚠️If a system Node is already installed, use which node to find and uninstall it to avoid conflicts.

🧪 Install Postman

  • 🌐Postman is used to test HTTP APIs. We’ll use it in the HTTP section.
  • 🔍To install: 1. Download the Linux .tar.gz from postman.com/downloads (choose ARM64 or x64).
    2. In Terminal: 
    cd ~/Downloads  
tar -xzf Postman-linux-*.tar.gz  
mkdir -p ~/Applications  
mv Postman/ ~/Applications/
    3. Create a desktop shortcut: in Terminal: 
    cat > ~/Desktop/postman.desktop << 'EOF'  
[Desktop Entry]  
Name=Postman  
Exec=/home/USERNAME/Applications/Postman/Postman  
Icon=/home/USERNAME/Applications/Postman/app/resources/app/assets/icon.png  
Terminal=false  
Type=Application  
Categories=Development;  
EOF  
chmod +x ~/Desktop/postman.desktop
    Replace USERNAME with your Linux username.
  • ✅Launch via desktop icon or ~/Applications/Postman/Postman.

📡 Install Wireshark

  • 🔧Wireshark captures network packets—useful for debugging networking code.
  • ⌨️To install: 
    sudo add-apt-repository ppa:wireshark-dev/stable  
sudo apt update  
sudo apt install wireshark
  • 🔓During installation, select “Yes” when asked to allow non-root users to capture packets.
  • ▶️Run Wireshark with root privileges: 
    sudo wireshark
    If you don’t run as root, interfaces won’t appear.
  • ❕To capture on your loopback (127.0.0.1) or your main interface, double-click the interface in Wireshark.
  • 📘You can turn off packet highlighting and auto-scroll via toolbar icons if it’s confusing.

🔌 Net-Tools (ifconfig)

  • ⚙️Install net-tools to use ifconfig and see IP addresses and interfaces.
  • ⌨️In Terminal: 
    sudo apt install net-tools
  • 🔍Run ifconfig to list interfaces.
    • 🐧Look for lo (loopback) and your main interface (e.g., enp0s3 or wlp2s0).
    • 🌐See IPv4 and IPv6 addresses for each interface.

📊 System Monitor

  • 🔍“System Monitor” (GNOME System Monitor) shows running processes and resource usage (CPU, memory, network, disk).
  • ▶️Open via “Show Applications” → search “System Monitor” → open it.
  • 👀Tabs to check:
    • Processes – list all processes; right-click to kill, view open files, etc.
    • Resources – graphs for CPU cores, memory usage, and swap usage.
    • File Systems – displays disk usage, but we’ll mainly use the “Processes” and “Resources” tabs.
  • 🕵️‍♂️To monitor a Node process: run node or node app.js in Terminal, then find “node” in System Monitor to see CPU percentage and memory usage.

🔢 Programmer Calculator

  • 🧮Use the built-in Calculator in “Programmer” mode to convert between number bases (binary, octal, decimal, hex).
  • ▶️Open Calculator via “Show Applications” → search “Calculator” → open it. Then choose “Programmer” from the menu (View > Mode > Programmer).
  • ✨Converting examples:
    • Enter a decimal number (e.g., “10”) → see its hex (0xA), octal (012), binary (1010).
    • Enter a hex number (e.g., “0xF”) → see decimal (15), octal (017), binary (1111).
    • Enter a binary sequence (e.g., “1010”) → see decimal (10), hex (0xA), octal (012).
  • 📘We’ll use this in the “Buffers” section to understand raw bytes (zeros/ones) vs. text.

🚀 Testing a Simple NodeJS App

  • 📂Open Terminal and navigate to Desktop: cd ~/Desktop.
  • 📄Create a text file: touch text.txt. Then open in VS Code: code text.txt → type This text is coming from Node. → save and close.
  • 🆕Create Node app file: touch app.js → open in VS Code: code app.js.
  • 💻In app.js, copy/paste this code: 
      
const http = require('http');  
const fs = require('fs');  

const server = http.createServer();  
server.on('request', (req, res) => {  
  const data = fs.readFileSync('text.txt');  
  res.setHeader('Content-Type', 'text/plain');  
  res.end(data);  
});  

server.listen(4080, '127.0.0.1', () => {  
  console.log('Server running at http://' + server.address().address + ':' + server.address().port);  
});
  • ▶️In Terminal: node app.js → you should see “Server running at http://127.0.0.1:4080”.
  • 🌐Open Postman → set method to GET → URL http://127.0.0.1:4080 → click “Send” → response should show “This text is coming from Node.”
  • 📡Open Wireshark (with root privileges) → double-click “Loopback” interface to capture → in Postman click “Send” → stop Wireshark → find the HTTP packet from 127.0.0.1.
    • Click that packet → scroll down to see the plain-text response: “This text is coming from Node.”
  • ✅If Postman returns the text and Wireshark captured packets, your Linux setup is complete!
  • 🎉Congrats! You’re ready to follow along with the course.
