💻 Terminal (Command Line)

  • 🔍Press Start → All Apps → Windows Terminal to open the recommended terminal app.
  • 🖥️Other Windows options: PowerShell or Command Prompt, but Terminal is preferred (supports tabs).
  • 📌Pin Windows Terminal to your taskbar for quick access.
  • 🔧Zoom in/out: Ctrl + + / –. Create new tab: click “+” or use Ctrl + Shift + T.
  • ℹ️Run systeminfo to see Windows version (“Windows 11 Pro”) and CPU architecture (e.g., “ARM64” or “x64”). Remember your CPU type for later downloads.

🌐 Web Browser

  • 🌟Windows default: Microsoft Edge. You can use it or download Google Chrome (or Firefox) for testing HTTP apps.
  • 🔧To install Chrome:
    1. Search “Download Google Chrome” → go to official site → click “Download Chrome” → run installer.
    2. Optionally set Chrome as default: Settings → Apps → Default Apps → Google Chrome → Set Default.
  • 🔍Open DevTools: Right-click → Inspect or Ctrl + Shift + I. Use the Network tab to view HTTP requests/responses (essential in later HTTP section).

📝 Code Editor

  • 💻Recommended: Visual Studio Code. If you have another editor (e.g., Atom, Sublime), feel free to skip.
  • 🔍To install VS Code:
    1. Search “Download Visual Studio Code” → go to code.visualstudio.com.
    2. Select Windows (ARM64) or Windows (x64) based on your CPU.
    3. Run installer → accept defaults → finish.
  • 🎨Configure Theme & Icons:
    1. Open Extensions: Ctrl + Shift + X.
    2. Install Material Theme and Material Icon Theme.
    3. Switch theme: Ctrl + K, Ctrl + T → choose a Material dark/light variant.
  • ⚙️Enable “Format on Save” (requires Prettier extension):
    1. Install Prettier Code Formatter via Extensions (Ctrl + Shift + X).
    2. Open Settings: Ctrl + , → search “Format on Save” → check box.
    3. Configure default formatter: Ctrl + Shift + P → “Format Document With…” → “Configure Default Formatter” → choose Prettier.
  • 🔗Use VS Code from terminal: code <folder-name> opens that folder in VS Code (verify “code” is on PATH).
  • 🎯Hide extras:
    1. Activity Bar: View → Appearance → uncheck “Activity Bar”.
    2. Mini Map: View → Appearance → uncheck “Mini Map”.
    3. Toggle Side Bar: Ctrl + B to show/hide Explorer.
    4. Switch Panels: Explorer (Ctrl + Shift + E), Search (Ctrl + Shift + F), Extensions (Ctrl + Shift + X).

📦 Installing NodeJS

  • 🔑Windows: There’s no official NVM for Windows ARM64, but you can install NodeJS directly or use “nvm-windows” if on x64.
  • 🔗To install NodeJS natively:
    1. Go to nodejs.org → Downloads → Windows.
    2. Choose Windows Installer (ARM64) if on ARM64, or Windows Installer (x64) if on x64.
    3. Run installer → accept defaults → finish.
    4. Restart terminal → run node -v and npm -v to verify installation.
  • ⚙️If on x64 you can also use nvm-windows (NVM clone):
    1. Install “nvm-windows” from its GitHub releases → unzip/run installer.
    2. Restart terminal → run nvm install 20.9.0 (or latest LTS) → nvm use 20.9.0.
    3. Then confirm with node -v and npm -v.
  • ⚠️If on ARM64 and you use nvm-windows, NodeJS will run under emulation (slower). Better to install native ARM64 binary directly.
  • 🔥Always pick the LTS version for stability (e.g., 20.x). “Current” is only for experimenting with new features.

🧪 Installing Postman

  • 🌐Visit postman.com/downloads.
  • ⬇️Download the Windows installer (x64 or ARM64). Installer is self-contained (no extra prompts).
  • 🚀Run the downloaded file → automatic installation → open Postman.
  • 🔍Use Postman to test HTTP APIs later in the course (set method, URL, send request, inspect response).

📡 Installing Wireshark

  • 🌐Visit wireshark.org/download.
  • 💾Choose the installer for your CPU:
    • 🔹x64: download stable .x64 installer.
    • 🔹ARM64: if stable ARM64 isn’t available, scroll to “Automated Builds” → select ARM64 (experimental but works).
  • ⚙️Run installer → accept defaults → ensure Npcap is checked (required for packet capture).
  • 🔍Open Wireshark → double-click your network interface (e.g., “Ethernet”) to start capturing packets.
  • 📊Perform a web request (e.g., in Postman) → stop capture → you’ll see HTTP packets you generated. (Details make more sense later in Networking section.)

🛠️ Task Manager & Programmer Calculator

  • 📋Task Manager:
    • ▶️Open: Right-click Taskbar → Task Manager or search “Task Manager.”
    • 📈View CPU, memory, disk, network usage of all processes.
    • 🔎Under “Details” tab, find node.exe to monitor NodeJS process CPU/memory usage.
  • 🔢Programmer Calculator:
    • ▶️Open Windows Calculator → switch to “Programmer” mode (☰ → Programmer).
    • ✨Convert numbers between different bases:
      • 🔟Decimal ↔ Binary ↔ Hexadecimal ↔ Octal
      • Example: Enter “5” → see binary “0101” and hex “0x5”.
      • Later in Buffers section, use this to understand bytes and encodings.

🚀 Testing a Simple NodeJS App

  • 📂Create a working folder on Desktop (e.g., MyNodeTest).
  • 📄In your terminal: cd Desktop && mkdir MyNodeTest && cd MyNodeTest.
  • 📝Create a text file: New-Item text.txt → open it in VS Code: code text.txt → enter content like “This text is coming from Node.” → save.
  • 🆕Create Node app file: New-Item app.js → open in VS Code: code app.js.
  • 🔧In app.js, copy/paste this code: 
      
const http = require('http');  
const fs = require('fs');  

const server = http.createServer();  
server.on('request', (req, res) => {  
  const result = fs.readFileSync('text.txt');  
  res.setHeader('Content-Type', 'text/plain');  
  res.end(result);  
});  

server.listen(4080, '127.0.0.1', () => {  
  console.log('Server running at http://' + server.address().address + ':' + server.address().port);  
});
  • ▶️Back in terminal: node app.js → see “Server running at http://127.0.0.1:4080”.
  • 🌐Open Postman → GET http://127.0.0.1:4080 → click “Send” → response = “This text is coming from Node.”
  • 📡Open Wireshark → select “Loopback” → click “Start Capture” → send request in Postman → stop Wireshark → verify HTTP packets (look for protocol HTTP and source 127.0.0.1).
  • ✅If you see the expected response in Postman, your setup is complete and works correctly!
  • 🎉Congratulations—you’re ready to move on with the course!
