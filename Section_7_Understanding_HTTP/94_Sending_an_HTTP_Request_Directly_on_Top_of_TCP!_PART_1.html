🎯Goal

Use Node’s net module to send a raw HTTP request to our simple HTTP server and inspect the TCP packet in Wireshark.

🔧Setup “net” Client

  1. Copy your simple TCP sender code into net-sender.js.
  2. Change host to localhost and port to 8050 (your HTTP server’s port).
  3. Add listeners:
    • socket.on('data', …) to log the HTTP response.
    • socket.on('end', …) to log when the connection closes.

🐟First Attempt

Send a dummy buffer:

let req = Buffer.from('hello');  
socket.write(req);

Result: Server replied 400 Bad Request – because it’s not valid HTTP.

🕵️‍♂️Capture in Wireshark

  1. Start HTTP server on port 8050.
  2. Run your normal HTTP client (e.g. node simple-client.js).
  3. In Wireshark, listen on Loopback, then immediately stop capture after the request.
  4. Filter for tcp.port == 8050 – find the HTTP request packet.
  5. Right-click → Copy → Bytes → As Hex Stream.

📋Paste & Send Raw HTTP

  1. In net-sender.js, replace dummy buffer with: 
    const raw = Buffer.from('YOUR_HEX_STREAM', 'hex');  
socket.write(raw);
  2. Run node net-sender.js.
  3. The server now receives a valid HTTP request and you’ll see the proper response logged.
