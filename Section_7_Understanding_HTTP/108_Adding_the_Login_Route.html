🔐 Login Routes & Body Parsing

🧐 Investigate Login Request

  • 🖥️Open DevTools → Network → click “Log in”.
  • 🔍See a POST /api/login 404 (not defined yet).
  • 📦Payload shows JSON with username & password.

📥 Read & Parse JSON Body

  • 🔗Add route handler: 
    server.route('POST','/api/login', (req,res) => {
  let body = '';
  req.on('data', chunk => { body += chunk.toString(); });
  req.on('end', () => {
    const data = JSON.parse(body);
    console.log(data); // { username, password }
  });
});
  • 🛠️We accumulate chunks, then JSON.parse to get an object.

🔑 Authenticate User

  • 👥Find user: const user = users.find(u=>u.username===data.username)
  • 🔒Check password: if(user && user.password===data.password)
  • ✅On success → res.status(200).json({message:'Logged in!'})
  • ❌On failure → res.status(401).json({error:'Invalid credentials'})

📡 Test Login Flow

  • ▶️Send correct credentials → 200 “Logged in!”.
  • 🚫Wrong credentials → 401 “Invalid credentials”.
  • 🔧Client uses HTTP status to show messages.
