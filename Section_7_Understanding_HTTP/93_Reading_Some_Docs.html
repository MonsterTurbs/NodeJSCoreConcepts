📚HTTP Module Variants

  • http – basic HTTP/1.1 (we use this)
  • http2 – HTTP/2 (later)
  • https – HTTP over TLS (later)

🔍Key Node.js HTTP Objects

Two “modes”: Server vs Client

Server side

  • http.createServer() → HttpServer
  • HttpServerResponse – the outgoing response message
  • IncomingMessage – request streamed in

Client side

  • http.request() → ClientRequest
  • Agent – manages underlying TCP connections
  • IncomingMessage – response streamed in

⚙️Streams, Not Buffers

Node says: “never buffer entire requests or responses.”
● Body comes in via streams (‘data’, ‘end’), not as one giant Buffer.
