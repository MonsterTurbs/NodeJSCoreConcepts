🚀 Your First Node.js Web Server – Beginner Notes

🌐 What Is a Web Server?

  • 💡A server can serve any protocol (TCP chat, HTTP JSON, etc.).
  • 🖥️A web server specifically serves HTML, CSS, JS to browsers.
  • 📱Browsers understand HTML + web APIs—no extra install needed!

📦 Project Setup

  • 📁Create folder simple-web and inside it server.js and a subfolder public.
  • 🛠️In public/index.html put basic HTML: 
    <!DOCTYPE html>
<html><head><title>Hello</title></head>
<body><h1>Hi from Node.js!</h1></body>
</html>

🖥️ Writing server.js

  • 📦Import modules: const http = require('http');
    const fs = require('fs').promises;
  • 🎧Create server and listen: 
    const server = http.createServer(async (req, res) => {
  // handle requests...
});
server.listen(9000, () => console.log('Running at http://localhost:9000'));

🔀 Routing “/”

  • 🔍Detect root URL and GET method: 
    if (req.method==='GET' && req.url==='/' ) { … }
  • 📄For "/", serve your HTML file.

📑 Serving HTML with Streams

  • ⚙️Set response header: res.setHeader('Content-Type','text/html')
  • 📂Read & stream file: 
    const fh = await fs.open('./public/index.html');
const rs = fh.createReadStream();
rs.pipe(res);
  • 🚀Efficient: streams send file in small chunks, not whole memory.

🔄 Recap

  • 1️⃣Create HTTP server with http.createServer.
  • 2️⃣Listen on port 9000.
  • 3️⃣Route GET "/" → set header → pipe HTML file to response.
  • 🎉Open http://localhost:9000 in browser to see your page!
