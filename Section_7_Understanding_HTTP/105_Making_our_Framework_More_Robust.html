🛡️ Robust Routing: Study Notes

⚙️ What Is Robustness?

  • 💪Robust apps handle any data or URL safely.
  • 🛑They don’t crash when you hit an undefined route.
  • 🔄Instead, they return a friendly error message.

🚫 Handle “Not Found” Routes

  • 🔍Before calling a route handler, check if it exists:
    • const key = req.method.toLowerCase() + req.url;
if (!this.routes[key]) {
  return res
    .status(404)
    .json({ error: `Cannot ${req.method} ${req.url}` });
}
  • ✅If missing, send 404 + JSON error.

🔧 Adding status & json Helpers

  • 🏷️Attach to res before routes:
    • res.status = code => { 
  res.statusCode = code; 
  return res; 
};
res.json = data => {
  res.setHeader('Content-Type','application/json');
  res.end(JSON.stringify(data));
};
  • 🔗Chaining: res.status(400).json({...})

🛣️ Defining Routes in Butter

  • ➕Simple syntax: 
    app.route('get','/', (req,res)=>{
  res.sendFile('./public/index.html','text/html');
});
app.route('post','/login',(req,res)=>{
  res.status(400).json({error:'Bad login'});
});
  • 🚀Now you avoid big if/switch blocks!

🎉 Why It Rocks

  • 🎯Cleaner, DRYer code—no repetitive checks.
  • 🤝Front-end teams get consistent JSON + status replies.
