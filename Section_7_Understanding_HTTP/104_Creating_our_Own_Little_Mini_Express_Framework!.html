🔧 Build a Mini “Butter” Framework – Study Notes

📋 Why a Framework?

  • ✂️We copy-&-pasted route logic many times.
  • 🛠️Better to extract into reusable functions/objects.
  • 🚀Makes code cleaner and easier to add new routes.

🧰 Create the “Butter” Class

  • 📦Make a new file: butter.js.
  • 💡Import HTTP & export class: 
    const http = require('http');
class Butter { … }
module.exports = Butter;
  • 🏗️In constructor, create HTTP server: 
    constructor(){
  this.server = http.createServer();
}

🎧 Listen Method

  • 🔌Add inside class: 
    listen(port, cb){
  this.server.listen(port, cb);
}
  • ✅Usage in server.js: 
    const app = new Butter();
app.listen(4060,()=>console.log('Live'));

🛣️ Routing Table

  • 🗺️Store routes in an object: 
    constructor(){
  this.routes = {};
  this.server.on('request', this.handle.bind(this));
}
  • ➕Define a route method: 
    route(method, path, cb){
  this.routes[method+path] = cb;
}

🔄 Handle Requests

  • 🚦On each request, find matching route: 
    handle(req,res){
  const key = req.method.toLowerCase()+req.url;
  const fn = this.routes[key];
  if(fn) fn(req, res);
  else {
    res.statusCode=404;
    res.end('Not Found');
  }
}
  • 🎉Now app.route('get','/', handler) works!

📁 Utility: sendFile

  • 🍞Attach to response: 
    res.sendFile = async (path, type)=>{
  res.setHeader('Content-Type',type);
  const fh = await fs.open(path,'r');
  fh.createReadStream().pipe(res);
};
  • ✨In your route: 
    app.route('get','/', (req,res)=>{
  res.sendFile('./public/index.html','text/html');
});
