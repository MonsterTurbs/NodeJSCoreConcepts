📦Include HTTP Module & Agent

• Use Node’s built-in HTTP module:
const http = require('node:http'); 😊
• Create an agent to manage TCP connections:
const agent = new http.Agent({ keepAlive: true });
Agents let you reuse or close sockets when sending multiple requests.

🛠️Build Request Options

Configure where and how to send your HTTP request:

  • agent: which TCP connection to use
  • hostname: server address (e.g. 'localhost')
  • port: server port (e.g. 8050)
  • method: HTTP verb (e.g. 'POST')
  • path: endpoint URL (e.g. '/upload')
  • headers: extra info, like content type

✍️Sending the Body as a Stream

• The request object is a duplex stream.
• Write chunks of data with req.write(…): you can call it many times.
• Call req.end() (optionally with one final chunk) to signal: “I’m done sending.” 👍

📬Handling the Server Response

• Listen for the 'response' event once:
req.on('response', res => { … })
• Inside, res is a readable stream:
  – Read status code: res.statusCode
  – Read headers: res.headers
  – Read body chunks: res.on('data', chunk => { … }) 😊

🔀Chunked vs. Content-Length

• Transfer-Encoding: chunked
  – Send body in unknown-size chunks;
  – End with req.end() marker.

• Content-Length: N
  – Tell server exactly how many bytes you’ll send;
  – Useful when you know body size ahead.

Choose one per message—can’t use both at once!
