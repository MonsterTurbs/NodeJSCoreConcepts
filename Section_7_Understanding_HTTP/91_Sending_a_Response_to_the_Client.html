📝Collect Request Body

1. Create a variable to accumulate data:
let body = '';
2. On each data chunk:
req.on('data', chunk => body += chunk.toString());
3. When finished:
req.on('end', () => { dataObj = JSON.parse(body); }); 😊

🔑Read Custom Header

• Access any header from the request:
const user = req.headers.name;
• Useful for simple auth (but not secure in real apps). 🔒

📤Respond with JSON

1. Send status and headers:
res.writeHead(200, { 'Content-Type': 'application/json' });
2. Send body and end:
res.end(JSON.stringify({
  message: `Post "${dataObj.title}" created by ${user}`
}));

📥Handle Response on Client

1. Listen for server response:
req.on('response', res => { … });
2. Read status & headers:
console.log(res.statusCode, res.headers);
3. Read body chunks:
res.on('data', chunk => console.log(chunk.toString()));
4. On end:
res.on('end', () => console.log('Done')); 🎉
