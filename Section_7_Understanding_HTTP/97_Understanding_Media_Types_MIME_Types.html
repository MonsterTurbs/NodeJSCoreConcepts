🗂️What Are Media (MIME) Types?

Just like your operating system uses file extensions (e.g. .pdf, .jpg) to know how to open files, HTTP uses the Content-Type header to tell the other end “how to read” the message body bits.

⚙️Media Type Format

Every media type has this exact format:

type/subtype[; parameter=value]
  • type: general category (e.g. text, image, application)
  • subtype: specific format (e.g. css, png, json)
  • parameter (optional): extra info like charset (;charset=utf-8)

📚Discrete vs. Multipart

Media types belong to two classes:

  • Discrete – a single file, e.g. text/css or image/jpeg
  • Multipart – multiple parts in one message, e.g. multipart/form-data; boundary=… for file uploads

🔍Finding the Right Type

Go to the IANA registry to see official media types:

iana.org/media-types

Search for your subtype. For example:

  • image/png for PNG images
  • text/javascript (preferred) for JS files
  • application/json for JSON data

📦Example: File Upload (Multipart)

Sending two items (a text and a file) in one request:

Content-Type: multipart/form-data; boundary=----WebKitFormBoundaryXYZ

------WebKitFormBoundaryXYZ
Content-Disposition: form-data; name="username"

Alice
------WebKitFormBoundaryXYZ
Content-Disposition: form-data; name="avatar"; filename="pic.png"
Content-Type: image/png

(binary data…)
------WebKitFormBoundaryXYZ--

🔒Bonus: Magic Numbers

Some servers check file “magic numbers” (first bytes) to verify type, e.g. PNG files start with 89 50 4E 47. This guards against wrong extensions.
