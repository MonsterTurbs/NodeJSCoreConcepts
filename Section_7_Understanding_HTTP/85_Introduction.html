🌐What is HTTP?

HTTP (HyperText Transfer Protocol) is the foundation of the Web. It defines how browsers and servers talk. Every website, API, or web app you use runs on HTTP(S).

📦Node.js & HTTP Module

Node.js has a built-in http module. It lets you create web servers, handle requests & send responses. All popular frameworks (Express, Koa, Nest…) build on this core.

🛠️Main HTTP Concepts

  • Requests: Method (GET, POST…), URL, headers, body
  • Responses: Status code, headers, body
  • Routing: Map URLs + methods to handler functions
  • Middleware: Pre-/post-processing of requests

🚀Building “Butter” Framework

You’ll create a mini-Express called Butter. It supports:

  • Routing & URL parameters
  • JSON parsing & static file serving
  • Middleware chains (next())
  • Helpers like res.json(), res.sendFile()

🎯Why Master HTTP?

Understanding raw HTTP & Node’s module empowers you to:

  • Read/write any web framework’s internals
  • Customize performance & security (TLS, headers)
  • Build robust APIs without black-box libraries
  • Level-up full-stack skills—front & back end
