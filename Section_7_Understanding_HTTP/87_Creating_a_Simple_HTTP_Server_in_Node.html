🚀Include the HTTP Module

Use Node’s built-in HTTP feature—no install needed! const http = require('node:http'); The node: prefix means “native to Node.js.”

🛠️Create & Start the Server

```js const server = http.createServer(); server.listen(8050, () => { console.log('Server listening on http://localhost:8050'); }); ``` This opens port 8050 on all network interfaces (by default).

📬Handle Incoming Requests

Listen for the 'request' event to see each HTTP call: ```js server.on('request', (req, res) => { // req = incoming request (readable stream) // res = outgoing response (writable stream) }); ```

🔍Log Method, URL & Headers

Inside your handler: ```js console.log('→ Method:', req.method); console.log('→ URL:', req.url); console.log('→ Headers:', req.headers); ``` • Method tells what action the client wants (GET, POST…).
• URL is the path after / (like /users).
• Headers describe the request format and metadata.

📦Read the Body as a Stream

Don’t do req.body—that would load all data into memory!
Instead, stream it chunk by chunk: ```js req.on('data', chunk => { console.log('📥 Chunk:', chunk.toString()); }); ``` Great for large uploads without crashing!

✅Putting It All Together

const http = require('node:http');

const server = http.createServer();
server.on('request', (req, res) => {
  console.log('→', req.method, req.url);
  console.log('Headers:', req.headers);

  req.on('data', chunk => {
    console.log('Body chunk:', chunk.toString());
  });

  // send a simple response
  res.writeHead(200, { 'Content-Type': 'text/plain' });
  res.end('Hello, HTTP!');
});

server.listen(8050, () => {
  console.log('Server listening on http://localhost:8050');
});

Visit http://localhost:8050 in your browser or use curl/postman to test!
