🔍Recap

Previously, we copied only the HTTP start-line and headers in hex—no body. Now we’ll grab the body too and send the full raw HTTP message over TCP.

📦Copying the Body

  1. In Wireshark find the HTTP packet containing the JSON body.
  2. Select the bytes from the opening “{” to the closing “}”.
  3. Right-click → Copy → Bytes → As Hex Stream.
  4. Paste into your code as a second Buffer.from(..., 'hex').

🔧Building the Full Request

Concatenate header-buffer and body-buffer before sending:


const head = Buffer.from('...hex for start-line & headers...', 'hex');
const body = Buffer.from('...hex for JSON body...',   'hex');
const req  = Buffer.concat([head, body]);
socket.write(req);

🕵️‍♂️Server Behavior

  • Server waits until it has received the declared Content-Length bytes before it fires its request-end event.
  • Only then does it parse JSON, log data, and send back an HTTP response.

📡Wireshark Verification

  1. Capture Loopback traffic while running your TCP client.
  2. Confirm two HTTP packets: one with full request (start-line, headers, body) and one with response.
  3. Inspect delimiters (\r\n\r\n) separating head/headers from body.

✏️What You Learned

  • HTTP is just text+CRLF delimiters sent over a TCP stream.
  • You can craft raw HTTP by concatenating byte-buffers of hex data.
  • Node’s http module automates parsing; net shows the raw bytes.
