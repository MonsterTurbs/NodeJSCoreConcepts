✏️ CRUD Routes Overview

🆕 Create Post

  • 📥Read JSON body (parsed by middleware): req.body.title & req.body.body
  • 🆔Make new post object: 
    const post = {
  id: posts.length + 1,
  title,
  body,
  userId: req.userId
};
  • ➕Add to array & respond: 
    posts.unshift(post);
res.status(201).json(post);

✏️ Update Profile

  • 📥Read inputs: req.body.username, req.body.name, req.body.password
  • 🔍Find your user: 
    const user = users.find(u => u.id===req.userId);
  • ✏️Apply changes: 
    user.username = username;
user.name     = name;
if(password) user.password = password;
  • ✅Send back updated info: 
    res.status(200).json({
  username: user.username,
  name:     user.name
});

🔒 Log Out

  • 🗑️Remove session record: 
    const idx = sessions.findIndex(s => s.userId===req.userId);
if(idx>=-1) sessions.splice(idx,1);
  • 🍪Clear cookie: 
    res.setHeader("Set-Cookie",
  "token=; Path=/; Expires=Thu, 01 Jan 1970 00:00:00 GMT");
  • 📤Confirm log out: 
    res.status(200).json({message:"Logged out successfully"});
