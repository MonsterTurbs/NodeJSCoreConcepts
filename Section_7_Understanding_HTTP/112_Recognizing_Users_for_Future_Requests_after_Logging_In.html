🔐 Sessions & Cookies – Beginner Notes

📝 1. Store Sessions In Memory

  • 📂Use an array (or database) to hold sessions: 
    const sessions = [];
  • 🔑Each session = `{ userId, token }`

🚪 2. Login & Generate Token

  • 🔍On successful login: 
    const token = Math.floor(Math.random()*1e10).toString();
  • ➕Save session: 
    sessions.push({ userId: user.id, token });

🍪 3. Send Cookie To Browser

  • ✉️Tell browser to store token: 
    res.setHeader("Set-Cookie", "token=" + token + "; Path=/");
  • 🔄Browser saves it and auto-sends in every request.

🔑 4. Read & Parse Cookie

  • 📥Get raw header: 
    const raw = req.headers.cookie;
  • 🔍Extract token: 
    const token = raw.split("=")[1];

✔️ 5. Verify Session

  • 🕵️‍♂️Find in sessions: 
    const session = sessions.find(s => s.token === token);
if (!session) {
  res.statusCode = 401;
  return res.end("Unauthorized");
}
  • ✅If found, user is authenticated.

👤 6. Serve Profile

  • 📋Once validated, send user info: 
    res.statusCode = 200;
res.end(JSON.stringify({
  name: user.name,
  username: user.username
}));
