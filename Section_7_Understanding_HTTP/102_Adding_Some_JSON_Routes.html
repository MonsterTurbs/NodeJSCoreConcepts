🔑 JSON Routes – Beginner Study Notes

📦 What Are JSON Routes?

  • 🌐We can add API-style endpoints (routes) to send back JSON data.
  • ✉️Each route checks req.method and req.url.
  • 🔄Use res.setHeader('Content-Type','application/json') to declare JSON responses.
  • 🚦Use res.statusCode = … to pick appropriate HTTP status (200, 401, etc.).

🔐 POST /login

  • 🚀Route signature: 
    if (req.method==='POST' && req.url==='/login') { … }
  • ⚙️Set headers & status: 
    res.setHeader('Content-Type','application/json');  
res.statusCode = 200;
  • 📤Send JSON body & end response: 
    const body = { message: 'Logging in…' };  
res.end(JSON.stringify(body));
  • ✅Postman test: • Method: POST • URL: http://localhost:9000/login → get `{"message":"Logging in…"}`

🛠️ PUT /user

  • ✏️Route signature: 
    if (req.method==='PUT' && req.url==='/user') { … }
  • ⚙️Set headers & status: 
    res.setHeader('Content-Type','application/json');  
res.statusCode = 200;
  • 📤Send JSON body & end: 
    const body = { message: 'Updating your info…' };  
res.end(JSON.stringify(body));
  • 🔒Example error scenario: 
    res.statusCode = 401;  
const body = { message: 'Please log in first' };  
res.end(JSON.stringify(body));

⏹️ Why Use res.end()?

  • 📛res.write() only writes data—doesn’t finish the response.
  • ✔️res.end() writes (optional) & signals “body complete.”
  • 🔄Without end(), client (Postman/Browser) keeps waiting 🔄
