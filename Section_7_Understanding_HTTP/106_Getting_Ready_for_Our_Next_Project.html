🚀 Poster App: Beginner Setup Notes

📁 Create New Project “poster”

  • 🌱Make a folder named poster inside your http directory.
  • 📂Inside poster, create public (for front-end files) and server.js.
  • 🔧We'll power backend with our butter.js framework.

🛠️ Move & Require “butter.js”

  • ✂️Drag your butter.js into the http root (next to poster).
  • 🔗In poster/server.js, import it with: 
    const butter = require('../butter');
  • 💡Later you’ll publish it on npm—then just require('butter').

📥 Add Front-End into public

  • 📦Download **poster-front-end.zip** from the video resources.
  • 📂Unzip and copy **index.html**, **styles.css**, **script.js** into poster/public.
  • 📂Your folder now looks like: 
    poster/
├─ public/
│  ├ index.html
│  ├ styles.css
│  └ script.js
└ server.js

🖥️ About the Front-End Code

  • 💻It’s a React app bundled by Webpack—don’t edit script.js.
  • 🎨HTML & CSS live in index.html & styles.css.
  • 🔗API calls marked with // 📡 API CALL use Axios to talk to our backend.

🔌 How API Calls Will Work

  • 🌐Front-end uses relative URLs (e.g. /login), so browser calls our server’s origin.
  • 📡Axios sends GET/POST to endpoints we’ll define in server.js.
  • 🔄Responses (JSON data) will drive login, post-creation, & feed display.
