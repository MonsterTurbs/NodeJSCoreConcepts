🚀What is Postman?

● A desktop tool to send HTTP requests and view responses.
● Great for API testing, designing & documenting endpoints.
● Alternative tools: Swagger, HTTPie, cURL, etc.

🔧Methods, URL & Params

● Choose HTTP method: GET, POST, PUT, PATCH, DELETE.
● Enter full URL: http://localhost:8050/create-post.
● Add query parameters in Params tab:
?key1=value1&key2=value2 😊

📋Headers Explained

● Everything in Postman UI → becomes HTTP headers.
● Common ones:
  – Authorization (e.g. Bearer token)
  – Content-Type (e.g. application/json)
  – Accept (what response types client can handle)
  – Connection (keep-alive vs. close)
  – Accept-Encoding (e.g. gzip for compression)

📦Body Types

● none: no body → no Content-Type or Content-Length.
● form-data: key/value pairs + files (multipart).
● x-www-form-urlencoded: simple form fields.
● raw: free text, JSON, XML, GraphQL.
● binary: upload a single file.
● Choose type → Postman auto-sets headers. 👍

🔍Server Receives

● Node.js gives you:
  – req.method, req.url
  – req.headers
  – req as a readable stream for body.
● It does not auto-parse body for you.

🛠️Parsing the Body

● Collect chunks:
let body = '';
req.on('data', c => body += c.toString());
● On 'end':

  • JSON: const obj = JSON.parse(body);
  • Form-data: use busboy, multer
  • URL-encoded: use body-parser
  • GraphQL: use a GraphQL parser
