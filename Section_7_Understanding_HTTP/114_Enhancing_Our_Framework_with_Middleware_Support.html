🛠️ Adding Middleware to Butter

🔍 What Is Middleware?

  • 🔄Functions that run before your route handler.
  • 🚦Can perform tasks like auth, JSON parsing, CORS, logging…
  • ➡️Call `next()` when done so the next middleware or route runs.

📜 Declaring Middleware

  • ✏️In your app code: 
    // register three middlewares
server.beforeEach((req,res,next) => {
  console.log("1st middleware")
  setTimeout(() => next(),2000)
})
server.beforeEach((req,res,next) => {
  console.log("2nd middleware")
  setTimeout(() => next(),2000)
})
server.beforeEach((req,res,next) => {
  console.log("3rd middleware")
  setTimeout(() => next(),2000)
})

⚙️ Framework Changes: Store & Run

  • 📂Add in constructor: 
    this.middleware = [];
  • ➕`beforeEach(fn)` pushes to array: 
    this.middleware.push(fn)
  • 🏃Invoke all before route: 
    runMiddleware(req,res, list, i=0){
  if(i===list.length) {
    // all done → call route
    this.routes[req.method+req.url](req,res)
  } else {
    list[i](req,res,()=> runMiddleware(req,res,list,i+1))
  }
}

🔁 Using Recursion

  • 🔄Define a function that re-calls itself with `i+1`.
  • ⛔Exit when `i === middleware.length` → then run route.
  • 💡Automatically handles any number of middlewares!

🚀 Final Flow

  • 1️⃣Incoming request → `runMiddleware(req,res,middleware,0)`
  • 2️⃣Each middleware runs `fn(req,res,next)` in order
  • 3️⃣After all, your route handler runs!
