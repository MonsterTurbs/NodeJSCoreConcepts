📤 File Upload Route – Beginner-Friendly Notes

📂 Create Storage Folder

  • 🗄️Make a new directory in your project, e.g. storage/.
  • 📁Uploaded files will be saved here.

🚀 Define Upload Route

  • 🔍In server.js, add: 
    if (req.method==='PUT' && req.url==='/uploads') { … }
  • ✏️Use PUT since upload is idempotent (same file gets overwritten).

⚙️ Open & Stream to File

  • 📂Create (or overwrite) target file: 
    const fh = await fs.open('./storage/uploaded-file.jpg','w');
  • 📈Make a writable stream: 
    const ws = fh.createWriteStream();
  • 🚰Pipe incoming request body into file: 
    req.pipe(ws);

✅ Finish & Respond

  • 🏁Wait for upload to complete: 
    req.on('end', ()=>{ … });
  • 📤Send JSON success message: 
    res.setHeader('Content-Type','application/json');
res.end(JSON.stringify({ message: 'File uploaded!' }));
  • 🚦Test with Postman: • Method: PUT • URL: http://localhost:9000/uploads • Body → “binary” → choose a file → get {"message":"File uploaded!"}

💡 Why Streams?

  • ⚡Efficiently handles large files.
  • 🧠Only small chunks held in memory at once.
  • 🔄Better performance vs. buffering entire file.
