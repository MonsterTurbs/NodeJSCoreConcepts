🛠️Creating a TCP “Net” Server

We use Node’s net.createServer() to build a simple TCP server that listens on a port.


const net = require('net');
const server = net.createServer(socket => {
  socket.on('data', data => {
    console.log(data.toString('utf8'));
  });
});
server.listen(8000);

🔍Reading Raw HTTP Requests

When Postman (or any HTTP client) sends a request, our socket.on('data') logs the clear-text HTTP:

  • Request line (e.g. GET /path HTTP/1.1)
  • Headers (Host:, User-Agent:, etc.)
  • Body (if any)

🕵️‍♂️HTTP Is Clear-Text!

All HTTP messages travel unencrypted over TCP. Anyone sniffing the network can read everything:


GET /login HTTP/1.1
Host: localhost:8000
Custom-Header: hello
Content-Type: application/json

{"user":"Jack","pass":"1234"}

→ Sensitive data (passwords, tokens) are exposed.

📤Sending a Raw HTTP Response

We manually craft the raw response bytes and write them back on the same socket:


const response = Buffer.from('HTTP/1.1 200 OK\r\nContent-Type: application/json\r\n\r\n{"msg":"Hi!"}', 'utf8');
socket.write(response);

Postman then shows the JSON reply and status 200.

⏳Connection Keep-Alive vs Close

  • By default HTTP/1.1 uses persistent (keep-alive) connections.
  • You can close the TCP socket manually: socket.end().
  • Or respect the Connection: close header and let client/server drop.

🔑Key Takeaways

  • HTTP = text + CRLF delimiters over TCP.
  • All headers & bodies are visible in plain text.
  • Use HTTPS/TLS to encrypt and protect sensitive data.
  • Node’s http module automates parsing; raw net shows how it really works under the hood.
