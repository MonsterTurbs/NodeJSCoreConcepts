🛠️ Serving & API Routes: Beginner Notes

🚀 Start Server & Static Routes

  • 🌐Pick a port: const port = 8000
  • ⚙️Init framework: const server = new butter();
  • ▶️Listen: server.listen(port, ()=>console.log(...));
  • 📂Define file routes: 
    server.route('GET','/', (req,res)=>res.sendFile('./public/index.html','text/html'));
    Repeat for /styles.css & /script.js.

🔍 Test Static Serve

  • 🔎Open http://localhost:8000/ → HTML, CSS, JS load OK.
  • ❗Check Network → 404 for /api/posts & /api/user.
  • 📋Front-end Axios tries GET /api/user & GET /api/posts.

💾 Mock “Database” Data

  • 👥Users array: 
    const users = [
  {id:1,name:'Liam Brown',username:'liam23',password:'string'},
  {id:2,name:'Meredith Green',username:'meritt',password:'string'},
  {id:3,name:'Ben Adams',username:'benpoet',password:'string'}
];
  • 📝Posts array: 
    let posts = [
  {id:1,title:'Post title',body:'Lorem ipsum…',userId:1}
];

🔗 Define GET /api/posts

  • 📡Add route: 
    server.route('GET','/api/posts',(req,res)=>{
  // merge author → see next card
  res.status(200).json(posts);
});
  • 👾Client receives JSON array of posts.

🧬 Merge Author into Posts

  • 🔄Map posts, find user: 
    posts = posts.map(post=> {
  const user = users.find(u=>u.id===post.userId);
  post.author = user.name;
  return post;
});
  • ✨Now each post has author for front-end display.

✅ Test /api/posts

  • 🔄Refresh browser → no more 404 for posts.
  • 📦Network preview shows: 
    [
  {id:1,title:'…',body:'…',userId:1,author:'Liam Brown'}
]
  • 🎉Front-end renders title, body & author on page!
