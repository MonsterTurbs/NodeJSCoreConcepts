🗜️ Compression Basics

🔍 What Is Compression?

  • Encoding data using fewer bits (zeros & ones).
  • Reduces file size without changing its content.
  • Two types:
    • Lossless: no information lost.
    • Lossy: some detail dropped (e.g. images, video).

🔒 Lossless vs Lossy

  • Lossless: exact original can be reconstructed. Examples: text files, gzip, PNG.
  • Lossy: drops tiny details for smaller size. Examples: JPEG images, MP3 audio, video codecs.

🛠️ Node.js zlib Example

  • Use built-in zlib module:
    zlib.createGzip() to compress, zlib.createGunzip() to decompress.
  • Stream example: 
    fs.createReadStream('big.txt')
  .pipe(zlib.createGzip())
  .pipe(fs.createWriteStream('big.txt.gz'))
  • Gzip is lossless—data restored exactly!

🚀 Why Compression Matters

  • Storage: smaller files → lower disk costs.
  • Transfer: less data over network → faster uploads/downloads.
  • Example: 10 GB text → 2 GB gzip (~80% saved!)

📊 Real-World Video Example

  • Uncompressed 1080 p 7 min video → 57 GB!
  • Lossy tool („compressor“) → ~100 MB (~500× smaller).
  • Gzip (lossless) → 3.8 GB (~15× smaller) with zero quality loss.
