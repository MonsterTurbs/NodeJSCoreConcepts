🎨 Lossy Compression

❓ What Is Lossy Compression?

  • We lose some data (quality) to shrink file size.
  • Ideal for multimedia (images, audio, video), not for text/UTF-8.
  • Once done, you cannot restore the exact original.

📂 Common Lossy Formats

  • Images: JPEG (removes colors/details humans don’t notice)
  • Audio: MP3, AAC (drops inaudible frequencies)
  • Video: H.264 (saves key frames + references motion)

💡 Why It Works

  • Humans can’t perceive all details—drop “unimportant” bits.
  • Images: merge similar pixels → big size drop (50 MB → ~800 KB!)
  • Audio: collapse frequencies outside hearing range.
  • Video: store full frames + only changes between frames.

🚫 Don’t Re-Compress Lossy Files

  • Re-zipping/jpeg-compressing an already lossy file gives no gain.
  • May even grow size—wasteful compute for no benefit.

🔧 How to Apply

  • Usually a one-time step before serving files.
  • Tools: ffmpeg, ImageMagick, online converters, or “Save As → JPEG” in editors.
  • Pick quality/bitrate slider to balance size vs. look/sound.
