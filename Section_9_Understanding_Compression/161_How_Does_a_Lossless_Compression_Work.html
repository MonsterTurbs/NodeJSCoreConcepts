🗜️ How Lossless Compression Works

🔧 Compression Methods

  • gzip (built on deflate)
  • brotli (often better ratio but slower)
  • deflate (core algorithm)
  • All return transform streams in Node’s zlib

📦 LZ77 (Lempel–Ziv)

  • Idea: replace repeated chunks with “pointer” back to first occurrence
  • Example: “Mr. Bingley” appears 3× → store once + 3 pointers
  • Pointers encode distance back + length (e.g. 16-bit distance + 4-bit length)
  • Saves bytes by not re-storing repeated data

🧮 Huffman Coding

  • Assign shorter codes to common symbols, longer to rare ones
  • Compute symbol frequencies (e.g. “t” appears 83×, “v” 9× in text)
  • Build a binary tree to generate prefix codes
  • Example: “t” → 4 bits, “v” → 8 bits → big savings over fixed 8 bits/char

🔗 Combining LZ77 + Huffman

  • gzip, brotli, deflate use LZ77 then Huffman on those pointers/data
  • Result: transform stream that outputs fewer bits, exactly reversible

📄 Text Example

  • Original text: 1 164 bytes
  • gzip via zlib.createGzip() → ~684 bytes (≈1.7× smaller)
  • Shows real-world half-size savings on random novel excerpt!
