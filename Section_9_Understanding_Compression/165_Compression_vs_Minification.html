✂️ Minification vs Compression

📝 What Is Minification?

  • Removes “extra” text in source files (JS/CSS/HTML): comments, whitespace, long names
  • Shortens variable/function names to single letters
  • Result: same code behavior but smaller file size
  • Not altering the binary format—still plain JS/CSS/HTML text 😊

🔍 How It Differs from Compression

  • Minification: strips and renames in source code (text-level)
  • Compression: encodes binary data (gzip, brotli…) using algorithms like LZ77/Huffman
  • Minified files still readable by JS engine; compressed files need to be decompressed first

⚙️ Example Workflow

  • Take your JS file → minifyjs.com or build-step tool → get app.min.js (½ size)
  • Then run compression: 
    brotli app.min.js -o app.min.js.br
    → yields even smaller file (~700 B in demo)

✅ Best Practice

  • Use both minification + compression on web assets
  • Minify to remove useless text, then gzip/brotli to encode efficiently
  • Other size-reducing techniques (resizing, cropping) also differ from compression
  • Minification ≠ lossy compression—no quality/data loss in minification 👍
