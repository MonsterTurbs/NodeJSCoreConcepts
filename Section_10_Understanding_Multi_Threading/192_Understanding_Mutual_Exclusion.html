🔐 Mutual Exclusion: Beginner-Friendly Notes

🤝 What Is Mutual Exclusion?

  • 🔒If one thread enters a critical section (shared code/resource), no other thread may enter it at the same time.
  • ⚠️Prevents race conditions when multiple threads read/write the same data.

🔄 Spinlock

  • ⏳Use a shared flag (lock) initialized to 0.
  • ↪️When entering critical section: 
    while (atomicCompareExchange(lock, 0, 1) === 1) { /* spin */ }
  • ⏏️On exit: 
    atomicStore(lock, 0);

⚡ Spinlock Drawbacks

  • 🔥100% CPU usage while spinning—wastes cycles.
  • 🚫Not ideal when critical sections run longer or many threads wait.

🛠️ Semaphore (Suspend/Resume)

  • 😴Threads call Atomics.wait(typedArray, idx, 1) to sleep when locked.
  • 🔔Lock release uses Atomics.notify(typedArray, idx, 1) to wake one waiter.
  • 💡Combines atomic test+set with suspend/resume to save CPU.

💻 C vs JavaScript

  • 📜In C: use pthread_mutex_lock / pthread_mutex_unlock or sem_wait / sem_post.
  • 🔗In JS: build locks on SharedArrayBuffer + Atomics.
  • 🤖Concepts are universal—once you know one, you adapt to any language.
