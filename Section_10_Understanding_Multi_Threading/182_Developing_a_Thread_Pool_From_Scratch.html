🧰 DIY Thread Pool in Node.js

🔍 What You'll Build

  • A simple “worker pool” to reuse threads instead of spawning per task.
  • Improves performance by avoiding thread‐creation overhead. ⚡

📦 Core Concepts

  • Pool Size: Fixed number of threads ready to run jobs.
  • Job Queue: Holds incoming tasks when all threads are busy.
  • Worker Threads: Take tasks from queue, process, then signal completion.

  • Maintain freeWorkers list and taskQueue array.
  • When a job comes:
    • If freeWorkers.length>0, assign job immediately.
    • Else taskQueue.push(job).
  • On worker message (completion):
    • Return worker to freeWorkers.
    • If taskQueue not empty, dequeue and assign next job.

💡 Tips

  • Use worker.terminate() on shutdown to clean up threads.
  • Monitor queue length & busy threads to tune pool size. 📈
  • Avoid unbounded queue growth—impose max queue length or reject excess tasks. 🚫
