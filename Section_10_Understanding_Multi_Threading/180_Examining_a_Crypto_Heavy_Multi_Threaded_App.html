🔐 Crypto & Worker Threads

🚀 Demo Overview

  • We spawn N worker threads running calc-crypto.js.
  • Each thread generates random numbers using Node’s crypto.randomFillSync(), sums them, and reports back.
  • Main thread aggregates results and logs total time & sum.

❌ Performance Issue

  • More threads → slower! 🤯
  • Bottleneck: calling crypto.randomFillSync() millions of times blocks each worker.

🔧 Batch Solution

  • Allocate a buffer of size BATCH_SIZE bytes once.
  • Fill it with random data in one call (crypto.randomFillSync(buf)).
  • In each loop, read 16-bit slices from the buffer, and refill when exhausted.
  • Result: threads spend less time in the blocking crypto call → near-linear speedup! 🚄

💡 Key Takeaways

  • Not all blocking calls scale in threads—identify bottlenecks with testing.
  • Batch expensive operations when you must call them repeatedly.
  • With batching, adding more threads yields the expected performance gains.
