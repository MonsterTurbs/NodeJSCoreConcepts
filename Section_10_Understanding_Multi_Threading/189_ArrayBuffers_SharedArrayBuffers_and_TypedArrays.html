🔢 ArrayBuffers & Typed Arrays

📦 Raw Binary: ArrayBuffer

  • 🧩ArrayBuffer is pure bytes—no interpretation.
  • ⚠️Cannot read/write directly; must use a view.
  • 🆕Allocate: new ArrayBuffer(bytes).

🔭 Views: Typed Arrays

  • 🔢TypedArray (e.g. Uint8Array, Int16Array) view raw data.
  • 📏Element size fixed: Uint8Array = 1 byte, Int16Array = 2 bytes, etc.
  • 👁️‍🗨️Wrap buffer: new Uint8Array(arrayBuffer).

🧱 Node.js Buffer

  • ⚙️Built on Uint8Array; adds methods (slice, concat).
  • 💨Uses an 8 KB internal pool for fast allocations.
  • ⚗️Allocate vs from:
    • Buffer.alloc(n) → new memory.
    • Buffer.from(str) → encodes string.

🔄 Endianness

  • 🔀Big-endian: most-significant byte first.
  • ↔️Little-endian: least-significant byte first.
  • ⚠️Must match when sharing across systems/languages.

💡 When to Use

  • 🎨Ideal for binary data (images, network packets, shared memory).
  • 🔧Use Buffer in Node.js for convenience.
  • 📚Use TypedArrays in browser or when fixed element size needed.
