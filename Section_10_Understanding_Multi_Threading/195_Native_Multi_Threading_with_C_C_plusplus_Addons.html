🛠️ Node.js Native Add-ons & Multithreading

💡 Why Use Native Add-ons?

  • ⚡Run C/C++ code directly inside Node.js for 🔥 high CPU tasks
  • 🚀Massive speedups (e.g. prime gen in 1s vs 60s in JS)
  • 🤝Leverage existing C/C++ libraries & multithreading

🔧 How Native Add-ons Work

  • 🔗Write C/C++ functions (e.g. `generatePrimes`) & compile into a binary module
  • 🔌Use Node-API (N-API) or `node-addon-api` to bind C++ ↔ JS
  • 📦`require('bindings')('your_module')` → call as normal JS function

📑 Binding Example

  • 🗂️binding.cc defines wrapper: 
    napi_create_function(…, "generatePrimes", generatePrimesWrapped)
  • 🔄Convert between JS types & C++ (arrays, strings, BigInt)
  • 🎯Run C++ logic off the main thread, callback when done

📈 Real-World Speedup

  • 🕐JS Prime gen (1 thread): ~60 s
  • 🏃‍♂️C++ Prime gen (1 thread): ~1 s
  • 💥C++ (8 threads): ~0.16 s

🖥 Integrating in Your App

  • 🔍Include in JS: 
    const { generatePrimes } = require('bindings')('heavyLifter');
  • ▶️Call naturally: 
    generatePrimes({count:400, start:"900...", threads:8}, (err, primes)=>{…});
  • 💤Runs async—main thread remains free!

🚀 Getting Started

  • 📘Read Node.js docs: “C/C++ Add-ons” & “C/C++ Add-ons with N-API”
  • 📂Explore node-addon-examples
  • 🔧Try the “node-cpu-intensive” demo repo on GitHub

📝 Key Tips

  • 🛡️Use mutexes (e.g. `std::lock_guard`) to protect shared data
  • 📈Profile & compare: only offload heavy CPU work
  • 👥Collaborate with C/C++ colleagues for complex tasks
