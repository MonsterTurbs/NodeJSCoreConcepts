🧵 Worker Threads: isMainThread

What is isMainThread? 🤔

  • Boolean flag in Node’s worker_threads module.
  • Tells you where your code is running:
    • true = main thread (your app’s original thread)
    • false = inside a worker (spawned thread)

Why use it? 🚦

  • In one file, run different code paths for main vs. worker:
    • const { isMainThread, Worker, parentPort } = require('worker_threads');

if (isMainThread) {
  // ↪️ spawn worker
  new Worker(__filename);
} else {
  // ↪️ worker work
  parentPort.postMessage('Hello from worker!');
}
  • Helps keep both main-and-worker logic in one place.

Beginner Tips 📝

  • Always check isMainThread before spawning—avoids infinite loops.
  • Use __filename so worker runs same file.
  • Clear code paths: main thread ⇄ worker thread sections.
