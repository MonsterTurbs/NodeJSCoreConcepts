🖥️ CPU & Process Utilization (Beginner)

💡 Core Utilization

  • Measures one CPU core’s busy time over a period (e.g. 100 ms).
  • Formula: (total_time – idle_time) / total_time × 100% 👍
  • Value is 0–100% per core (speed doesn’t matter).

📊 Total CPU Utilization

  • Average of all cores’ utilizations.
  • Formula: (sum of each core %) / number_of_cores ⚖️
  • Never exceeds 100%. It’s an overall “health” metric.

🔍 How to Find Core Count

  • macOS/Linux: nproc or sysctl -n hw.ncpu
  • Windows PowerShell: (Get-WmiObject -Class Win32_ComputerSystem).NumberOfLogicalProcessors
  • Node.js: os.availableParallelism() 🖥️

🛠️ Process CPU Utilization Methods

  • 👣 Method 1 (per‐core): Sum core usage used by process. - Four threads fully busy → 400% usage. - Common on macOS & top default.
  • 🔢 Method 2 (normalized): Divide Method 1 result by core count. - Four cores & one busy core → 25% usage. - Used by Windows Task Manager & some Linux monitors.

⚙️ Switching Between Methods

  • Linux top: Press Shift + I to toggle Irix mode (Method 1) on/off.
  • Observe process % change (e.g. 100% → 50% on a 2-core machine).

📈 Visualizing Core Load

  • macOS Activity Monitor: View ▶️ CPU History for each core.
  • Windows Resource Monitor: Performance → CPU → per‐core graphs.
  • Linux System Monitor: Resources → per‐core charts.

⚙️ Recap

  • Core Utilization: Busy% of one core (0–100%).
  • Total CPU: Average across cores (0–100%).
  • Process CPU:
      • Method 1: Sum of cores used (can exceed 100%).
      • Method 2: Normalized by core count (max 100%).
  • Always confirm which method your monitor uses! 🔎
