🧩 Add a New Task to the Thread Pool

➕ Create a Factorial Task

  • Write calculateFactorial(n) function: 
    
function calculateFactorial(n) {
  let result = 1n;
  for (let i = 2n; i <= n; i++) result *= i;
  return result;
}
module.exports = calculateFactorial;
  • Export from factorial.js and require in your pool controller:
  • In your worker‐pool switch:
    • 
case 'factorial':
  const fact = calculateFactorial(options.n);
  parentPort.postMessage(fact);
  break;

🔄 Submit Factorial Jobs

  • When scheduling, choose task type by condition, e.g.:
    • 
if (i % 5 === 0) {
  pool.submit({ type: 'factorial', n: BigInt(i) });
} else {
  pool.submit({ type: 'primes', count: i, start: BigInt(2) });
}
  • Worker threads handle both tasks seamlessly in parallel 🏃‍♂️🏃‍♀️

✅ Quick Test

  • Run node app.js and monitor CPU—you’ll see mix of prime & factorial jobs.
  • Add console.log inside each case to confirm results 🤓

💡 Key Takeaway

  • Extending your pool with new operations is as easy as adding a new case ✔️
  • Workers stay reusable; main thread simply dispatches tasks, keeping it free 🔧
