🖥️ CPU-Intensive HTTP & Worker Threads

1. Setup Heavy Server 🚧

  • Download and unzip the “Heavy Server” starter code.
  • Run npm install and npm start to launch on http://localhost:8090.
  • Routes: login/logout/profile + /api/primes?start=<n>&count=<k>.

2. Blocking Main Thread ⚠️

  • Prime generator runs in the main thread:
    • const primes = generatePrimes(count, start);
// … send response
  • With large inputs (e.g. count=400,start=1e12), it can take 10+ seconds.
  • During that time, all other HTTP requests (home, profile…) are frozen.

3. Cluster ≠ Fix 🛑

  • Spinning multiple Node instances (cluster) distributes load, but cloning the block still happens.
  • Under heavy simultaneous requests, each instance still blocks separately.
  • Cluster helps scale, but doesn’t un-block the main thread.

4. Worker Threads Solution 🧵

  • Move heavy work into a separate file (e.g. lib/calc.js).
  • In your route handler:
    • const { Worker } = require('worker_threads');
app.get('/api/primes', (req,res)=>{
  const worker = new Worker('./lib/calc.js', {
    workerData: { start, count }
  });
  worker.on('message', primes => res.json({ primes }));
});
  • In lib/calc.js:
    • const { parentPort, workerData } = require('worker_threads');
const generatePrimes = require('./primeGenerator');
const { start, count } = workerData;
const primes = generatePrimes(count, start);
parentPort.postMessage(primes);

5. Non-Blocking in Action 🌐

  • Each /api/primes request spawns one thread—main thread stays free.
  • Concurrent heavy requests run in parallel but don’t block simple routes.
  • Test: open 3 tabs, each generating primes → CPU ≈300%, profile/home remain responsive.

6. Tips & Best Practices 💡

  • 🚦 Thread Pool: Pre-spawn fixed threads and send tasks instead of constant spawn/terminate.
  • ⏱️ Request Timeout: Use worker.terminate() after timeout to avoid runaway tasks.
  • 🔐 Rate-Limit: Protect heavy endpoints so one user can’t exhaust threads.
  • 📊 Monitor: Watch CPU & thread counts in real-time to avoid overload.
