⏳ Event Loop & Main Thread

🔄 What Is the Event Loop?

  • It’s the engine that runs Node.js JavaScript code.
  • Continuously checks task queues, runs callbacks, then repeats.
  • Keeps the main thread non-blocking for asynchronous I/O. ⚙️

🧵 Main Thread Duties

  • Executes your JavaScript, one instruction at a time.
  • Schedules and dispatches async callbacks (timers, I/O) via the event loop.
  • Runs non-blocking code quickly, then yields to next callback. 🚦

🛑 Blocking vs Non-Blocking

  • Blocking code (e.g., while(true)) freezes the main thread.
  • Non-blocking code (e.g., setTimeout, I/O) uses callbacks—event loop handles resume.
  • Always avoid heavy loops or sync I/O on main thread! 🚫

🔍 Visualizing Flow

  • 🏃‍♂️ Main thread runs top-level code.
  • ⏲️ Syncs timers, I/O requests → yields to sleep state.
  • ⚡ On events (timer, network), moves callbacks to ready queue.
  • 🔁 Dispatcher picks next callback → main thread resumes work.

💡 Tips for Beginners

  • Use non-blocking APIs (e.g., fs.readFile vs fs.readFileSync).
  • Break large tasks into smaller chunks or move to worker threads.
  • Monitor event loop lag with tools like node:perf_hooks or clinic. 📈
