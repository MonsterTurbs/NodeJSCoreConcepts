⚙️ Intro to Our CPU-Intensive Program

Key Concepts

  • 🖥️ CPU-Intensive Task: Generating large prime numbers takes significant processor time.
  • ⏳ When one request runs this heavy work synchronously, the entire Node.js server blocks.
  • 🚫 While blocked, other requests (e.g., visiting profile) wait until completion.
  • ❌ Spawning extra cluster processes helps capacity but doesn’t remove blocking.
  • ✅ Solution: Offload heavy computation into separate threads (or child processes) so main loop stays free.

Code Example Sketch

app.get('/primes', (req, res) => {
  const result = generatePrimes(start, count); // 10s CPU work
  res.json(result);
});

👉 This blocks the event loop for ~10 seconds per request.

Next Steps

  • 🔨 Use worker_threads or child_process to run generatePrimes off the main thread.
  • ⚙️ Communicate results back so the server can handle other requests concurrently.
