📦 Buffers & Binary – Beginner-Friendly Study Notes

❓ Why Are Buffers So Important?

  • 🔑Almost everything on a computer is binary data (zeros and ones).
  • 🌐Files, videos, sounds, network requests, even this webpage—it’s all stored as 0s and 1s.
  • ⚙️Node.js runs on top of those zeros and ones. To read/write files or talk over the network, we need a way to handle raw binary.
  • 📦Buffer objects in Node.js let us work directly with raw bytes (the 0s and 1s!), so we can read a file, send/receive data, and more.
  • 🚀Without buffers, Node.js wouldn’t be able to read a file or send a network packet—buffers link JavaScript code to the low-level binary world.

💻 Computers Understand Only Binary

  • 🔢Binary means “two”: data made of only 0s and 1s (off/on).
  • 🏭Every computer chip (CPU) has tiny switches (transistors) that can be off (0) or on (1).
  • 💡In old computers, light bulbs were used: light=1, dark=0.
  • 📶Even Wi-Fi or 4G/5G is sending “on/off” signals (radio waves) to represent 0s and 1s.
  • 💾Storage devices (USB thumb drives, SSDs, hard drives, DVDs) all store 0/1 in different ways—magnetic charges, electronic charges, pits on a disc, etc.
  • 🔊Audio, video, and all files on your computer are just long sequences of zeros and ones.

🛠️ How Buffers Help in Node.js

  • 📂Imagine you want to read a file from disk: disk returns raw bytes (0s & 1s). How do you catch them in JavaScript? By using a Buffer.
  • 🌐When you send or receive data over the network (HTTP, TCP, etc.), the data travels as bytes—Node.js wraps those bytes into a Buffer.
  • ⚡Buffers give direct access to binary chunks, so you can manipulate data at the “byte” level (e.g., convert to string, modify bits, merge chunks).
  • 🔀Many core Node.js APIs (like fs and net) pass around buffers when handling streams, sockets, and files.
  • 📈Understanding buffers unlocks all of Node’s core modules—without them, you can’t work with low-level data.

🔢 Binary Numbers (Preview)

  • 0️⃣/1️⃣Binary (base-2) uses only two digits: 0 and 1.
  • 🔠What we write as “5” in decimal is “101” in binary (because 1×2² + 0×2¹ +1×2⁰ = 4 + 0 + 1 = 5).
  • 🧮Every byte (8 bits) is a sequence like 01101001, which can represent numbers 0–255.
  • 🎯We’ll learn how to convert between decimal and binary step by step.

🔗 Hexadecimal Numbers (Preview)

  • 🔟Hex (base-16) uses digits 0–9 and letters A–F (for values 10–15).
  • 📦One hex “pair” (like 3F) equals exactly one byte in binary (3F₁₆ = 00111111₂).
  • ✂️Hex is used to write bytes more compactly; e.g., 0x3F is shorter than “00111111.”
  • 💡We’ll practice converting between hex and binary/decimal.

🔤 Character Encodings (Preview)

  • 🔣Text (letters, numbers, symbols) also sits in bytes—each character is a byte or multiple bytes.
  • 📜ASCII: simple encoding where “A” = 0x41 (binary 01000001), etc. Covers 0–127 in one byte.
  • 🌍UTF-8: modern encoding that uses 1–4 bytes per character, so we can store international scripts (e.g., emoji, Chinese characters).
  • 🔑Buffers let us convert a string into bytes (e.g., Buffer.from('hi')) and back (buf.toString()).
