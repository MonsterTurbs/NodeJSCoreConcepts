📝 Reading the Buffer Documentation

📚 Why Read the Buffer Docs?

  • ✅You already learned the basics of buffers!
  • 🔍The docs explain every method and option.
  • 👉You’ll see how NodeJS uses buffers throughout modules like fs, net, and streams.
  • 🚀Reading the docs helps you build real projects faster and correctly.

💡 Buffer Basics

  • 📦A Buffer is a fixed-length sequence of bytes (0–255).
  • 🔢Buffers inherit from Uint8Array, meaning each element is 1 byte (8 bits).
  • 📏When you call Buffer.alloc(size), Node zero-fills those bytes; allocUnsafe skips zeroing for speed.
  • ⚙️Common operations: reading, writing, slicing, filling, comparing, and encoding/decoding text.

🧩 Typed Arrays & Uint8Array

  • 🔍Buffers are built on Uint8Array (a standard ES6 "typed array").
  • 📦Uint8Array means "array of 8-bit unsigned integers."
  • 🔄You could use new Uint8Array(n) similarly, but buffers have extra methods (like toString()).
  • ⚠️Before diving into typed arrays, make sure you understand binary numbers (e.g., two’s complement for negatives).

🔑 Key Buffer Methods

  • 📏Buffer.alloc(size[, fill]) – allocate & zero-fill.
  • ⚡Buffer.allocUnsafe(size) – allocate without zeroing (must fill() yourself).
  • 🐢Buffer.allocUnsafeSlow(size) – same as allocUnsafe but skips the internal pool.
  • 🔄Buffer.from(...) – create a buffer from an array, string, ArrayBuffer, or another buffer.
  • 🔗Buffer.concat([buf1, buf2, ...]) – join multiple buffers into one.
  • ✂️buf.slice(start, end) / buf.subarray(start, end) – get a new buffer view on part of the data.
  • 💬buf.toString(encoding, start, end) – decode bytes into text (e.g., 'utf8', 'hex').
  • ✍️buf.write(string, offset, length, encoding) – encode text into bytes.
  • 🔍Buffer.byteLength(string, encoding) – find how many bytes text needs.

🔢 Binary, Bytes & Encodings

  • 📦Each buffer element holds 1 byte (8 bits). Values range from 0 to 255.
  • ✏️When reading ≈ writing numbers, use methods like buf.readUInt8() or buf.writeUInt8(), or bigger variants (16, 32, 64 bits).
  • 🌐Text is stored in bytes via a character encoding (e.g., utf8, ascii, latin1). Always specify the right one, or text will look garbled!
  • ⚙️For negative numbers or floats, Node provides readInt8/16/32, readFloat, etc.—these rely on two’s complement and IEEE-754 formats.
  • 📖To truly master typed arrays, brush up on binary basics:
    • 0️⃣1️⃣Binary counting & bitwise shifts (e.g., >>1 = divide by two).
    • ➕➖Two’s complement for negative integers.
    • 🔣IEEE-754 for floating-point numbers.

⚠️ Deprecated Methods & Tips

  • ❌buf.slice() is now deprecated—use buf.subarray().
  • 🔍Check with Buffer.isBuffer(obj) to confirm if something is a buffer.
  • 🔤Buffer.isEncoding(enc) tells you if a string like 'utf8' or 'hex' is valid.
  • 📊Buffer.poolSize shows Node’s default internal pool (usually 8192 bytes).
  • 🚫Be cautious with allocUnsafe()—always fill or overwrite before use.
