🔷 Hexadecimal Numbers – Beginner-Friendly Notes

🔢 What Is Hexadecimal?

  • 🔍Hexadecimal is a base 16 number system.
  • 🔢“Base 16” means we use 16 symbols: 0–9 plus A–F (where A=10, B=11, …, F=15).
  • 💡We prefix hex numbers with an indicator like 0x (e.g. 0x456) so we know they’re hex.
  • ❓Why learn hex?
    • Hex is a compact way to write binary (4 bits per hex digit).
    • Easier to read memory addresses, color codes, and file contents than long strings of 0s and 1s.

🔠 Hex Digits & Their Values

  • 🔟Digits 0–9 represent values 0–9.
  • 🔠Letters A–F represent values 10–15:
    • A = 10
    • B = 11
    • C = 12
    • D = 13
    • E = 14
    • F = 15
  • 🔄Hex is case-insensitive: 0xAa equals 0xAA.

🧮 Hex → Decimal Conversion

  • 📐To convert a hex number, multiply each hex digit by 16ⁿ, where n is its index (0 at rightmost).
  • Example: 0x456
    • Rightmost 6 × 16⁰ = 6 × 1 = 6
    • 5 × 16¹ = 5 × 16 = 80
    • 4 × 16² = 4 × 256 = 1024
    • Sum = 6 + 80 + 1024 = 1110₁₀
  • 🔍So, 0x456 in hex = 1110₁₀ in decimal.

🔢 Hex → Decimal with A–F

  • 🔠Example: 0xFA3C
    • Rightmost C (12) × 16⁰ = 12 × 1 = 12
    • 3 × 16¹ = 3 × 16 = 48
    • A (10) × 16² = 10 × 256 = 2560
    • F (15) × 16³ = 15 × 4096 = 61440
    • Sum = 12 + 48 + 2560 + 61440 = 64060₁₀
  • 📊So, 0xFA3C = 64060 in decimal.

📏 Comparing Lengths

  • 🔢Hex 0xFFFFFF is 6 hex chars.
  • 🔠Decimal equivalent 16777215 is 8 decimal chars.
  • 💻Binary equivalent 11111111 11111111 11111111 is 24 bits (24 chars).
  • ✨Hex condenses 24 binary bits into 6 hex digits—much easier to read!

🔄 Quick Hex ↔ Binary Conversion

  • 🗒️Each hex digit = exactly 4 binary bits (nibble).
  • 🛠️Use a simple lookup table for 0–F:
    • 0 → 0000
    • 1 → 0001
    • … up to …
    • 9 → 1001
    • A → 1010
    • B → 1011
    • C → 1100
    • D → 1101
    • E → 1110
    • F → 1111
  • 🔄Example: Hex 5F → 5 = 0101, F = 1111 → Binary 01011111.
  • 🔄To convert binary 1011 0110 → split into nibbles: 1011 = B, 0110 = 6 → Hex B6.

🌐 Real-World Uses of Hex

  • 🎨Color Codes (CSS/HTML): #FF5733 (shorter than 24 binary bits).
  • 🌐URLs & Encoding: Non-ASCII characters become %20, %E2%9C%93, etc.
  • 🔡Unicode Code Points: Represent characters like &#x2764; for ❤️.
  • 🖥️Memory Addresses: Commonly shown as 0x7FFFB2A4 in debuggers.
  • 📂Binary Files: Hex dumps let you inspect file contents (e.g. codecs, executables).

🚀 Why Hex Matters for Engineers

  • 🧩Hex is a bridge between humans and machine: easier to read than raw binary.
  • ⚙️In back-end work (networking, encryption, file I/O), you’ll often inspect raw data in hex.
  • 📚Knowing hex (and binary) is a fundamental skill—software courses teach it early on.
  • ✨Hex never becomes outdated—it’s been around for decades and still underpins modern computing.
