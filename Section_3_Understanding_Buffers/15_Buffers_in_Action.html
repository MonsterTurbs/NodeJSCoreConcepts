📝 Buffers in Node.js – Study Notes

📁 Project Setup

  • 💻Open your terminal and navigate to your workspace (e.g., Desktop).
  • 📂Create a folder named buffers for this section’s code: 
    mkdir buffers  
cd buffers
  • 📝Inside buffers, create app.js: 
    touch app.js
  • ⚙️Open app.js in your code editor.

🔧 Requiring the Buffer Object

  • 🧩At the top of app.js, include the Buffer module: 
    const Buffer = require('buffer').Buffer;
  • ℹ️Even though Buffer is global, it’s best practice to require it explicitly.
  • 🔗Now you can use Buffer.alloc(), Buffer.from(), and all Buffer methods.

🛠️ Allocating a Buffer

  • 🤏Buffers are fixed‐size memory containers. To reserve 4 bytes (32 bits): 
    const buf = Buffer.alloc(4);  
// This creates a 4-byte buffer, each byte = 8 bits.
  • 🔢Each of the 4 bytes starts at 0x00 (all bits = 0).
  • 📦Think of buf as an “array” of 4 elements, each element = 1 byte (0–255).

👀 Inspecting the Buffer Contents

  • 📋Log the buffer to see its initial state: 
    console.log(buf);  
// Output: <Buffer 00 00 00 00>
  • 🔍Each “00” is one byte set to zero, shown in hexadecimal by default.
  • 🔢To log the first element (byte) in decimal: 
    console.log(buf[0]); // 0

✍️ Writing Hex Values to Buffer Bytes

  • ✏️Each byte holds an integer 0–255. To write the first byte = 0xF4 (hex): 
    buf[0] = 0xF4;  
console.log(buf);  
// <Buffer f4 00 00 00>
  • 🔢In decimal, 0xF4 = 244, so console.log(buf[0]) prints 244.
  • 🔄You can write to any index 0–3: 
    buf[1] = 0x34;  
buf[2] = 0xB6;  
buf[3] = 0xFF;  
console.log(buf);  
// <Buffer f4 34 b6 ff>

🔢 Byte Range & Maximum Value

  • 📏Each buffer element = 8 bits → can hold 0–255 (decimal).
    • Min: 0x00 → 0
      Max: 0xFF → 255
  • 🧮To confirm, open a Programmer Calculator (Windows: type “Calculator” → View → Programmer).
    • Select “Hex” and enter FF → switch to “Dec” → you get 255.
    • All bits = 11111111₂ → 255₁₀.
  • ⚠️If you assign a number >255, Node.js clamps it to 255; if <0, clamps to 0.

➖ Negative Numbers & Two’s Complement (Advanced)

  • ❗By default, each byte is treated as unsigned 0–255. To store signed (negative) values, Node.js uses two’s complement.
  • 🔄Example:
    • Want to store -34 in one byte: 
      buf[2] = -34;  
console.log(buf[2]); // prints 222
    • 🔢222 = 0xDE. To decode as signed, take 0xDE (11011110₂), flip bits (00100001₂ → 0x21), add 1 → 0x22 (34), then attach “−” → −34.
  • ⚙️Rather than manual flipping, use Buffer’s “write”/“read” methods:
    buf.writeInt8(-34, 2); console.log(buf.readInt8(2)); // −34
  • 🛑We won’t dive deeply into two’s complement here; this is just a quick note. For most text/binary use, keep data as unsigned.

🔤 Converting Buffer → String

  • 🌐Buffers hold raw bytes. To interpret them as text, use an encoding (e.g., UTF-8).
  • ✨Example: 
    const bufText = Buffer.from([0x48, 0x69, 0x21]); // [ “H”, “i”, “!” ]  
console.log(bufText.toString('utf8')); // “Hi!”
  • ⚙️buf.toString('hex') shows raw bytes as a hex string (e.g., "486921").
  • 💡Always match the encoding used when writing text into a buffer with the .toString(…) encoding when reading it back.

🖋️ Creating Buffer from Hex String

  • ✂️Instead of manually writing buf[0]=0x48, use Buffer.from(…, 'hex') to build a buffer from a hex string:
    • const bufHex = Buffer.from('486921', 'hex');  
console.log(bufHex);          // <Buffer 48 69 21>  
console.log(bufHex.toString('utf8')); // "Hi!"
  • 🧠Node auto‐calculates buffer size (3 bytes for "486921").

🎯 Challenge: Write Raw Binary & Decode

  • 📋Raw binary data:
    01001000 01101001 00100001 (24 bits total).
  • 🔢Step 1: Count bits → 24 bits → bytes = 24 ÷ 8 = 3. Allocate a 3‐byte buffer.
  • 🖋️Step 2: Split into three 8-bit chunks:
    • 01001000 → hex 0x48
    • 01101001 → hex 0x69
    • 00100001 → hex 0x21
  • ⚙️Step 3: In app.js: 
    const Buffer = require('buffer').Buffer;  
const buf = Buffer.alloc(3);  
buf[0] = 0x48;  
buf[1] = 0x69;  
buf[2] = 0x21;  
console.log(buf);            // <Buffer 48 69 21>  
console.log(buf.toString('utf8')); // "Hi!"
  • ✅If correct, buf.toString('utf8') prints "Hi!".
  • 💡You can also use Buffer.from('486921', 'hex') to skip manual byte‐by‐byte writes.

⚠️ Pitfalls: Buffer Size Must Match Data

  • ❌Too large (e.g., Buffer.alloc(10) for 3 bytes):
    • Result: Extra bytes remain 0x00 → wasted memory.
  • ❌Too small (e.g., Buffer.alloc(1) for 3 bytes):
    • Result: Only first byte is written; the other two are discarded.
  • ✅Always allocate exactly data_length_in_bits ÷ 8 bytes.

🆚 Alternative: Buffer.from(…)

  • 🚀Instead of: 
    const buf = Buffer.alloc(3);  
buf[0]=0x48; buf[1]=0x69; buf[2]=0x21;
  • ✨You can write: 
    const buf = Buffer.from('486921', 'hex');  
console.log(buf.toString('utf8')); // "Hi!"
  • ⚙️Node auto‐calculates size = 3 bytes and fills the data.

🔤 Character Encoding Reminder

  • 🌍Buffers store raw bytes. To interpret them as text, choose the correct encoding.
  • ✨buf.toString('utf8') decodes bytes as UTF-8 text (our “Hi!” example).
  • ⚠️If you decode with the wrong encoding, you’ll see garbage. e.g. buf.toString('utf16le') ≠ “Hi!”.

📚 Quick Reference: Common Buffer Methods

  • 🆕Buffer.alloc(size) – create a zero‐filled buffer of size bytes.
  • 🔄Buffer.from(string, encoding) – build buffer from text (e.g., “Hello” → UTF-8 bytes).
  • 🔄Buffer.from(hexString, 'hex') – build buffer from a hex string of raw data.
  • 👀buf.toString(encoding) – decode bytes into text with encoding (e.g., “utf8”, “hex”, “ascii”).
  • ✍️buf[index] = value – write a single byte (0–255) at index.
  • ✏️buf.writeInt8(n, offset) – write signed 8-bit number at offset.
  • 📖buf.readInt8(offset) – read signed 8-bit number from offset.
  • 🗜️Other writes/reads: writeUInt16LE, readUInt32BE, writeDoubleLE, etc.
