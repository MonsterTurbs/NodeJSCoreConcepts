📘 Your First C App: Quick Notes

📁 File & Folder Setup

  • Create folder: learning-C 📂
  • Inside, make app.c for C code 📝
  • Extension .c tells compiler “this is C”
  • Header files use .h (we’ll cover later)

🧩 The main Function

  • Every C program starts at int main() 🚀
  • Only main runs by default
  • Return 0 means “success,” non-zero means “error” ⚠️
  • Example skeleton: 
    int main() {
    // your code here
    return 0;
}

⚙️ Compile & Run

  • Compile with GCC:
    • gcc -o app app.c
  • Creates executable app (instead of default a.out)
  • Run it:
    • ./app
  • That’s it! You just ran your C program.

🖨 Printing Text with printf

  • Use printf() to write to standard output:
    • printf("Hello, C world!\n");
  • Need to include header for I/O functions:
    • #include <stdio.h>
  • This header defines printf & others

🔍 Where Does <stdio.h> Come From?

  • Headers live in system include folders
  • GCC searches these paths:
    • gcc -E -x c -v - < /dev/null
  • Look under “#include <...> search starts here:”
  • These folders contain files like stdio.h

✅ Quick Recap

  • Create .c file, write main() 🖋️
  • Include needed headers (<stdio.h>) 📚
  • Compile with gcc -o app app.c ⚙️
  • Run with ./app ▶️

🎉 Congratulations on your first C program!
