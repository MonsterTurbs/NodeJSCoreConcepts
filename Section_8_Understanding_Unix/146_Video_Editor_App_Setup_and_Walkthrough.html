🎬 Video Editor Starter – Study Notes

1️⃣ Project Overview

This is a full-featured video editor backend. Users can:

  • 🔼 Upload videos
  • 🔊 Extract audio
  • 📐 Resize/crop
  • 💾 Download originals or processed assets

Frontend is a React SPA; backend is Node.js + custom “Kpic” framework.

2️⃣ Client Structure & API Calls

Frontend code lives in public/scripts.js (built by React/Webpack).

All HTTP requests are marked with {@api call}. Key endpoints:

  • GET /api/videos – list user’s videos
  • POST /api/videos/:id/extract-audio – extract audio
  • GET /api/videos/:id/download?type=audio – download asset

Search for {@api call} comments in public/scripts.js.

3️⃣ Persistent File-based “DB” 💾

Data (users, sessions, videos) is stored in JSON files under /data.

Use DB.update() to reload from files, and DB.save() to write back.

Keeps data across restarts—essential for long video jobs and clustering.

4️⃣ Clean Code Organization 📂

  • src/index.js: app setup, middleware, router, error handler
  • src/middleware/: auth & static file serving
  • src/routes.js: maps URL → controller functions
  • src/controllers/: one file per resource (user.js, video.js)
  • src/db.js: file-based data layer

Keeps each concern in its own folder for maintainability. 👍

5️⃣ Kpic Feature: JSON Body Parser 📥

Utility parseJson lives in util.js. Add with:

cpp.beforeEach(cp.parseJson)

Automatically parses application/json bodies into req.body.

6️⃣ Kpic Feature: Static File Server 📁

serveStatic scans your public/ folder once at startup and maps URLs → files:

cpp.use(cp.serveStatic(path.join(__dirname, 'public')))

Fast lookup via an in-memory map; restart required if you add new files. 🚀

7️⃣ Kpic Feature: Error Handler ⚠️

Add after all routes to catch errors:

cpp.use(cp.handleError)

Controllers throw or pass an Error with .status & .message, then:

  • Sends JSON { message } & correct HTTP status
  • Logs unexpected errors & returns 500

8️⃣ Kpic Feature: URL Params Parser 🌐

Access query params via req.params.get('key')—wrapped URLSearchParams:

let id = req.params.get('id')

No more manual split('?') steps in your controllers.

9️⃣ Quick Test: Add “Get Videos” Route 🧪

1. In src/controllers/video.js:

exports.getVideos = (req, res, handleError) => {
  let name = req.params.get('name');
  if (!name) return handleError(400, 'Please specify a name');
  res.json({ message: `Your name is ${name}` });
};

2. In src/routes.js:

server.routes('get', '/api/videos', video.getVideos)

3. Run npm start → GET localhost:8060/api/videos?name=Joe 😊
