🎥 Installing FFmpeg & FFprobe

1️⃣ What Are FFmpeg & FFprobe?

FFmpeg is a powerful C-based tool for video/audio tasks: extract audio, resize, crop, convert formats… 🎬
FFprobe (part of FFmpeg) inspects media files and shows detailed info. 🔍

2️⃣ macOS: Download Prebuilt Binaries 🍎

  • Go to osxexperts.net/ffmpeg
  • Download both “Apple Silicon” & “Intel” zip files for ffmpeg and ffprobe.
  • Unzip to get two executable files.

3️⃣ Add to PATH 🔧

1. Pick a folder in your $PATH (e.g. /usr/local/bin)
2. Copy executables there:
mv ~/Downloads/ffmpeg /usr/local/bin/
mv ~/Downloads/ffprobe /usr/local/bin/
3. Reload your shell (source ~/.bashrc or restart).

4️⃣ Linux & WSL: Simple APT Install 🐧

On Ubuntu or Debian-based:

sudo apt update
sudo apt install ffmpeg

This also installs ffprobe. Verify with ffmpeg -version.

5️⃣ Build from Source (All Platforms) 🏗️

  1. Install Git & build tools:
    sudo apt install git build-essential (Linux)
    brew install git (macOS)
  2. Clone repo:
    git clone https://github.com/FFmpeg/FFmpeg.git
  3. Configure & compile:
    cd FFmpeg ./configure make -j$(nproc)
  4. Install to /usr/local/bin:
    sudo make install

Now ffmpeg & ffprobe are in your $PATH.

6️⃣ Uninstall Commands ❌

  • APT-install removal:
    sudo apt remove ffmpeg
  • Homebrew removal (macOS):
    brew uninstall ffmpeg
  • Source-built removal:
    cd FFmpeg sudo make uninstall
