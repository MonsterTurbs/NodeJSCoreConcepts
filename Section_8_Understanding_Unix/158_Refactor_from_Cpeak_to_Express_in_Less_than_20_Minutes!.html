🎓 Refactoring to Express

1️⃣ Smooth Express Switch 🚀

Refactored Kpig to Express in ~20 min—same routes/controllers, just replaced kpig() with express()!

🎉 It “just worked” with minimal changes.

2️⃣ Key Changes 🔑

  • Init: const app = express();
  • Body parsing: still use app.use(express.json()), no body-parser.
  • Static files: app.use(express.static(absolutePath))
  • Middleware: app.use(myMiddleware) vs. Kpig’s server.beforeEach.
  • Error handler: same signature (err, req, res, next).

3️⃣ Route Definitions 🛣️

// Kpig
server.get('/api/upload', uploadController);

// Express
app.get('/api/upload', uploadController);

Only difference: server.route → app.METHOD.

4️⃣ URL & Query Params 🔍

  • Kpig: req.params.get('videoId') for query
  • Express: req.query.videoId or req.params.videoId for URL params

Express supports “:/param” routes out of the box.

5️⃣ Cluster Mode & Express 🤝

Your existing cluster.js & JobQueue stayed unchanged—Express plays nicely in cluster mode!

6️⃣ Absolute Paths 📂

Express res.sendFile() needs an absolute path—use path.join(__dirname, '...').

7️⃣ Next Steps & Enhancements 🔭
