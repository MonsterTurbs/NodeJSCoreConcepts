📐 Video Resize – Study Notes

1️⃣ Why Schedule? ⏳

Resizing big videos can take minutes or hours and max out CPU. We’ll schedule one job at a time in next step.

2️⃣ API Route

POST /api/video/resize

Payload JSON: { videoId, width, height } 📐

3️⃣ Read & Validate


// get data
const { videoId, width: wStr, height: hStr } = req.body;
const width  = Number(wStr), height = Number(hStr);
db.update();
const video = db.videos.find(v => v.videoId===videoId);
if (!video) return handleError(404,'Video not found');

4️⃣ Mark “Processing” 🔄


// add entry: "WIDTHxHEIGHT": { processing:true }
video.resizes[`${width}x${height}`] = { processing: true };
const resp = { status:'success', message:'Video is being processed' };
res.status(200).json(resp);

5️⃣ Paths 📂


// original file
const inPath  = `storage/${videoId}/original.${video.extension}`;
// new resized file
const outPath = `storage/${videoId}/${width}x${height}.${video.extension}`;

6️⃣ Spawn FFmpeg 🐚


await f.resize(inPath, outPath, width, height);
// in lib/f.js:
spawn('ffmpeg', [
  '-i', inPath,
  '-vf', `scale=${width}:${height}`,
  '-c:a','copy',
  outPath
])
.on('close',code=> code===0?resolve():reject(...))
.on('error',err=>reject(err));

7️⃣ Finish & Save 💾


// on success:
video.resizes[`${width}x${height}`].processing = false;
db.save();
// on error:
await util.deleteFile(outPath);
return handleError(e);

✅ Recap

  • 🔎 Read videoId, width, height
  • ⚙️ Mark job “processing” & respond
  • 🛠️ Run FFmpeg to resize
  • ✔️ Update processing=false on finish
  • 🧹 Clean up on error
