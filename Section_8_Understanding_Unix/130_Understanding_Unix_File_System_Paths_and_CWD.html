🗺️ Unix Paths & Current Directory

🌳Filesystem Tree

• Everything lives under the / (root) folder.
• Subfolders and files form a tree: /home/user/docs/file.txt
• ls / shows top-level folders like bin, etc, home.

🚪Slash “/” = Separator & Root

  • Separator: Use / between folders: foo/bar/baz
  • Root path: Leading / means start from the top: /usr/bin

📍Dot & Dot-Dot

  • . = current directory
  • .. = parent directory
  • Example: cd ../sibling-folder moves up, then into sibling-folder.

🛣️Absolute vs. Relative Paths

  • Absolute: Always starts with /. E.g. /home/user/file.txt.
  • Relative: Depends on where you are. E.g. ./file.txt or subdir/file.txt.
  • Absolute works anywhere; relative only works if you’re in the right folder.

🔎Current Working Directory

• Your “current folder” where commands run.
• Get it in shell: pwd
• In Node.js: console.log(process.cwd())
• Child processes inherit parent’s cwd by default.

💻Why FS & Require Differ

• require('./file.js') resolves relative to the file’s own folder.
• fs.readFileSync('./text.txt') resolves relative to cwd!
• Mistake: If you run node path/folder/app.js from project root, FS looks for ./text.txt in root, not in path/folder.

🛠️Fix with __dirname & path.join

const path = require('path');
const fs   = require('fs');

// __dirname is the folder where this file lives
const txtPath = path.join(__dirname, 'text.txt');
const contents = fs.readFileSync(txtPath, 'utf8');
console.log(contents);

This builds an absolute path, so it works from anywhere.

🚀Key Takeaways

  • Understand /, ., .., absolute vs relative.
  • Current working directory (pwd / process.cwd()) affects FS calls.
  • Use __dirname + path.join for file-relative operations in Node.
