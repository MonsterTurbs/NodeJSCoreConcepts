🐚 Bash & Zsh: What Happens on Startup?

🔀Shell Types

  • Login shell: you “log in” (SSH, console).
  • Non-login shell: e.g. new terminal tab.
  • Interactive shell: you type commands live.
  • Non-interactive shell: runs a script file, no prompt.

📁Bash Startup Files

On a new login interactive bash shell, files run in order:

/etc/profile
~/.bash_profile  (or ~/.bash_login or  ~/.profile)
then ~/.bashrc

On a new non-login interactive bash shell, only:

~/.bashrc

⚙️Zsh Startup Files

On a new login interactive zsh shell:

~/.zprofile
~/.zshrc

On a new non-login interactive zsh shell:

~/.zshrc

🛠️Why Two Files?

  • profile/zprofile: global & login setup (PATH, env-vars).
  • rc/zshrc: interactive configs (aliases, prompt, functions).
  • Separating them speeds up non-login shells by skipping heavy login steps.

✨Make It Yours!

  • Edit your ~/.bashrc or ~/.zshrc—add:
    • Aliases alias ll='ls -l'
    • Functions
    • Prompt customization
    • Environment variables
  • Reload with source ~/.bashrc (or simply . ~/.bashrc).
  • Backup your config—save hours every month!

📋Quick Examples

# alias in bashrc
alias d='cd ~/Desktop'

# function in bashrc
mkd() {
  mkdir -p "$1"
  cd "$1"
}

# reload config
alias bc='source ~/.bashrc'

# prompt (bash)
PS1="\u:\W\$ "
