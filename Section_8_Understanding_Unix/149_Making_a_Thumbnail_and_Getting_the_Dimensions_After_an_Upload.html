🎥 Upload, Thumbnail & Dimensions 📏

1️⃣ Routes & spawn()

  • Use Node’s child_process.spawn to run FFmpeg/FFprobe.
  • Create a helper file lib/f.js with functions:
    • makeThumbnail(inputPath, thumbPath)
    • getDimensions(inputPath) → {width, height}

2️⃣ Thumbnail Path 📁

Store thumbnail in the video’s folder:

const thumbPath = `storage/${videoId}/thumbnail.jpg`;

This keeps each video’s assets together.

3️⃣ FFmpeg Command for Thumbnail 📷

Example shell command:

ffmpeg -i video.mp4 -ss 5 -vframes 1 thumbnail.jpg
  • -i: input file
  • -ss 5: seek to 5 sec
  • -vframes 1: capture 1 frame

4️⃣ makeThumbnail() Function ✂️

In lib/f.js:


async function makeThumbnail(inPath, outPath) {
  return new Promise((res, rej) => {
    const ff = spawn('ffmpeg', ['-i', inPath, '-ss','5','-vframes','1', outPath]);
    ff.on('close', code => code===0 ? res() : rej());
    ff.on('error', err => rej(err));
  });
}

5️⃣ FFprobe Command for Dimensions 📐

Example shell command:

ffprobe -v error -select_streams v:0 \
-show_entries stream=width,height \
-of csv=p=0 video.mp4

Outputs "1920,1080"

6️⃣ getDimensions() Function 🔢


async function getDimensions(path) {
  return new Promise((res, rej) => {
    let dims = '';
    const fp = spawn('ffprobe', [ /* args above */, path ]);
    fp.stdout.on('data', d=> dims += d.toString());
    fp.on('close', code => {
      if (code===0) {
        dims = dims.replace(/\s+/g,'');
        const [w,h] = dims.split(',');
        res({ width: +w, height: +h });
      } else rej(new Error(`ffprobe exit ${code}`));
    });
    fp.on('error', err=> rej(err));
  });
}

7️⃣ Error Handling & Cleanup 🚨

  • On spawn error or non-zero close code, reject promise.
  • In controller catch, delete folder if thumbnail failed:
await fs.rm(folderPath, { recursive:true });

8️⃣ Validate & Status Codes ✅

  • Check file extension against allowed array (e.g. ['mov','mp4']).
  • Return 400 Bad Request on unsupported format.
  • Return 201 Created on successful upload + thumbnail.
