🐾 Bash: Piping & Redirection

🔗 Pipe (|)

Take stdout of cmd1 and feed it as stdin to cmd2:

cmd1 | cmd2

📦 Chain Processes

You can keep chaining:

echo "hello" | tr '[:lower:]' '[:upper:]' | grep HELLO

→ converts to uppercase, then filters “HELLO”.

📥 & 📤 Redirect Streams

  • > file.txt → overwrite stdout to file
  • 2> err.txt → overwrite stderr to file
  • >> file.txt → append stdout

📂 Input Redirection

Use a file as stdin:

myprogram < input.txt

Equivalent to piping cat input.txt | myprogram.

🚫 Discard Output

Send unwanted output to “trash”:

cmd >/dev/null      # throw away stdout
cmd 2>/dev/null    # throw away stderr

🔢 File Descriptors

  • 0 = stdin
  • 1 = stdout
  • 2 = stderr

You can redirect FD by number: 2> err.log.

📑 Example: Echo → Node → Uppercase

echo "hi world" | node script.js | tr '[:lower:]' '[:upper:]'

● echo outs text → node reads stdin → tr uppercases.

🎯 Why It’s Useful

  • 🔧 Build small tools and glue them.
  • 💾 Save or filter exactly the streams you need.
  • 🚀 Automate workflows in one-liners.
