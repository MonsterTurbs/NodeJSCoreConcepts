⚙️ Node.js Clustering Explained

1️⃣ What Is Clustering? 🤔

Clustering runs your Node.js app multiple times (processes) so you can use all CPU cores instead of just one.

2️⃣ Why Cluster? 🚀

  • 💪 Utilise full CPU power (e.g. 8 cores → 8 worker processes)
  • 🔧 Handle heavy tasks without freezing the server
  • 🔄 If one worker crashes, the master can restart it

3️⃣ CPU Count in Node.js 🖥️

const os = require('os');
console.log(os.cpus().length);           // List of core objects
console.log(os.availableParallelism());  // Number of cores

Use os.cpus() or os.availableParallelism() to know how many workers to spawn.

4️⃣ Master & Workers 🎭

  • 👑 Master process: forks workers, monitors them
  • 🤖 Worker processes: run your app logic
  • 🔁 Master can respawn workers if they exit

5️⃣ How Fork Works 🔄

  1. Master calls cluster.fork()
  2. Node spawns a new process running the same code
  3. New worker gets its own CPU core and memory
  4. Repeat to match number of cores

6️⃣ Diagram Overview 📊

Hardware → Kernel → Master → Worker 1 (Core A)
         Worker 2 (Core B)
         … up to number of cores

7️⃣ Blocking vs. Non-Blocking ⚠️

A CPU-heavy loop (e.g., counting to millions) will block a single process for seconds, making the server unresponsive to other requests.

8️⃣ Clustering Solves Blocking 💡

With clustering, if one worker is busy, other workers can still handle new incoming requests—no freezing! 🛡️
