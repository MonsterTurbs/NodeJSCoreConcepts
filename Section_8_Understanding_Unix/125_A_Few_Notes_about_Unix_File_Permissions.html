🔐 Unix File Permissions

📄1. What Are Permissions?

  • Read (r): Can view the file’s contents
  • Write (w): Can modify or delete the file
  • Execute (x): Can run the file as a program or script

Each file has these permissions for three categories:

  1. User (file owner)
  2. Group (owner’s group)
  3. Other (everyone else)

🔍2. Checking Permissions

Use ls -l to list files with permissions:

-rwxr--r--  1 alice staff  123 Feb 10  file.sh
│││││││││
││││││││└─ others: r-- (read only)
│││││││└── group: r-- (read only)
│││││└──── user: rwx (read, write, execute)
│└───────── “-”: regular file (not a directory)
└────────── d: directory

⚙️3. Changing Permissions

Use chmod to adjust permissions. Examples:

  • chmod u+x file.sh — give owner execute rights
  • chmod u-rw file.sh — remove owner’s read & write
  • chmod ug+rw file.txt — add read & write for owner & group

Syntax: chmod [who][+-=][rwx] filename

👤4. Ownership

Every file has an owner and a group.

Check owner & group with ls -l, columns after permissions:

-rwxr--r--  1 alice staff      123 Feb 10  file.sh
│        └─ owner  └─ group

See your username with whoami. Switch to root (superuser) with sudo.

🚀5. Executing Files

A file must be x (executable) to run directly:

./script.sh      # works if 'script.sh' has u+x
script.sh         # permission denied if no 'x'

Or invoke with a shell:

bash script.sh
zsh script.sh
