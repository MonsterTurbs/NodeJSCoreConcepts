📂 Get Videos Route – Study Notes

1️⃣ Purpose

Allow a logged-in user to get the list of all their uploaded videos.

Endpoint: GET /api/videos 📋

2️⃣ Read & Refresh DB

  • Use our file-backed DB module to load latest data:
  • db.update() reads JSON files into memory

3️⃣ Filter by User 🔍

Only return videos owned by req.userId:


const all = db.videos;
const mine = all.filter(v => v.userId === req.userId);

4️⃣ Send Response 📤

Return the filtered list:


res.status(200).json(mine);

Status 200 OK on success.

5️⃣ Error Handling 🚨

  • If something goes wrong, call handleError.
  • Example: catch I/O or logic errors and send 500 Internal Server Error.

6️⃣ Test It 🧪

  1. Clear storage & DB data; restart server.
  2. Upload a video → thumbnail & DB entry created.
  3. GET /api/videos → see array of your videos.

7️⃣ Next Steps ▶️

Implement GET /api/videos/:id/assets?type=… to download:

  • type=original → raw video
  • type=thumbnail → JPEG thumb
  • type=audio → extracted AAC
  • type=resize → resized version
