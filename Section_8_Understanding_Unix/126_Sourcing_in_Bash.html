🔄 Bash: Sourcing & Reusable Code

✏️Defining Functions & Variables

  • Function syntax: 
    myfunc() {
  echo "Hello!"
}
    Call with myfunc.
  • Variables: 
    myvar=100
echo $myvar
    Note: no spaces around =, use $ when referencing.

📂Making Code Available Everywhere

To use your functions/vars/aliases in any shell, “include” your script:

source ~/scripts.sh
# or shorthand:
. ~/scripts.sh

This runs scripts.sh in the current shell.

🚚What Gets Imported?

  • Functions — your custom bash functions.
  • Variables — any VAR=… definitions.
  • Aliases — e.g. 
    alias ll='ls -l'

After sourcing, you can immediately call them:

$ myfunc
$ echo $myvar
$ ll
