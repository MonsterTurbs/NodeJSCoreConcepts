👶 Child Processes in Unix

🖥️What Is a Child Process?

Every running program in Unix is a process. When one process starts another, the new one is its child process.

  • Parent ↔ Child relationship
  • All processes (except the kernel) have a parent
  • PID = unique Process ID
  • PPID = Parent’s Process ID

📟Viewing PID & PPID

In your shell you can see your current process and parent IDs:

# Your shell’s PID
echo $$

# Your shell’s PPID
echo $PPID

Spawn a child (e.g. Node) and inspect inside it:

node -e "console.log('PID=', process.pid, 'PPID=', process.ppid)"

🐚Spawning in Bash

Any executable file can be run as a child process:

# Start a process from shell
/path/to/app arg1 arg2

# Example: run “ls -l”
ls -l

Behind the scenes, the shell calls a fork/exec system call to create the child.

💥Spawning in Node.js

Node’s child_process module lets you launch new processes:

const { spawn } = require('child_process');

const ls = spawn('ls', ['-l']);
ls.stdout.on('data', data => console.log(data.toString()));

The first argument is the executable name, the second is an array of arguments.

🔄Environment & Streams

  • Environment variables flow from parent → child
  • STDIN / STDOUT / STDERR are pipes for passing data
  • You can pipe, read output, or send input programmatically

👀Quick Recap

  • A PID identifies each process; PPID shows its parent.
  • Any executable—CLI or GUI—can be a child process.
  • Use your shell or Node’s spawn to launch children.
  • Communicate via arguments, environment, and streams.
