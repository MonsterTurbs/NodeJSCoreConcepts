🔍 How Bash Finds Your Commands

⚙️Command Lookup Order

When you type hello and press Enter, Bash checks in this order:

  1. Alias (custom shortcuts)
  2. Function (your defined scripts)
  3. Built-in (shell’s internal commands)
  4. PATH executable (program files on disk)

🔗1. Aliases

Quick text replacements. alias ll='ls -l' After you define it, typing ll runs ls -l.

Disable: unalias ll

🧩2. Functions

Mini-programs in your shell. 

myfunc(){
  echo "Hello, $1!"
}
Call with myfunc world, prints “Hello, world!”.

Remove: unset -f myfunc

🚀3. Built-ins

Commands built into Bash (no new process). echo, cd, pwd, etc. Faster than external programs!

📂4. PATH Executables

If it’s not above, Bash searches folders in $PATH for an executable file. See your paths with: 

echo $PATH | tr ':' '\n'

Add a folder: export PATH="$PATH:/home/you/bin"
