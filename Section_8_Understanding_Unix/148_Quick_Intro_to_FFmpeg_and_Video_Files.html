🎥 FFmpeg & Video File Basics

1️⃣ What Is a Video File?

  • 📸 A sequence of images called frames (e.g. 30 or 60 fps).
  • 🔊 May include one or more audio tracks (e.g. English, French).
  • 💬 Can contain subtitles or other data streams.
  • ⚙️ Uses codecs (encoders) for video frames (e.g. H.265) and audio (e.g. AAC).

2️⃣ Frames & Pixels 📐

Each frame is an image of width × height pixels. • Higher resolution = more pixels.

When played quickly, frames create motion! 🎬

3️⃣ Containers vs. Codecs 📦

  • Containers (extensions): MP4, MOV, MKV → hold streams.
  • Codecs: H.264, H.265 for video; AAC for audio → compress/decompress data.
  • Not all containers support every codec or subtitles.

4️⃣ Meet FFmpeg 🛠️

FFmpeg is a powerful open-source tool for video/audio:

  • 🎞️ Convert formats (e.g. MOV → MP4)
  • ✂️ Trim or cut segments
  • 🔧 Change codecs, bitrates, resolution
  • 🔊 Extract or remove audio
  • 🔢 Inspect streams, metadata, frames

5️⃣ Streams <– FFprobe 🔍

Use ffprobe to inspect a file:

ffprobe -v quiet -print_format json -show_format -show_streams input.mov > info.json

This outputs JSON containing:

  • 📹 Video stream(s): codec, width, height, fps
  • 🔊 Audio stream(s): codec, channels, bitrate
  • 📝 Other data streams & metadata

6️⃣ Quick ffprobe Example 📄

Sample JSON snippet:

{
  "streams": [
    { "codec_type":"video", "codec_name":"hevc", "width":1920, "height":1080, … },
    { "codec_type":"audio", "codec_name":"aac", "channels":2, … }
  ],
  "format": { "filename":"input.mov", "duration":"10.123", … }
}

We’ll read width & height for our app. 📏

7️⃣ ffmpeg in Action 🎞️➡️📦

Convert MOV to MP4:

ffmpeg -i input.mov output.mp4

FFmpeg reads -i input, writes new file. It uses all CPU cores by default but you can limit threads.

8️⃣ Why Use FFmpeg? 🌟

It’s everywhere: YouTube, VLC, Chrome, streaming apps. If you work with video as a backend dev, you’ll likely use FFmpeg!
