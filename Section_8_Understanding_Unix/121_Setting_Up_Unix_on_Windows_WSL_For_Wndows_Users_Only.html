💻 Setting Up Unix on Windows

⚙️Install WSL (Ubuntu)

Run in PowerShell as admin:

wsl --install

Reboot when prompted, then choose a UNIX username and password.

🐧Launch Ubuntu Terminal

  • Open Windows Terminal, click “+” and pick “Ubuntu”.
  • Make Ubuntu your default profile in Settings → Profiles → Default.

🗂️Access Windows Files

Your Windows C: drive is at /mnt/c/. To jump to Desktop:

cd /mnt/c/Users/YourName/Desktop

Tip: Add a shortcut in ~/.bashrc so you can des to go there.

🌐Install Node.js via NVM

  1. Download NVM: 
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.1/install.sh | bash  
source ~/.nvm/nvm.sh
  2. Install Node v20: 
    nvm install 20

🔧Developer Essentials

  • Global nodemon: npm install -g nodemon
  • Build tools & C compiler: 
    sudo apt update  
sudo apt install build-essential

🚀Test Your Setup

Run a simple Node server on WSL and access on Windows:

node app.js  # listens on localhost:4080

Visit http://localhost:4080 in Windows browser.

📂Persist Last Directory

Add to ~/.bashrc to remember your last folder across tabs:

# restore last working directory
function __save_cwd { pwd > ~/.last_cwd; }
function __restore_cwd { [ -f ~/.last_cwd ] && cd "$(cat ~/.last_cwd)"; }
PROMPT_COMMAND="__save_cwd; $__restore_cwd"

📊Monitor Processes

  • top — live system monitor
  • ps -aux — snapshot of running processes
