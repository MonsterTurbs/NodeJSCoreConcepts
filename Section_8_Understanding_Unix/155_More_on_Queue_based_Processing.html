🎓 Job Queue Review – Study Notes

1️⃣ Why Use a Queue? 🤔

Resizing videos can take a long time. If we run many at once, the computer slows down or crashes. A queue makes sure only one runs at a time.

2️⃣ What Is a Queue? 📚

  • FIFO: First In → First Out
  • enqueue(item) adds to end of list
  • dequeue() removes from front of list

3️⃣ How It Works – Step by Step


// 1. enqueue({videoId, w, h})
jobs.enqueue(job)

// 2. executeNext():
if (!currentJob) {
  currentJob = jobs.dequeue()
  execute(currentJob)
}

// 3. execute(job):
//    runs ffmpeg resize...
//    when done: 
currentJob = null
executeNext()

4️⃣ Enqueue from Controller 🖥️


// in video.js route:
const jobs = new JobQueue()

app.post('/api/video/resize', (req, res) => {
  const { videoId, width, height } = req.body
  jobs.enqueue({ type: 'resize', videoId, width, height })
  res.json({ status:'success', message:'Resize scheduled!' })
})

5️⃣ JobQueue Class Structure 🔧


class JobQueue {
  constructor() {
    this.jobs = []      // pending jobs
    this.current = null // running job
  }
  enqueue(job) {
    this.jobs.push(job)
    this.executeNext()
  }
  dequeue() {
    return this.jobs.shift()
  }
  executeNext() {
    if (this.current) return
    const job = this.dequeue()
    if (!job) return
    this.current = job
    this.execute(job)
  }
  async execute(job) {
    // perform resize...
    // on finish:
    this.current = null
    this.executeNext()
  }
}

6️⃣ Benefits ✅

  • 🛡️ Prevent CPU overload
  • ⌛ Immediate “Scheduled!” reply
  • 🔄 Jobs run in order
  • ⚙️ Easy to extend for other tasks
