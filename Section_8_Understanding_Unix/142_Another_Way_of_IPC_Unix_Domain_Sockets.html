🔌 IPC with Unix Domain Sockets

1️⃣ What Is IPC Socket? 🤝

IPC = Inter-Process Communication. Unix domain sockets let processes on the same machine talk directly.

2️⃣ Why Use Unix Sockets? 🚀

  • ✅ Faster than TCP (no network overhead)
  • 🔒 Only on local host (more secure)
  • 📁 Uses a special “socket file” as the address

3️⃣ Node.js Client Example 📝

const net = require('net');
const socketPath = '/tmp/ipc.sock';

const client = net.createConnection({ path: socketPath }, () => {
  console.log('✅ Connected to C server');
  // Send 8 bytes
  const buf = Buffer.alloc(8);
  buf.writeUInt8(0xAB, 0);
  buf.writeUInt8(0xCD, 1);
  // …
  client.end(buf);
});

client.on('data', data => {
  console.log('📥 From C:', data.toString('hex'));
});

client.on('error', err => {
  console.error('❌ Client error:', err);
});

4️⃣ C Server Example 🖥️

#include <sys/socket.h>
#include <sys/un.h>
#include <unistd.h>
#include <stdio.h>

#define SOCK_PATH "/tmp/ipc.sock"

int main() {
  int server = socket(AF_UNIX, SOCK_STREAM, 0);
  struct sockaddr_un addr = { .sun_family = AF_UNIX };
  strcpy(addr.sun_path, SOCK_PATH);
  bind(server, (struct sockaddr*)&addr, sizeof(addr));
  listen(server, 5);
  printf("🛡️ Server listening at %s\n", SOCK_PATH);

  while (1) {
    int client = accept(server, NULL, NULL);
    char buf[128];
    ssize_t len = read(client, buf, sizeof(buf));
    if (len > 0) {
      printf("📦 Received %zd bytes: ", len);
      for (int i=0; i<len; i++) printf("%02x ", (unsigned char)buf[i]);
      printf("\n");
    }
    close(client);
  }
  return 0;
}

5️⃣ How It Works 🔄

  1. Server bind() & listen() on socket file
  2. Client connect() to same socket path
  3. Data sent via write()/read() or socket.write()
  4. Server accept() new clients in a loop

6️⃣ IPC vs Pipes 📊

  • Pipes & stdio: simple one-way streams
  • Unix sockets: bidirectional, message-oriented

7️⃣ IPC vs TCP 🌐

IPC for same-machine (fast, local).
TCP for network (cross-host).

8️⃣ The “Socket File” 📂

Unix socket appears as a zero-length file:

$ ls -l /tmp/ipc.sock
srwxr-xr-x 1 you you 0 Jun  7 12:34 /tmp/ipc.sock

“s” = socket. It’s not real disk I/O—just an identifier.

9️⃣ When to Choose? 🤔

  • ↔️ Local IPC tasks (microservices on same host)
  • ⚡ Performance-critical same-host comms
  • 🔐 Privileged local daemons
