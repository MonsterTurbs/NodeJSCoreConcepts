📤 Adding Video Upload Route

1️⃣ Client Request 🖥️

Frontend sends a POST /api/upload-video with:

  • Binary file in the body
  • Original filename in header file-name

You can test in Postman with “binary” body + file selector. 📥

2️⃣ Define New Route 📑

In src/routes.js add:

server.routes('post', '/api/upload-video', video.uploadVideo)

Points to uploadVideo in controllers/video.js.

3️⃣ Read Filename & Extension ✏️

In controller:

const originalName = req.headers['file-name'];
const ext = path.extname(originalName).substring(1).toLowerCase();
const name = path.parse(originalName).name;

Grabs the header, splits off “.ext”, and file base name. 🗂️

4️⃣ Generate Unique Video ID 🎲

Use Node.js crypto:

const videoId = crypto.randomBytes(4).toString('hex');

Produces a random hex string to name the folder. 🔑

5️⃣ Create Folder & Save File 📂

  1. Make directory: await fs.mkdir(`storage/${videoId}`)
  2. Open write-stream: await fs.open(fullPath, 'w')
  3. Pipe upload into file: 
    await pipeline(req, fileStream)

Saves to storage/VIDEOID/original.${ext}. 🎉

6️⃣ Handle Canceled Uploads 🛑

Wrap pipeline in try…catch and on error:

await util.deleteFolder(`storage/${videoId}`);
// then handleError(...)

Removes incomplete folder if user cancels. 🗑️

7️⃣ Update File-based DB 📝

Store metadata in data/videos.json:

db.update();
db.videos.unshift({
  id: db.videos.length,
  videoId,
  name, ext,
  userId: req.userId,
  extractedAudio: false,
  resizes: {}
});
db.save();

Keeps list of all uploaded videos. 💾

8️⃣ Send Success Response ✅

Finally reply to client:

res
  .status(200)
  .json({ status: 'success', message: 'File uploaded!' });

Now upload route is done! 🎉
