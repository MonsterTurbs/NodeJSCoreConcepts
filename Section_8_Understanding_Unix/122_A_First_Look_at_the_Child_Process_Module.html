📝 Node.js child_process Basics

🚀What Is child_process?

The child_process module lets your Node.js app run other programs on your computer. You can spawn a new process or exec a shell command.

🌱spawn – Streamed Output

spawn() starts a program and gives you its output as a stream. Great for big data or long-running tasks. 

const { spawn } = require('child_process');
const ls = spawn('ls', ['-l']);

ls.stdout.on('data', chunk => {
  console.log(chunk.toString());
});

📌 Streams let you handle data in small chunks without using lots of memory.

⚡exec – Shell Commands

exec() runs a full shell command string and collects all its output before giving it to you. Good for quick tasks or piping. 

const { exec } = require('child_process');

exec(`echo "hello"| tr ' ' '\n'`, (err, stdout, stderr) => {
  if (err) {
    console.error('Error:', err);
    return;
  }
  console.log('Output:', stdout);
  console.log('Errors:', stderr);
});

📌 Output comes back all at once in stdout, not as a stream.

❓spawn vs exec: When to Use?

  • spawn: Use for large or continuous output (file transfers, logs).
  • exec: Use for short commands or when you need shell features (pipes, &&).

🔍Why spawn Didn’t Pipe?

spawn does not run your command through a shell by default. So pipes (|) and shortcuts (ll) aren’t understood. They work in exec because it uses a shell.
