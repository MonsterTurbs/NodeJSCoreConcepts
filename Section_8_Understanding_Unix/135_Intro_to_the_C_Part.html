📚 C-Part Pathways & Setup

🤔 Why Learn C?

  • 🔹 Unix & Linux are written in C
  • 🔹 Core developer tools (Node.js, databases) use C
  • 🔹 Deepen OS & memory understanding
  • 🔹 Boost your skills as a software engineer

🚦 Four Learning Paths

  1. ✅ Comfortable with C → jump to “C port” lecture
  2. 🔄 Need C refresh → watch learning-C videos
  3. ❌ Skip C code, but install compiler → download C & Node solutions
  4. 🚫 No C at all → skip C & compiler steps, use Node version

Tip: If under 1 year JS experience, skip C to avoid confusion.

🛠 Installing on macOS

Most Macs already include GCC & make. If missing:

xcode-select --install

Runs Apple’s Command-Line Tools installer (includes gcc & make).

🐧 Installing on Ubuntu/Linux

Update & install build tools:

sudo apt update
sudo apt upgrade
sudo apt autoremove -y
sudo apt install build-essential

Or install minimal:

sudo apt install gcc make

✅ Verify Installation

  • gcc → “no input files” (not “command not found”)
  • make → “No targets specified”

If errors appear, fix before proceeding.
