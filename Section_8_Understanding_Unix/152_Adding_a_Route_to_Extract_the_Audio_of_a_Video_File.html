🎵 Extract Audio – Study Notes

1️⃣ What It Does

Extract the audio track from a video file and save it as audio.aac in its folder. 🎬➡️🎧

2️⃣ API Route

Patch /api/video/extract-audio?videoId=<id>

Only once per video – after extraction, button changes to “Download Audio.”

3️⃣ Read & Validate


const videoId = req.params.get('videoId');
db.update();
const video = db.videos.find(v => v.videoId === videoId);
if (!video) 
  return handleError(404, 'Video not found');
if (video.extractedAudio) 
  return handleError(400, 'Audio already extracted');

4️⃣ File Paths 📂


const srcPath = `storage/${videoId}/original.${video.extension}`;
const outPath = `storage/${videoId}/audio.aac`;

5️⃣ Run FFmpeg spawn 🐚


await f.extractAudio(srcPath, outPath);
// inside f.extractAudio:
spawn('ffmpeg', [
  '-i', srcPath,
  '-vn',           // no video
  '-c:a', 'copy',  // copy audio
  outPath
])
.on('close', code => code===0?resolve():reject(...))
.on('error', err => reject(err));

6️⃣ Update DB & Respond 💾


video.extractedAudio = true;
db.save();
res.status(200).json({
  status: 'success',
  message: 'Audio extracted successfully'
});

7️⃣ Error Cleanup 🚨🧹


catch(e) {
  await util.deleteFile(outPath); // remove partial file
  return handleError(e);
}

✅ Recap

  • 🔑 Read videoId, find in DB
  • 🔒 Prevent re-extracting
  • 🛠️ Spawn FFmpeg: copy audio
  • 💾 Mark extractedAudio=true & save
  • 📤 Return success JSON
  • 🗑️ On error, delete file & report

🎉 Now users can extract audio with one click!
