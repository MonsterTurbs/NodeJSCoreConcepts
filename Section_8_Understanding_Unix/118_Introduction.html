🐧 Unix Essentials – Beginner Notes

🌟 Why Learn Unix?

  • 💻Most servers (and the Internet) run on Unix/Linux
  • 🚀Unlock powerful system tools & workflows
  • 🔧Skills translate to macOS & Windows
  • 🧠Deepen programming & DevOps understanding

📚 Core Concepts

  • 🐚Bash shell & command-line basics
  • 🔗Inter-process communication & data streams
  • ⚙️Process management & environment variables
  • 🧩Node.js: child_process, cluster, & process modules

1️⃣ Project: “show” CLI Utility

  • 📂Create a command-line tool like cat
  • 🔄Read from files or piped input
  • 🌊Learn Node.js streams & Unix piping
  • 🎯Usage: show text.txt or echo "hi" | show

2️⃣ Project: Massive IPC with C

  • 📊Read huge (10 GB) file in Node.js
  • 🔄Pipe numbers into a C program
  • 💰C app formats numbers as money
  • 📈Compare memory & CPU usage across processes

3️⃣ Project: Video-editing Server

  • 📹Upload & inspect video metadata
  • 🎵Extract audio via FFmpeg (C executable)
  • 📐Resize or convert formats
  • 🧪Run in single-process or clustered mode for full CPU utilization
