🔎 What Is a Shell?

🌐Shell in the OS

The kernel is the core of Unix (talks to hardware). A shell is just another program—an interface between you and the kernel. When you type commands in your terminal, the shell turns them into system calls.

📞System Calls

System calls let programs talk to the kernel (e.g., open(), read(), write()). You find them in man 2 pages. They’re usually used in C, but shells use them too under the hood.

📚Man‐Page Sections

  • man 1: User commands (ls, mkdir)
  • man 2: System calls (open, read)
  • man 3: C library functions (printf, malloc)

🐚Popular Shells

  • sh (Thompson, 1971) – original, now obsolete
  • Bourne sh (1979) – added features
  • bash (“Bourne Again SHell”, 1989) – default on Linux
  • zsh (1990) – more features, default on macOS
  • …and others (dash, csh, ksh)

🔄Launching a Shell

1. You open your terminal (app) → it tells the kernel: “Spawn a shell for me.”
2. The kernel starts the shell process (bash, zsh, etc.).
3. You type commands; the shell makes system calls and shows results.

Each new tab runs a new shell process. Type echo $SHELL to see which one you’re in! 😊
