🎬 Get Video Assets – Study Notes

1️⃣ Purpose

Serve video-related files (thumbnail, original video, audio, resized) via one route:

GET /api/videos/assets?videoId=<id>&type=<kind> 📁

2️⃣ Read Request Params 📥


const videoId = req.params.get('videoId');
const type    = req.params.get('type');

3️⃣ Load DB & Find Video 🔍


db.update();
const video = db.videos.find(v => v.id === videoId);
if (!video) return handleError(404, 'Video not found');

4️⃣ Pick File & MIME Type 🎞️

Use a switch(type):

  • thumbnail: storage/<videoId>/thumbnail.jpg, image/jpeg
  • original: storage/<videoId>/original.<ext>, video/mp4
  • audio: storage/<videoId>/audio.aac, audio/aac
  • resize: storage/<videoId>/<width>x<height>.<ext>, video/mp4

5️⃣ Set Headers & Stream 📡


const stats = await file.stats();            // get file size
res.setHeader('Content-Type', mimeType);
res.setHeader('Content-Length', stats.size);
if (type !== 'thumbnail') {
  res.setHeader('Content-Disposition',
    'attachment; filename=' + downloadName);
}
await pipeline(
  file.createReadStream(),
  res
);
file.close();                                // free system resources

6️⃣ Error & Edge Cases 🚨

  • Wrap await pipeline in try/catch to avoid crashes on client cancel
  • Validate type & handle missing files
  • Always file.close() to prevent resource leaks

7️⃣ Testing 🔧

  1. Visit /api/videos/assets?videoId=<id>&type=thumbnail → see image
  2. Type=original → triggers video download
  3. Type=audio → download .aac
  4. Type=resize → download resized video

✅ Summary

One smart route serves multiple file-types. Key steps:

  • Read & validate query params
  • Lookup video in DB
  • Locate correct file & MIME
  • Set Content-Type, Content-Length, Content-Disposition
  • Stream via pipeline() & close file

🎉 You're all set to serve any video asset!
