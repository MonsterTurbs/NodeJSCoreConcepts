📥 Reading Command-Line Arguments in C

✨ What Are Arguments?

  • When you run ./app arg1 arg2, those words after the program name are arguments. 🎯
  • C programs receive them in main() automatically from the shell.

🖋️ main Signature

int main(int argc, char *argv[]) {
    // ...
    return 0;
}
  • argc = argument count (number of tokens passed).
  • argv = argument vector (array of strings).

🔢 argc (Count)

  • Type int, holds how many items were passed.
  • Always at least 1 (the program name itself). 🎒

📝 argv (Strings)

  • An array of C-strings (char*), one per argument.
  • argv[0] = program name, argv[1] = first user argument, etc.

🔄 Looping Through Them

for(int i = 0; i < argc; i++) {
  printf("arg %d: %s\n", i, argv[i]);
}
  • Prints each argument in order.
  • Uses %d for the index, %s for the string. 💬

🚀 Example Run

$ gcc -o show args.c
$ ./show apple banana 123
arg 0: ./show
arg 1: apple
arg 2: banana
arg 3: 123
  • Arguments are split by spaces in the shell.
  • Dashes (-f, --help) are just more strings, handled the same way.

👍 Key Takeaways

  • ✨ argc = count, argv = array of C-strings.
  • 🔍 argv[0] is always your program’s name.
  • 📚 Loop from 0…argc-1 to access all arguments.
  • 🛡️ Always check argc before using argv[i] to avoid out-of-bounds errors.
