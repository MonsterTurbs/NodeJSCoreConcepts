🗂️ Video Resize Queue – Study Notes

1️⃣ Why Queue? 🤔

Resizing videos is heavy and can take minutes or hours. If we fire many at once, CPU spikes and crashes. We’ll queue jobs so only one runs at a time.

2️⃣ What Is a Queue? 📚

  • FIFO: First In → First Out
  • enqueue() adds to end
  • dequeue() removes from front

3️⃣ Queue Demo


// start
let q = [];
q.push("A"); // enqueue
q.push("B");
console.log(q.shift()); // "A" (dequeue)
console.log(q.shift()); // "B"

4️⃣ Build JobQueue Class


class JobQueue {
  constructor() {
    this.jobs = [];       // waiting list
    this.current = null;  // job in progress
  }

  enqueue(job) {
    this.jobs.push(job);
    this.executeNext();
  }

  dequeue() {
    return this.jobs.shift();
  }

  executeNext() {
    if (this.current) return;
    const job = this.dequeue();
    if (!job) return;
    this.current = job;
    this.execute(job);
  }

  execute(job) {
    // run ffmpeg resize...
    // on finish:
    this.current = null;
    this.executeNext();
  }
}

5️⃣ Enqueue in Controller


// in video.js route:
const jobs = new JobQueue();

app.post('/api/video/resize', (req,res) => {
  const { videoId, width, height } = req.body;
  jobs.enqueue({ type:'resize', videoId, width, height });
  res.status(200).json({ status:'success', message:'Resize scheduled' });
});

6️⃣ Execute a Job


async execute(job) {
  const { videoId, width, height } = job;
  const inPath  = `storage/${videoId}/original.mp4`;
  const outPath = `storage/${videoId}/${width}x${height}.mp4`;
  try {
    await f.resize(inPath, outPath, width, height);
    // mark done in DB...
    db.save();
  } catch(e) {
    util.deleteFile(outPath);
  }
  this.current = null;
  this.executeNext();
}

7️⃣ Benefits ✅

  • 🛡️ Avoid CPU overload
  • ⌛ Users get immediate response (“Scheduled!”)
  • 🔄 Jobs run in order
  • 🔧 Easy to extend for other tasks
