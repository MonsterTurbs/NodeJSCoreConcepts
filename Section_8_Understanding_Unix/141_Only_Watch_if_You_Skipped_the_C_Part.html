🔧 Massive Communication App: Quick Setup

1️⃣ Two Versions Provided

📂 In the resources you’ll find:

  • C version (number_formatter.c)
  • Node.js version (number_formatter.js)

👉 Download the one you prefer.

2️⃣ Compile the C Version

📥 Navigate to the folder and run:

gcc -o number_formatter number_formatter.c

✅ Produces ./number_formatter executable.

3️⃣ Place or Reference the Executable

  • 🔗 Either put number_formatter in your $PATH,
  • 📁 Or in Node code use "./number_formatter".

4️⃣ Run the Node Or C “Second Part”

📦 If you chose C:

node app.js

📦 If you chose Node.js:

node app.js number_formatter.js dest.txt '$' ','

5️⃣ High-Level Flow

  1. Node reads source.txt via stream.
  2. Pipes data into formatter (C or JS).
  3. Formatter prints formatted numbers into dest.txt.

6️⃣ CPU & Memory

  • ⚙️ Formatter (C or JS) uses ~100% CPU.
  • 💾 Node I/O uses low CPU & small memory.

7️⃣ Code Comparison

🆚 Both versions share same logic:

  • Read chunks from stdin.
  • Split by spaces → numbers.
  • Format with prefix & separators.
  • Write to output file.

8️⃣ Why C & Node Together?

🌐 Use the best tool for each job:

  • C for heavy processing.
  • Node for file/network I/O.

🔄 Streams glue them seamlessly.
