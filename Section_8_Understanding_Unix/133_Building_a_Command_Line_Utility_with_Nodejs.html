🐱 Build “cat” CLI Tool in Node

📋 What “cat” Does

  • Reads file(s) or stdin
  • Writes contents to stdout
  • Keeps streaming until end-of-file

Can also pipe: echo "hi" | cat → outputs hi.

⚙️ Setup & Modules

Start cat.js with:

const fs = require('fs');
const { stdin, stdout, exit } = require('process');

Use stdin for piped input, fs for files.

🔄 Reading from stdin

stdin.on('data', chunk => {
  stdout.write(chunk);
});

Streams data from keyboard or pipe until EOF.

📂 Handling File Argument

const fp = process.argv[2];
if (fp) {
  const rs = fs.createReadStream(fp);
  rs.pipe(stdout);
  rs.on('end', () => exit(0));
}

Reads file if an argument is given, then exits with code 0.

✨ Putting It Together

if (!fp) {
  stdin.pipe(stdout);
} else {
  // file code above…
}

Supports both piping stdin and file-reading.

🔧 Usage Examples

node cat.js somefile.txt           # read file
echo "hello" | node cat.js            # read stdin
node cat.js file.txt | tr a-z A-Z     # pipe into TR

🎗️ Add an Alias

In your ~/.bashrc or ~/.zshrc:

alias mycat='node /path/to/cat.js'

You can then run: mycat file.txt
