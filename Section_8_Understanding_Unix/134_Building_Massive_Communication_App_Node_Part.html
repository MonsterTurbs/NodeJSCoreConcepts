🚀 Massive Communication Study Notes

📦 Project Overview

We’ll build a “massive communication” system:

  • 🔹 Read huge file (kilobytes→gigabytes) via streams
  • 🔹 Spawn a second process (e.g. a C program)
  • 🔹 Pass data via stdout→stdin
  • 🔹 Process & write to a new file

🌲 Data Flow Diagram

  • Source File → Node.js app reads with streams
  • Node.js pipes data to Formatter Process
  • Formatter adds $ & commas → writes dest.txt

⚙️ Node.js Setup

const { spawn } = require('child_process');
const fs = require('fs');

Use fs.createReadStream & spawn().

🛠 Spawning Formatter

const fmt = spawn('number_formatter', [
  'dest.txt',   // output file
  '$',          // prefix each number
  ','           // thousands separator
]);

Pass arguments: destination, prefix, separator.

🔄 Streaming Data

fs.createReadStream('source.txt')
  .pipe(fmt.stdin);

Pipes source file into formatter’s stdin.

📣 Logging & Exit

fmt.stdout.on('data', d => console.log('OUT:', d.toString()));
fmt.stderr.on('data', d => console.error('ERR:', d.toString()));
fmt.on('close', code => {
  if (code === 0) console.log('✅ Success!');
  else console.error('❌ Error code', code);
});

Monitor stdout, stderr, and exit code.

💡 Why Streams?

  • Handle gigabytes without high memory use
  • Backpressure & flow control
  • Chain processes efficiently
