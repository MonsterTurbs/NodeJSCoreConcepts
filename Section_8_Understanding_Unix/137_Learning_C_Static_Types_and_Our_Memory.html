🧠 Static Typing & Memory in C

🔢 Static Typing

  • You must declare each variable’s type: int a = 20;, float b = 3.14; 🎯
  • C won’t guess for you—types are fixed at compile time.
  • Contrast with JS: let x = 5; works without type.

💾 Memory as Bytes

  • 📦 Memory is a sequence of 1-byte boxes, each with an address.
  • Addresses increase by 1 per byte:
    • … [addr100] [addr101] [addr102] …
  • You must tell C how to interpret those bytes (number, char, etc.).

🔍 sizeof & Type Sizes

  • Use sizeof(type) to see how many bytes a type uses:
    • printf("int = %zu bytes\n", sizeof(int));   // often 4
printf("long = %zu bytes\n", sizeof(long)); // often 8
  • May vary by system—always check with sizeof.

📢 printf & Format Specifiers

  • Print data with printf() after #include <stdio.h>
  • Must use correct format:
    • %d → int
    • %zu → size_t
    • %f → float
    • %c → char
    • %p → pointer/address

📍 Pointers & Addresses

  • Pointer = variable that holds an address: int *p = &a; 📫
  • “&” → address-of, “*” → dereference (go to that box):
    • int a = 10;
int *p = &a;
printf("a = %d, *p = %d\n", a, *p);
  • Pass just the address instead of copying large data—super efficient!

📜 Strings in C

  • C strings = array of chars ending with '\0' (null):
    • char s[5+1] = {'H','e','l','l','o','\0'};
  • Or easier: 
    char *s = "Hello";
  • No built-in length—write your own or use strlen() from <string.h>.

✅ Key Takeaways

  • 🛠️ In C you manage types & memory yourself.
  • 📦 Variables occupy fixed bytes you must choose.
  • 🔗 Pointers let you pass addresses, not copy data.
  • 📝 Strings are char arrays ending in '\0'.

🌟 You now understand static typing & memory basics in C!
