🎓 Job Queue: Resume on Restart

1️⃣ Why Resume Jobs? 🔄

When the server restarts, queued resizes with processing=true stay unfinished. We need to re-enqueue them so users don’t lose their work!

2️⃣ When to Resume? ⏰

In JobQueue constructor: after this.jobs = [], read DB, find all videos where resizes[key].processing === true, and enqueue() each.

3️⃣ Code: Scan & Enqueue 📋

DB.update();
DB.videos.forEach(video => {
  Object.keys(video.resizes).forEach(key => {
    if (video.resizes[key].processing) {
      const [w, h] = key.split('x');
      this.enqueue({
        type: 'resize',
        videoId: video.videoId,
        width: Number(w),
        height: Number(h)
      });
    }
  });
});

4️⃣ Handle FFmpeg Prompts ❗

FFmpeg may ask “overwrite?” if output exists. Add -y flag to arguments to auto-answer “yes.”

5️⃣ Limit CPU Usage 🖥️

FFmpeg can eat all cores. Use -threads N to restrict it:
spawn('ffmpeg', ['-threads','2', …])

6️⃣ Summary 📚

  • ✅ On startup, re-enqueue unfinished jobs
  • ⚙️ Use -y to skip prompts
  • 🌐 Use -threads or nice to manage CPU
  • 🔄 Ensures long tasks keep running after restarts
